# X4 点击 Claude Code 输入框移动光标
requires: real-claude
checklist: X4
scenarios: []

fake agent 的 `❯` 输入行不做行编辑（没有光标移动），所以这一项要用真实 claude。Claude Code 隐藏终端光标、自己画一个，
但把真正的光标放在输入位置（输入法候选框跟着它），`cursor` 读的就是它。在输入框里输入一串 `a`，点击中间，再输入 `X`：
`X` 插在 `a` 中间。只验证不提交（`ctrl+c` 清掉输入）。

## setup
```sh
tests/gui/sandbox.sh real-up --label x4
```

## steps
```gilvt-steps
# 真实 HOME 会恢复用户保存的布局：在新标签里做，路径都用当前标签
key    cmd+t
wait   windows[0].tabs[?active==true].panes[*] exists count=1 && windows[0].tabs[?active==true].panes[0].foreground == "shell" timeout=15s
type   "mkdir -p ~/gilvt-lab/x4 && cd -P ~/gilvt-lab/x4 && clear\n"
wait   windows[0].tabs[?active==true].panes[0].cwd contains "/gilvt-lab/x4"
type   "claude --no-chrome\n"
wait   windows[0].tabs[?active==true].panes[0].foreground == "agent:claude" timeout=30s
# 在这个目录第一次运行时 Claude 会先问是否信任它：screen_tail 里出现 trust 字样时执行 key enter
sleep  3s
type   "aaaaaaaaaaaaaaaaaaaa"
wait   windows[0].tabs[?active==true].panes[0].screen_tail[*] contains "aaaaaaaaaaaaaaaaaaaa" timeout=10s
click  'rect(windows[0].tabs[?active==true].panes[0].cursor)+(-40,0)'
sleep  0.5s
type   "X"
wait   windows[0].tabs[?active==true].panes[0].screen_tail[*] contains "aXa" timeout=5s
shot   x4-moved
key    ctrl+c
type   "/exit\n"
wait   windows[0].tabs[?active==true].panes[0].foreground == "shell" timeout=15s
key    cmd+w
```

## judge
- `x4-moved`：Claude 输入框里是 `aaaaa…Xaaaaa`，Claude 自己画的光标在 `X` 之后。

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/X4
```
