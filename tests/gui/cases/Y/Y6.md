# Y6 Agent 卡片补课，点一轮回到过程
requires: sandbox
checklist: Y6
scenarios: [three-turns]

`three-turns` 第 1 轮成功、第 2 轮 API 错误、第 3 轮是当前轮：补课列出 T3、T2、T1，点 T1 跳到该 pane、检查器「过程」里第 1 轮展开。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "claude @scenario:three-turns\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "测试通过。" timeout=20s
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="agent"] exists count=1 timeout=10s
click  'rect(windows[0].monitor.cards[?kind=="agent"].catchup)'
wait   windows[0].monitor.cards[?kind=="agent"].expanded == true timeout=5s
assert windows[0].monitor.cards[?kind=="agent"].rows[*] exists count=3
assert windows[0].monitor.cards[?kind=="agent"].rows[0].text contains "T3"
assert windows[0].monitor.cards[?kind=="agent"].rows[1].text contains "T2"
assert windows[0].monitor.cards[?kind=="agent"].rows[1].text contains "✗"
assert windows[0].monitor.cards[?kind=="agent"].rows[2].text contains "T1"
shot   y6-catchup
click  'rect(windows[0].monitor.cards[?kind=="agent"].rows[2])'
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].focused == true timeout=5s
wait   windows[0].inspector.tab == "process" && windows[0].inspector.rows[?label contains "第 1 轮"].expanded == true timeout=5s
shot   y6-inspector
```

## judge
- `y6-catchup`：卡片横跨两列，下方三行：T3「第三轮：跑测试」✓、T2「第二轮：拉取依赖」✗（红色）、T1「第一轮：列出文件」✓。
- `y6-inspector`：回到 claude 的 pane，右侧检查器「过程」里第 1 轮就地展开（能看到 `ls` 那一行）。
