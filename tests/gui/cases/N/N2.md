# N2 ⌘⇧W 与红色关闭按钮：列出该标签 / 该窗口内全部受影响的会话
requires: sandbox
checklist: N2
scenarios: [long-tool, ask-question, approve-bash]

标签 1 左右分屏：左 pane 执行中（long-tool），右 pane 在问你（ask-question）；标签 2：一个 pane 在等授权（approve-bash）。
`⌘⇧W`（关标签）的确认条只列该标签里的两个会话（`action: "tab"`）；红色关闭按钮（关窗口）的确认条列出窗口里全部三个（`action: "window"`）。
取消之后什么都没关。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/l2 && cd -P ~/work/l2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l2"
type   "claude @scenario:long-tool\n"
wait   windows[0].inspector.card.status == "running_tool" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"].status == "awaiting_answer" timeout=15s
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/l2 && claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?section=="needs_you"].status == "awaiting_approval" timeout=15s
# --- 标签 2 单独：只有等授权的那一个 ---
key    cmd+shift+w
wait   windows[0].close_confirm.action == "tab" timeout=3s
assert windows[0].close_confirm.items[*] exists count=1
assert windows[0].close_confirm.items[0].status == "等待授权"
shot   l2-tab2
key    esc
wait   windows[0].close_confirm == null timeout=3s
assert windows[0].tabs[*] exists count=2
# --- 标签 1（分屏）：左右两个会话 ---
key    cmd+1
wait   windows[0].tabs[0].active == true timeout=3s
key    cmd+shift+w
wait   windows[0].close_confirm.action == "tab" timeout=3s
assert windows[0].close_confirm.items[*] exists count=2
assert windows[0].close_confirm.items[?status=="在问你"] exists count=1
assert windows[0].close_confirm.items[?status contains "sleep 30"] exists count=1
assert windows[0].close_confirm.items[?status=="等待授权"] !exists
shot   l2-tab1
key    enter
wait   windows[0].close_confirm == null timeout=3s
assert windows[0].tabs[*] exists count=2 && windows[0].tabs[0].panes[*] exists count=2
# --- 红色关闭按钮：窗口里全部三个会话（标准位置的 ⊗，窗口坐标，没有 rect）---
click  20,14
wait   windows[0].close_confirm.action == "window" timeout=5s
assert windows[0].close_confirm.items[*] exists count=3
assert windows[0].close_confirm.items[?status=="等待授权"] exists count=1
assert windows[0].close_confirm.items[?status=="在问你"] exists count=1
shot   l2-window
key    esc
wait   windows[0].close_confirm == null timeout=3s
assert windows[*] exists count=1 && windows[0].tabs[*] exists count=2
```

## judge
- `l2-tab2`：确认条只写一个会话（「… · 等待授权」）；`l2-tab1`：两个会话（「在问你」「执行 …」），没有标签 2 的那个；`l2-window`：三个。
- 红色关闭按钮没有 rect，这里点的是 macOS 标准位置（窗口坐标 `20,14`）。点不中时 `wait … action == "window"` 超时：看 `l2-tab1` 截图里红色按钮的位置，改这一行的坐标；不要改成从截图读（`shot` 后手动点一下也可以，等价于这一步）。
- 取消（`↩` / `Esc`）之后标签、pane、窗口都还在，三个 agent 的状态没变。
