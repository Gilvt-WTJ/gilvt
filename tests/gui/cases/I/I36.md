# I36 Terminal.app 与 iTerm2 精确跳转
requires: manual
checklist: I36
scenarios: []

## steps
```gilvt-steps
# 手动：运行 gilvt integrate install，分别在 Terminal.app 和 iTerm2 中启动一个测试 Agent 并保持运行
# 手动：在 Session Center 的「运行中」和「全部会话」中核对 exact、终端名和 TTY，再按回车跳转
# 手动：确认目标 tab/session 被选中，且 gilvt 没有输入 resume 或启动第二份 Agent
```

## judge
- Session Center「运行中」以及「全部会话」都显示会话为 `exact`、终端名和 TTY。
- 对会话按 `↩` 会激活对应应用并选中匹配 TTY 的 tab/session。
- gilvt 中没有输入 `resume` 命令，也没有启动第二份会话。
