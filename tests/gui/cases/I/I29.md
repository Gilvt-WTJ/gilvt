# I29 归档之后有新 turn：自动取消归档，回到列表和待 Review
requires: sandbox
checklist: I29
scenarios: [hist-claude]

一个刚完成两轮、还没 Review 的会话：`⌘E` 归档后它离开会话列表和「待 Review」。之后 Agent 又完成了两轮（`seed --append`：
同一个会话续写，轮数从 2 变成 4），它自动回到默认列表与「待 Review」，不需要手动取消归档。判定用归档时记下的轮数
（`archived_turns`），所以只改标题之类不增加轮数的写入不会让它回来。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/i29 && cd -P ~/work/i29 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i29"
seed   hist-claude --cwd work/i29 --id c1a0de00-0000-4000-8000-000000002901 --prompt "i29 归档后又有新一轮"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "2901"].unreviewed_count == 2 timeout=15s
key    cmd+4
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=5s
key    cmd+e
wait   windows[0].overlay.banner == "已归档 1 个会话" && windows[0].overlay.items == 0 timeout=3s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" timeout=5s
wait   windows[0].overlay.rows[?session_key contains "2901"] !exists && windows[0].overlay.tabs[?name=="review"].count == 0 timeout=10s
key    esc
wait   windows[0].overlay == null
# 只写标题（不加轮数）：仍然归档
sh     'printf "%s\n" "{\"type\":\"ai-title\",\"aiTitle\":\"i29 新标题\",\"sessionId\":\"c1a0de00-0000-4000-8000-000000002901\"}" >>"$(find .claude -name c1a0de00-0000-4000-8000-000000002901.jsonl)"'
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
# 重扫在打开时开始，约 1 秒内完成
sleep  2s
assert windows[0].overlay.items == 0
key    esc
wait   windows[0].overlay == null
# Agent 又完成了两轮
seed   hist-claude --cwd work/i29 --id c1a0de00-0000-4000-8000-000000002901 --append --prompt "i29 归档之后的新一轮"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 && windows[0].overlay.rows[0].session contains "2901" timeout=15s
assert windows[0].overlay.rows[0].meta contains "4 轮"
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i29-back
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "2901"].unreviewed_count == 4 timeout=15s
assert windows[0].overlay.tabs[?name=="review"].count == 1
sleep  1s
shot   i29-review
key    esc
wait   windows[0].overlay == null
```

## judge
- `i29-back`：会话回到默认列表（「~/work/i29 · 4 轮」），没有「已归档」标记。
- `i29-review`：「待 Review」里有它，写着 4 轮待 Review。
