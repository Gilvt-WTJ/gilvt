# O9 「外观」页：↑↓ 立即切换，停下后只写一次
requires: sandbox
checklist: O9
scenarios: []

在列表里按 `↓` / `↑`：每一步都立刻换主题（不需要 `⏎`）；`config.toml` 只在选择停下约 300 ms 后写入最后那一个。`Esc` 只清空搜索，不还原主题。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="appearance"])'
wait   settings.page == "appearance" timeout=5s
click  'rect(settings.appearance.search_rect)'
type   --window key "gilvt"
# 搜索 gilvt 后前两行固定是 gilvt Light、gilvt Dark（单元测试 searching_gilvt_lists_the_two_defaults_first）
wait   settings.appearance.query == "gilvt" && settings.appearance.selected == "gilvt Light" timeout=5s
assert settings.appearance.rows[1].name == "gilvt Dark"
key    down
wait   theme.name == "gilvt Dark" timeout=3s
key    up
wait   theme.name == "gilvt Light" timeout=3s
key    down
wait   theme.name == "gilvt Dark" timeout=3s
sleep  1s
sh     "grep -qx 'theme = \"gilvt Dark\"' .config/gilvt/config.toml"
# Esc 清空搜索，主题不变
key    esc
wait   settings.appearance.query == "" timeout=3s
assert theme.name == "gilvt Dark"
assert settings.appearance.fixed == "gilvt Dark"
key    cmd+w
wait   settings !exists timeout=5s
restart --set 'theme="light"'
```

## judge
- 无截图：全部由状态断言判定。这里只看最后写入的是 `theme = "gilvt Dark"`；「停下后只写一次、中间的选择不写」由单元测试 `config_file::tests::a_chosen_theme_applies_at_once_and_is_written_once_stable` 证明（GUI 看不到中间的写入）。
