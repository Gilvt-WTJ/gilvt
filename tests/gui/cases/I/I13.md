# I13 就地恢复不清空已敲的字符
requires: sandbox
checklist: I13
scenarios: [hist-claude]

已确认接受的行为：命令行上已经敲了但没回车的字符不会被清掉，会与恢复命令连在一起。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i13 --age 1h --id c1a0de00-0000-4000-8000-000000001301 --prompt "i13 会话"
type   "cd -P ~/work/i13 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i13"
type   "echo 已敲"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$ echo 已敲"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$ echo 已敲cd " timeout=5s
shot   i13
```

## judge
- 命令行是 `echo 已敲cd <会话目录> && claude --resume c1a0de00-…1301`：已敲的 `echo 已敲` 保留，恢复命令直接接在后面（断言）。
  因为前半段是 `echo`，这里会先打印一行再恢复会话；换成其他字符时 shell 报错，需要手动清掉重来——两者都符合清单。
