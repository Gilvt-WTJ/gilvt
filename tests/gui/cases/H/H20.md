# H20 时间线最新在上（一轮结束后的顺序）
requires: sandbox
checklist: H20
scenarios: [timeline]

当前轮的事件按「最新在上」排列：最后发生的在标题正下方，最早的在最底部。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h20 && cd -P ~/work/h20 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h20"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h20-all
assert windows[0].inspector.rows[0].kind == "title"
assert windows[0].inspector.rows[1].label == "Bash echo late"
assert windows[0].inspector.rows[2].label == "Bash cargo test"
assert windows[0].inspector.rows[3].label == "Bash echo early"
assert windows[0].inspector.rows[4].label contains "Write hello.txt"
assert windows[0].inspector.rows[5].label contains "Update README.md"
```

## judge
- `h20-all`：标题「时间线 · 第 1 轮」正下方是 `Bash echo late`，向下依次是 `cargo test`（红色 ✗，错误摘录在它下面）、`echo early`、`Write hello.txt`、
  `Update README.md`；`Read README.md` 与思考行在最底部（两者的先后沿用事件记录里的顺序，不属于本用例）。
