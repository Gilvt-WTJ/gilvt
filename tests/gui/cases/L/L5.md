# L5 已 Review，下一个（⌘↩）
requires: sandbox
checklist: L5
scenarios: [hist-claude]

两个待 Review 的会话。`Space` 打开第一个，`⌘↩` 把它标记为已 Review 并打开下一个；再按一次后队列清空，Review 关闭、显示空状态。
整个过程中快捷键不会漏进终端：回到终端后输入 `echo` 正常。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l5 && cd -P ~/work/l5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l5"
seed   hist-claude --cwd work/l5 --id c1a0de00-0000-4000-8000-0000000b0501 --prompt "l5 甲"
seed   hist-claude --cwd work/l5 --id c1a0de00-0000-4000-8000-0000000b0502 --prompt "l5 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
assert windows[0].overlay.rows[0].session_key contains "0b0501" && windows[0].overlay.rows[1].session_key contains "0b0502"
key    space
wait   windows[0].overlay.session_review.session_key contains "0b0501" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.actions.review_next.enabled == true && windows[0].overlay.session_review.notice == null
key    cmd+enter
wait   windows[0].overlay.rows[?session_key contains "0b0501"] !exists && windows[0].overlay.session_review.session_key contains "0b0502" timeout=10s
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.tabs[?name=="review"].count == 1 && windows[0].overlay.store_pending_count == 1 && windows[0].overlay.session_review.notice == null
shot   l5-next
key    cmd+enter
wait   windows[0].overlay.session_review == null && windows[0].overlay.rows[0] !exists timeout=10s
assert windows[0].overlay.tabs[?name=="review"].count == 0 && windows[0].overlay.store_pending_count == 0 && windows[0].overlay.store_last_error == null
shot   l5-empty
key    esc
wait   windows[0].overlay == null
type   "echo l5-done\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "l5-done" timeout=5s
```

## judge
- `l5-next`：第一个会话已经不在左侧队列里，右侧显示的是第二个会话的 Review。
- `l5-empty`：队列空了，显示「已全部 Review，没有待处理的结果」。
- 终端输入行没有多出 `s` / `z` / `p` 之类的残留字符。
