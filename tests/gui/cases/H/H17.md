# H17 会话结束后状态卡与时间线
requires: sandbox
checklist: H17
scenarios: [default]

会话结束（`/exit`，或连按两次 Ctrl-C 退出进程）后仍聚焦该 pane：状态卡变为「已结束」，时间线保留最后内容，不再更新。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h17 && cd -P ~/work/h17 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h17"
type   "claude @scenario:default h17 一轮就结束\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: h17 一轮就结束" timeout=15s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].inspector.card.status == "ended" timeout=10s
assert windows[0].inspector.timeline_rows != 0
shot   h17-ended
type   "echo 结束之后的输出\n"
sleep  1s
assert windows[0].inspector.card.status == "ended" && windows[0].inspector.timeline_rows != 0
shot   h17-still
type   "clear && claude @scenario:default h17 第二次\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: h17 第二次" timeout=15s
key    ctrl+c ctrl+c
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].inspector.card.status == "ended" timeout=10s
shot   h17-ctrl-c
```

## judge
- `h17-ended` 与 `h17-still` 的时间线一模一样（shell 里的新输出没有进入时间线），状态卡为「已结束」。
- `h17-ctrl-c`：进程退出的情况同样是「已结束」，时间线停在「OK: h17 第二次」这一轮。
