# M1 左栏 git 行：分支、dirty、ahead / behind，随仓库变化
requires: sandbox
checklist: M1
scenarios: [default]

会话的目录在 git 仓库里时，左栏行多一行 `⎇ <分支> ●<改动数> ↑<领先>↓<落后>`（`rows[].git`：`line` 是画出的文字，`branch` / `dirty` / `ahead` / `behind` 是原始值）。
仓库变化后约 10 秒内刷新。用一个带上游的仓库：新增文件（dirty）、提交一次（ahead）、另一个克隆推送后 fetch（behind）、换分支。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'git init -q --bare ~/work/k1-origin.git && git init -q -b main ~/work/k1 && cd ~/work/k1 && git config user.email t@t && git config user.name t && git remote add origin ~/work/k1-origin.git && git commit -q --allow-empty -m init && git push -q -u origin main'
type   "cd -P ~/work/k1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k1"
type   "claude @scenario:default k1 看分支\n"
wait   windows[0].sidebar.rows[?section=="project:k1"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
# 干净的仓库：只有分支名
wait   windows[0].sidebar.rows[?section=="project:k1"].git.line == "⎇ main" timeout=20s
assert windows[0].sidebar.rows[?section=="project:k1"].git.branch == "main"
assert windows[0].sidebar.rows[?section=="project:k1"].git.dirty == 0
assert windows[0].sidebar.rows[?section=="project:k1"].git.ahead == 0
assert windows[0].sidebar.rows[?section=="project:k1"].git.behind == 0
assert windows[0].sidebar.rows[?section=="project:k1"].git.linked_worktree == false
assert windows[0].sidebar.rows[?section=="project:k1"].git.repo == "k1"
shot   k1-clean
# 两个未跟踪文件：●2
sh     'cd ~/work/k1 && echo a > a.txt && echo b > b.txt'
wait   windows[0].sidebar.rows[?section=="project:k1"].git.dirty == 2 && windows[0].sidebar.rows[?section=="project:k1"].git.line == "⎇ main ●2" timeout=20s
shot   k1-dirty
# 提交其中一个：领先 1，还剩 1 个改动
sh     'cd ~/work/k1 && git add a.txt && git commit -q -m a'
wait   windows[0].sidebar.rows[?section=="project:k1"].git.ahead == 1 && windows[0].sidebar.rows[?section=="project:k1"].git.dirty == 1 timeout=20s
assert windows[0].sidebar.rows[?section=="project:k1"].git.line == "⎇ main ●1 ↑1↓0"
# 另一个克隆推送一个提交，这里 fetch 之后落后 1
sh     'git clone -q ~/work/k1-origin.git ~/work/k1-other && cd ~/work/k1-other && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m other && git push -q origin main && cd ~/work/k1 && git fetch -q'
wait   windows[0].sidebar.rows[?section=="project:k1"].git.behind == 1 && windows[0].sidebar.rows[?section=="project:k1"].git.ahead == 1 timeout=20s
assert windows[0].sidebar.rows[?section=="project:k1"].git.line == "⎇ main ●1 ↑1↓1"
shot   k1-ahead-behind
# 换分支
sh     'cd ~/work/k1 && git checkout -q -b feat-k1'
wait   windows[0].sidebar.rows[?section=="project:k1"].git.branch == "feat-k1" timeout=20s
assert windows[0].sidebar.rows[?section=="project:k1"].git.detached == null
assert windows[0].sidebar.rows[?section=="project:k1"].git.line contains "⎇ feat-k1"
# detached HEAD：分支为 null，显示短提交
sh     'cd ~/work/k1 && git checkout -q --detach'
wait   windows[0].sidebar.rows[?section=="project:k1"].git.branch == null && windows[0].sidebar.rows[?section=="project:k1"].git.detached != null timeout=20s
shot   k1-detached
```

## judge
- `k1-clean`：会话行第二行是状态，其下一行小字 `⎇ main`，没有 `●`、`↑↓`。`k1-dirty`：`⎇ main ●2`。`k1-ahead-behind`：`⎇ main ●1 ↑1↓1`。`k1-detached`：`⎇ <7 位短提交>`。
- 每次变化后都在 `timeout=20s` 内变过来（约 10 秒一次的刷新，`rows[].git` 的值按 `GIT_POLLS` 轮询；执行中的会话已有值时不刷新，本用例的会话是空闲的）。
- `git.line` 与行上实际画出的文字一致（对照截图）。
