# I23 每个会话开始等待时 Dock 图标跳一次
requires: sandbox
checklist: I23
scenarios: [ask-question]
parallel: serial

gilvt 在后台时，每个会话开始等待时跳一次，持续等待不重复跳；gilvt 在前台时不跳。先 `restart` 把 `dock_bounces` 清零
（`restart` 用 `open -g` 启动，gilvt 不会来到前台）。只断言 `dock_bounces`，不截 Dock。

## steps
```gilvt-steps
restart
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert dock_bounces == 0 && front == false
type   "mkdir -p ~/work/i23 && cd -P ~/work/i23 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 timeout=15s
wait   dock_bounces == 1 timeout=5s
sleep  3s
assert dock_bounces == 1
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "cd -P ~/work/i23 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=2 timeout=15s
wait   dock_bounces == 2 timeout=5s
sleep  3s
assert dock_bounces == 2
# gilvt 在前台时不跳：点一下当前 pane 把 gilvt 带到前台
click  pane(focused)
wait   front == true timeout=5s
key    cmd+t
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/i23 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=3 timeout=15s
sleep  2s
assert dock_bounces == 2
```

## judge
- 全部是状态断言。`front == false` 在开头不成立时（用户正好切到了 gilvt），请用户切回别的应用后重跑。
- 点击是唯一的前台动作；锁屏时它退出 5，最后一段记为 ⏭。
