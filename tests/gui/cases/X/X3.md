# X3 普通命令运行时点击不发方向键
requires: sandbox
checklist: X3
scenarios: []

`cat` 在规范模式（cooked）的 tty 上读输入，方向键只会被回显成 `^[[D`。gilvt 只在前台程序以 raw 模式读键（shell 的行编辑器、
Claude Code、Codex、vim）时才把点击换成方向键，所以这里点击输入的字左边，屏幕上不出现 `^[`，光标也不动。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "clear && cat\n"
wait   windows[0].tabs[0].panes[0].foreground == "other:cat" timeout=5s
type   "cccccccccc"
wait   windows[0].tabs[0].panes[0].screen_tail[*] == "cccccccccc" && windows[0].tabs[0].panes[0].cursor.col == 10 timeout=5s
click  'rect(windows[0].tabs[0].panes[0].cursor)+(-40,0)'
sleep  0.5s
shot   x3-cat
assert windows[0].tabs[0].panes[0].cursor.col == 10 && windows[0].tabs[0].panes[0].screen_tail[*] contains "^[" count=0
key    ctrl+c
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=5s
```

## judge
- `x3-cat`：`cat` 的输入行只有那串 `c`，没有 `^[[D`，光标在行尾。
