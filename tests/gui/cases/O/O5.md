# O5 用户主题优先于内置
requires: sandbox
checklist: O5
scenarios: []

## steps
```gilvt-steps
sh     "mkdir -p .config/gilvt/themes && printf '%s\n' 'background = #102030' 'foreground = #e0e0e0' > .config/gilvt/themes/Dracula"
restart --set 'theme="Dracula"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "Dracula"
assert theme.source == "user"
shot   o5
sh     "rm -rf .config/gilvt/themes"
restart --set 'theme="light"'
```

## judge
- `o5`：终端背景是深蓝（#102030），不是 Dracula 内置的紫灰。
