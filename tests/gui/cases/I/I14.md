# I14 ⌘⇧N 新建 Agent 面板的默认值与预览
requires: sandbox
checklist: I14
scenarios: [default]

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i14 && cd -P ~/work/i14 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i14"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.agent == "claude" && windows[0].overlay.dir contains "work/i14" && windows[0].overlay.task == "" timeout=5s
# 空闲判定由前台探测驱动，刚 clear 过的 pane 要等一次探测才算空闲
wait   windows[0].overlay.preview.head == "将在当前 pane执行：" && windows[0].overlay.preview.missing == false timeout=5s
assert windows[0].overlay.preview.command contains "work/i14 && claude"
shot   i14-panel
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
assert windows[0].tabs[0].panes[0].screen_tail[*] contains "work/i14 && claude"
shot   i14-ran
```

## judge
- `i14-panel`：标题「新建 Agent」；Agent 为 Claude；目录框是焦点 pane 的 cwd，旁注「当前 pane 的目录」（`~/work/i14` 不是
  git 仓库；在仓库根目录时为「当前 pane 的项目」）；光标在「初始任务」；预览「将在当前 pane执行：cd … && claude」。
- `i14-ran`：shell 里实际输入的命令与 `i14-panel` 的预览逐字一致（对照两张截图）。
- 沙盒里 pane 的 cwd 是物理路径（`cd -P`，见 README），所以目录框可能显示 `/private/var/…/home/work/i14` 而不是 `~/work/i14`；
  这是测试环境的路径形式，不算失败。
