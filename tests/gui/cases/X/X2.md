# X2 拖选、点击别的行不移动光标
requires: sandbox
checklist: X2
scenarios: []

点击只在「按下与松开在同一格」时移动光标：在输入行上拖动是选择文字，光标不动；点击光标所在逻辑行以外的行（上面的输出）也不动。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "clear && echo x2-output\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] == "x2-output" timeout=5s
type   "echo bbbbbbbbbbbbbbbbbbbb"
wait   windows[0].tabs[0].panes[0].cursor.col == 34 && windows[0].tabs[0].panes[0].cursor.row == 1 timeout=5s
drag   'rect(windows[0].tabs[0].panes[0].cursor)+(-80,0)' 'rect(windows[0].tabs[0].panes[0].cursor)+(-30,0)'
sleep  0.5s
assert windows[0].tabs[0].panes[0].cursor.col == 34
shot   x2-dragged
# 上一行（x2-output）不是光标所在的逻辑行
click  'rect(windows[0].tabs[0].panes[0].cursor)+(-200,-16)'
sleep  0.5s
assert windows[0].tabs[0].panes[0].cursor.col == 34 && windows[0].tabs[0].panes[0].cursor.row == 1
type   "Y"
key    enter
wait   windows[0].tabs[0].panes[0].screen_tail[*] == "bbbbbbbbbbbbbbbbbbbbY" timeout=5s
```

## judge
- `x2-dragged`：拖过的几个 `b` 是选中的高亮，光标仍在行尾。
