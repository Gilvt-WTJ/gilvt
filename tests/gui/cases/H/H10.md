# H10 失败命令：红色 ✗、exit N 与报错摘录
requires: sandbox
checklist: H10
scenarios: [timeline]

`timeline` 里的 `cargo test` 以 101 退出，输出 9 行，其中 3 行含 `Error` / `FAIL`；摘录应选这 3 行，而不是最后 3 行。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h10 && cd -P ~/work/h10 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h10"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h10
```

## judge
- `cargo test` 行显示红色 ✗ 与 `exit 101`。
- 行下方正好 3 行摘录，依次为（gilvt-fake-agent 的 `timeline_has_edits_…` 测试钉住了这个结果）：
  `Error: cannot find value `greeting` in this scope`、`test tests::greets ... FAILED`、
  `test result: FAILED. 1 passed; 1 failed; 0 ignored`——不是最后三行（`… FAILED` / `test result …` / `Finished in 0.02s`）。
- 其余成功的行没有摘录。
