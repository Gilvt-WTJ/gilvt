# O6 [colors] 单项覆盖
requires: sandbox
checklist: O6
scenarios: []

深色基础主题（`theme = "dark"`）上覆盖一个深色背景，文字仍是 gilvt Dark 的浅色前景，清晰可读。

## steps
```gilvt-steps
restart --set 'theme="dark"' --set 'colors.background="#202040"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "gilvt Dark"
assert theme.colors_overrides == 1
shot   o6
# 清理：删掉 [colors] 表头和那一行，不留覆盖（--set 追加的表里只有这一行）
sh     "sed -i '' -e '/\[colors\]/d' -e '/^background = \"#202040\"/d' .config/gilvt/config.toml"
sh     "! grep -q colors .config/gilvt/config.toml"
restart --set 'theme="light"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.colors_overrides == 0
```

## judge
- `o6`：终端背景为深蓝紫（#202040），文字是浅色、清晰可读；外框随之变为同色调深色（覆盖了背景后外框改为推导）。
