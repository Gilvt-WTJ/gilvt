# Q6 悬停 agent 行约 0.5 秒出现完整内容的提示，移开消失
requires: sandbox
checklist: Q6
scenarios: [long-title]

悬停在 agent 行上，`sidebar.tooltip.text` 含会话名（数据层已限制在 40 个字符内）、状态（工具标签由上游缩短）、位置和完整 cwd；鼠标移开后 `tooltip` 为 `null`。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q6 && cd -P ~/work/q6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q6"
type   "claude @scenario:long-title\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists timeout=15s
assert windows[0].sidebar.tooltip == null
hover  'rect(windows[0].sidebar.rows[?kind=="agent"])'
wait   windows[0].sidebar.tooltip.text contains "Add terminal rows to the sidebar and kee" timeout=5s
assert windows[0].sidebar.tooltip.text contains "cargo test -p gilvt-app"
assert windows[0].sidebar.tooltip.text contains "/work/q6"
shot   q6
hover  'pane(focused)'
wait   windows[0].sidebar.tooltip == null timeout=5s
```

## judge
- `q6`：行旁边（或下方）有一块提示，逐行写着会话名（至多 40 个字符，数据层已截断）、状态（含 cargo 命令，工具标签由上游缩短）、位置、完整目录路径；提示没有越出窗口。
