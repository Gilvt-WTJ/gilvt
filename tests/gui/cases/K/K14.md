# K14 汇总行展开成本会话净改动，Quick Look 标签为「本会话」
requires: sandbox
checklist: K14
scenarios: [artifacts-followups]

点开顶部汇总行，再对净改动里的文件按 Space。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k14 && cd work/k14 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k14 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k14"
type   "claude @scenario:artifacts-followups\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].turns[*] exists count=3 && windows[0].inspector.artifacts.cards[0].computing == false && windows[0].inspector.artifacts.summary.computing == false timeout=60s
click  'rect(windows[0].inspector.artifacts.net.rect)'
wait   windows[0].inspector.artifacts.net.open == true && windows[0].inspector.artifacts.net.files[*] exists count=2 timeout=10s
assert windows[0].inspector.artifacts.net.excluded == 0
assert windows[0].inspector.artifacts.net.range_label contains "第 1 轮前 → "
click  'rect(windows[0].inspector.artifacts.net.files[0].rect)'
wait   windows[0].inspector.artifacts.net.files[0].selected == true timeout=5s
key    space
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.base == "本会话（第 1 轮前 → 第 3 轮后）" timeout=10s
shot   k14-session-net
```

## judge
- `k14-session-net`：Quick Look 头部写着「本会话（第 1 轮前 → 第 3 轮后）」，diff 内容是整个会话的净差异（不是某一轮的）。
