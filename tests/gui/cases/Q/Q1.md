# Q1 空闲 shell 在侧栏里显示为终端行
requires: sandbox
checklist: Q1
scenarios: []

沙盒启动后只有一个空闲 shell pane。`cd ~/work/q1` 后侧栏出现一行终端行，头部写「会话 · 0 · 终端 1」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q1 && cd -P ~/work/q1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q1"
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=1 timeout=10s
assert windows[0].sidebar.rows[?kind=="terminal"].status == "terminal"
assert windows[0].sidebar.rows[?kind=="terminal"].cwd contains "/work/q1"
assert windows[0].sidebar.rows[?kind=="terminal"].section == "project:q1"
assert windows[0].sidebar.rows[?kind=="terminal"].session == ""
assert windows[0].sidebar.terminals == 1
assert windows[0].sidebar.header == "会话 · 0 · 终端 1"
shot   q1
```

## judge
- `q1`：左栏一行灰色 `>_` 方块、标题常规字重（不是粗体）、没有状态行、没有进度条、没有时间；头部「会话 · 0 · 终端 1」；没有「还没有会话」。
