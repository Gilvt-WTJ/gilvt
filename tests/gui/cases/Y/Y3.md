# Y3 另一个窗口的会话也出现
requires: sandbox
checklist: Y3
scenarios: [long-tool]

第二个窗口里运行的会话也出现在第一个窗口监控官的「运行中」分组，位置写「窗口 2」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# 先把 gilvt 带到前台，⌘N 的新窗口才会成为 key window
click  pane(focused)
wait   front == true timeout=5s
key    cmd+shift+o
wait   windows[0].monitor.groups[?name=="terminals"] exists timeout=10s
key    cmd+n
wait   windows[*] exists count=2 && windows[?key==true].tabs[0].panes[0].foreground == "shell" && windows[?key==true].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   --window key "claude @scenario:long-tool\n"
wait   windows[?key==true].sidebar.rows[?status=="running_tool"] exists count=1 timeout=15s
# 回到窗口 1（session.env 记录的窗口）：用辅助功能提窗口，不点 pane
raise
wait   windows[?key==true].monitor.cards[?group=="running"] exists count=1 timeout=10s
assert windows[?key==true].monitor.cards[?group=="running"].kind == "agent"
shot   y3
```

## judge
- `y3`：第一个窗口的监控官里有一张「运行中」agent 卡片，卡片上的位置写「窗口 2」（位置文字不在 debug state 里，靠截图确认）。
