# I8 复制会话 ID 与在访达中显示
requires: sandbox
checklist: I8
scenarios: [hist-claude]

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i8 --age 1h --id c1a0de00-0000-4000-8000-000000000801 --prompt "i8 复制它的 ID"
type   "cd -P ~/work/i8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i8"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+shift+c
clipboard == c1a0de00-0000-4000-8000-000000000801
shot   i8-copied
sh     "printf 'i8-cleared' | pbcopy"
# 「已复制会话 ID」横幅 4 秒后消失，列表随之上移一行高：等它消失再点，否则点到一半行就挪走了
wait   windows[0].overlay.banner == null timeout=6s
shot   i8-row
rclick 'rect(windows[0].overlay.rows[?title contains "i8 复制它的 ID"])'
wait   windows[0].context_menu.items[*].label == "复制会话 ID" && windows[0].context_menu.items[*].label == "在访达中显示" timeout=3s
click  'menu("复制会话 ID")'
clipboard == c1a0de00-0000-4000-8000-000000000801
wait   windows[0].overlay.banner == null timeout=6s
rclick 'rect(windows[0].overlay.rows[?title contains "i8 复制它的 ID"])'
wait   windows[0].context_menu.items[*].label == "在访达中显示" timeout=3s
click  'menu("在访达中显示")'
sleep  2s
```

## judge
- `i8-copied`：出现「已复制会话 ID」提示；剪贴板由断言核对（两种方式都是会话 ID）。
- 访达（系统界面，只读核对）：新开的访达窗口位于沙盒的 `…/home/.claude/projects/<项目目录>/`，选中
  `c1a0de00-0000-4000-8000-000000000801.jsonl`。用 `peekaboo see --app Finder --json --no-screenshot` 读取窗口标题与选中项，
  不截全屏；核对后可以关掉这个访达窗口（报告里注明）。
- 这个用例会覆盖用户的剪贴板（报告里注明）。
