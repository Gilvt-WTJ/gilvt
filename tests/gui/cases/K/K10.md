# K10 文件在这一轮之后又被改动
requires: sandbox
checklist: K10
scenarios: [artifacts-basic]

轮结束后改写磁盘上的 `hello.txt` 再打开：内容仍是这一轮的版本。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k10 && cd work/k10 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k10 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k10"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=30s
sh     "printf 'edited by hand\n' > work/k10/hello.txt"
click  'rect(windows[0].inspector.artifacts.cards[0].files[?path=="hello.txt"])'
wait   windows[0].inspector.artifacts.cards[0].files[?path=="hello.txt"].selected == true timeout=5s
key    space
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "hello.txt" timeout=10s
assert windows[0].overlay.changed_since == true
shot   k10-changed-since
```

## judge
- `k10-changed-since` 头部有「文件在这一轮之后又被改动」，正文仍是 `hello`（这一轮的版本），不是 `edited by hand`。
