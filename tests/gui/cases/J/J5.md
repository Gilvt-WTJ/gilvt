# J5 渲染后的 Markdown 跨块拖选并 ⌘C
requires: sandbox
checklist: J5
scenarios: []

Markdown 文件默认是渲染视图；从标题拖到最后一个列表项，选区文字是各块的文字（每个块一行，不含列表符号和 Markdown 标记），`⌘C` 复制。会覆盖用户的剪贴板。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j5 && cd work/j5 && git init -q && printf '# Title here\n\nFirst paragraph of text.\n\nSecond paragraph of text.\n\n- item one\n- item two\n\n~~~\ncode line 1\ncode line 2\n~~~\n' > note.md"
type   "cd -P ~/work/j5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j5"
type   "gilvt view note.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.mode == "rendered" && windows[0].overlay.code exists timeout=10s
# rect(…) 是矩形的中心，偏移加在中心上。文档区 (265,107,670,524)，中心 (600,369)；标题在 y≈151，段落 y≈186 / 216，列表项 y≈247 / 271，代码块两行 y≈315 / 335；正文从 x≈305 开始
assert windows[0].overlay.selection == null
drag   'rect(windows[0].overlay.code)+(-300,-218)' 'rect(windows[0].overlay.code)+(-40,-98)'
wait   windows[0].overlay.selection == "Title here\nFirst paragraph of text.\nSecond paragraph of text.\nitem one\nitem two" timeout=5s
shot   j5-selected
key    cmd+c
clipboard contains "First paragraph of text."
clipboard contains "item two"
```

## judge
- `j5-selected`：标题、两个段落、两个列表项的文字有选区高亮，代码块没有。
- 点是 `overlay.code` 中心加偏移（窗口 1280×648）；行位置对不上、选中的块不对时，按截图里的实际位置调整偏移后重跑。
- 会覆盖用户的剪贴板（报告里注明）。
