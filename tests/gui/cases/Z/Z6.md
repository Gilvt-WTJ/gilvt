# Z6 在移出来的标签里再按 ⌘⇧T，pane 回到原来的分屏位置
requires: sandbox
checklist: Z6
scenarios: []

分屏 `1 | (2 / 3)`，把右上的 pane 2 移到新标签再移回来：新标签消失，回到原标签，pane 2 仍在右上（第二个、和 3 上下排列），焦点在它上面。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].screen_tail[*] contains "sandbox$" timeout=10s
type   "clear && echo Z6-MARK\n"
wait   windows[0].tabs[0].panes[1].screen_tail[*] contains "Z6-MARK"
key    cmd+shift+d
wait   windows[0].tabs[0].panes[*] exists count=3 && windows[0].tabs[0].panes[2].focused == true timeout=10s
key    cmd+alt+up
wait   windows[0].tabs[0].panes[1].focused == true
key    cmd+shift+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].screen_tail[*] contains "Z6-MARK" timeout=5s
assert windows[0].tabs[0].panes[*] exists count=2
key    cmd+shift+t
wait   windows[0].tabs[*] exists count=1 && windows[0].tabs[0].active == true timeout=5s
assert windows[0].tabs[0].panes[*] exists count=3
assert windows[0].tabs[0].panes[1].screen_tail[*] contains "Z6-MARK" && windows[0].tabs[0].panes[1].focused == true
assert windows[0].layout.tabs[0].tree.type == "split" && windows[0].layout.tabs[0].tree.axis == "row"
assert windows[0].layout.tabs[0].tree.children[1].type == "split" && windows[0].layout.tabs[0].tree.children[1].axis == "column"
```
