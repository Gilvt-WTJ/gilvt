# V3 内置编辑器：未保存保护与外部修改
requires: sandbox
checklist: V3
scenarios: [default]

有未保存修改时 `⌘W` 不静默关闭：编辑 pane 顶部出现「要保存对 SKILL.md 的修改吗？」横条（取消 / 不保存 / 保存 ⏎），`Esc` = 取消；
关掉文件标签（`⌘⇧W`）弹窗口级确认条，`⌘↩`「不保存并关闭」后磁盘文件不变。编辑中文件被外部改写：不用等 `⌘S`，监听器立即弹出横条
「⚠ 文件已在磁盘上被修改，而你有未保存的改动。」（重新载入 / 对比 / 仍然覆盖），`⌘S` 仍被拦下，`Esc` 收起后磁盘仍是外部版本；
有未保存内容时 `⌘Q` 的确认条列出**文件名**，`Esc` 取消、gilvt 不退出；最后 `⌘S` 让横条回来，点「仍然覆盖」，磁盘变成编辑版本。
外部修改的其余按钮（重新载入、对比、删除横条）见 V5、V6。

默认字号（13）下终端区约 92 列，「编辑」开新文件标签（见 V2），关标签的确认条因此只涉及这一个编辑 pane。

横条按钮现在有 rect（`editors[].bar_buttons[].rect`，E2b-1），「仍然覆盖」用它点。
- pane 内关闭横条的「不保存」：本用例仍用窗口级确认条的 `⌘↩`「不保存并关闭」覆盖「丢弃修改、磁盘不变」，没有点 pane 内的按钮
  （需要时可以点 `rect(windows[0].editors[0].bar_buttons[?label=="不保存"].rect)`）。
- 横条上的「取消」（关闭横条）和收起外部修改横条都用 `Esc`（与按钮同一个动作）。
- 「仍然覆盖」放在 `⌘Q` 那一步**之后**：覆盖后缓冲区已保存，若在它之后按 `⌘Q`，没有任何未保存内容和执行中的 agent，gilvt 会直接退出。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/v3/.git work/v3/.claude/skills/code-review"
sh     "printf -- '---\nname: code-review\ndescription: Review a diff for bugs\n---\n# Code review\n\nbody\n' > work/v3/.claude/skills/code-review/SKILL.md && cp work/v3/.claude/skills/code-review/SKILL.md work/v3/SKILL.orig"
type   "cd -P ~/work/v3 && clear && claude @scenario:default v3 protect\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" && windows[0].inspector.card.status == "idle" timeout=20s
key    cmd+alt+3
wait   windows[0].inspector.tab == "config" && windows[0].inspector.config.loading == false && windows[0].inspector.config.skills == 1 timeout=10s
click  'rect(windows[0].inspector.config.group_rects[0])'
wait   windows[0].inspector.config.dialog.group == "skills" && windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect != null timeout=5s
hover  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].rect)'
click  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect)'
wait   windows[0].editors[0].path contains "/work/v3/.claude/skills/code-review/SKILL.md" && windows[0].tabs[*] exists count=2 && windows[0].tabs[1].panes[0].focused == true timeout=5s
key    cmd+up
type   "v3 "
wait   windows[0].editors[0].dirty == true && windows[0].editors[0].cursor.col == 4 timeout=5s
# 1. ⌘W 有未保存修改：pane 内横条，Esc = 取消，pane 和修改都还在
key    cmd+w
wait   windows[0].editors[0].bar == "close" timeout=5s
assert windows[0].editors[*] exists count=1 && windows[0].tabs[*] exists count=2 && windows[0].close_confirm == null
shot   v3-close-bar
key    esc
wait   windows[0].editors[0].bar == "none" timeout=5s
assert windows[0].editors[0].dirty == true && windows[0].editors[*] exists count=1 && windows[0].tabs[1].panes[0].kind == "editor"
sh     "cmp work/v3/SKILL.orig work/v3/.claude/skills/code-review/SKILL.md"
# 2. 关标签：窗口级确认条列出文件名；⌘↩「不保存并关闭」→ 标签关掉、回到来源标签，磁盘文件不变
key    cmd+shift+w
wait   windows[0].close_confirm.action == "tab" && windows[0].close_confirm.dirty[*] == "SKILL.md" timeout=5s
assert windows[0].close_confirm.dirty[*] exists count=1
key    cmd+enter
wait   windows[0].close_confirm == null && windows[0].editors[*] !exists && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].active == true timeout=5s
sh     "cmp work/v3/SKILL.orig work/v3/.claude/skills/code-review/SKILL.md"
# 3. 外部修改：编辑中用 sh 改写磁盘文件 → 监听器不等 ⌘S 就弹出横条（重新载入 / 对比 / 仍然覆盖）；⌘S 仍被拦下；
#    Esc 收起，磁盘仍是外部版本，缓冲区仍未保存
wait   windows[0].tabs[0].panes[0].focused == true && windows[0].inspector.config.loading == false && windows[0].inspector.config.skills == 1 timeout=10s
click  'rect(windows[0].inspector.config.group_rects[0])'
wait   windows[0].inspector.config.dialog.group == "skills" && windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect != null timeout=5s
hover  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].rect)'
click  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect)'
wait   windows[0].editors[0].path contains "/code-review/SKILL.md" && windows[0].tabs[1].panes[0].focused == true timeout=5s
key    cmd+up
type   "mine "
wait   windows[0].editors[0].dirty == true && windows[0].editors[0].cursor.col == 6 timeout=5s
sh     "printf 'external version\n' > work/v3/.claude/skills/code-review/SKILL.md"
wait   windows[0].editors[0].bar == "modified" timeout=10s
assert windows[0].editors[0].dirty == true && windows[0].editors[0].bar_buttons[*] exists count=3 && windows[0].editors[0].bar_buttons[0].label == "重新载入" && windows[0].editors[0].bar_buttons[1].label == "对比" && windows[0].editors[0].bar_buttons[2].label == "仍然覆盖"
key    cmd+s
# 注意：横条在 ⌘S 之前就已由监听器弹出，这个 wait 本身证明不了 ⌘S 被拦下；真正的检查是下面的磁盘断言（仍是外部版本）
wait   windows[0].editors[0].bar == "modified" timeout=5s

sh     'test "$(cat work/v3/.claude/skills/code-review/SKILL.md)" = "external version"'

assert windows[0].editors[0].dirty == true && windows[0].editors[*] exists count=1
sh     'test "$(cat work/v3/.claude/skills/code-review/SKILL.md)" = "external version"'
# 4. ⌘Q 有未保存内容：确认条只列文件名（不含目录）；Esc 取消，gilvt 不退出
key    cmd+q
wait   windows[0].close_confirm.action == "quit" && windows[0].close_confirm.dirty[*] == "SKILL.md" timeout=5s
assert windows[0].close_confirm.dirty[*] exists count=1 && windows[0].close_confirm.items[*] !exists
shot   v3-quit
key    esc
wait   windows[0].close_confirm == null timeout=5s
assert windows[0].editors[*] exists count=1 && windows[0].editors[0].dirty == true && windows[0].tabs[0].panes[0].foreground == "agent:claude"
# 5. 「仍然覆盖」（在 ⌘Q 之后，见说明）：⌘S 让横条回来（Esc 只是收起），点「仍然覆盖」→ 磁盘 = 编辑版本（「mine 」+ 原内容），已保存
wait   windows[0].tabs[1].panes[0].focused == true timeout=5s
key    cmd+s
wait   windows[0].editors[0].bar == "modified" timeout=5s
sh     'test "$(cat work/v3/.claude/skills/code-review/SKILL.md)" = "external version"'
click  'rect(windows[0].editors[0].bar_buttons[?label=="仍然覆盖"].rect)'
wait   windows[0].editors[0].bar == "none" && windows[0].editors[0].dirty == false timeout=5s
sh     "printf 'mine ' | cat - work/v3/SKILL.orig | cmp - work/v3/.claude/skills/code-review/SKILL.md"
# 收尾：缓冲区已保存，⌘⇧W 直接关掉文件标签（没有确认条），下一个用例从干净的窗口开始
key    cmd+shift+w
wait   windows[0].close_confirm == null && windows[0].editors[*] !exists && windows[0].tabs[*] exists count=1 timeout=5s
sh     "printf 'mine ' | cat - work/v3/SKILL.orig | cmp - work/v3/.claude/skills/code-review/SKILL.md"
```

## judge
- `v3-close-bar`：编辑 pane 顶部（头部下面）一条黄色横条「要保存对 SKILL.md 的修改吗？」，按钮依次「取消」「不保存」「保存 ⏎」，
  「保存 ⏎」是默认（强调）样式；文本区仍可见。
- `v3-modified-bar`：横条「⚠ 文件已在磁盘上被修改，而你有未保存的改动。」，按钮从左到右「重新载入」「对比」「仍然覆盖」，「对比」是默认样式；
  头部仍显示 ●；文本区是编辑中的内容（第 1 行以 `mine ` 开头），不是外部版本。
- `v3-quit`：窗口级确认条列出 `● SKILL.md`（只有文件名），按钮「取消」「不保存并关闭」「全部保存并关闭」，「全部保存并关闭」是默认；
  没有列出 Agent 会话（它是空闲的）。
- 没有自动化：pane 内关闭横条的「不保存」按钮（见说明；它有 rect，只是本用例没有点）。需要时手动点一次，确认它关 pane 且磁盘不变。
