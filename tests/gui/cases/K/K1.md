# K1 一个任务一张卡：文件、测试结果、引语
requires: sandbox
checklist: K1
scenarios: [artifacts-basic]

在 git 仓库里运行 `artifacts-basic`，「产物」标签出现最新一张卡片。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k1 && cd work/k1 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k1"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
wait   windows[0].inspector.card.status == "idle" timeout=30s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[*] exists count=1 timeout=10s
wait   windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=15s
assert windows[0].inspector.artifacts.cards[0].title contains "add a greeting"
assert windows[0].inspector.artifacts.cards[0].started != ""
assert windows[0].inspector.artifacts.cards[0].files[?path=="hello.txt"].status == "A"
assert windows[0].inspector.artifacts.cards[0].files[?path=="README.md"].status == "M"
assert windows[0].inspector.artifacts.cards[0].test.ok == true && windows[0].inspector.artifacts.cards[0].test.command contains "cargo test"
assert windows[0].inspector.artifacts.cards[0].quote == "Added hello.txt and updated README.md."
assert windows[0].inspector.artifacts.summary.files == 2
shot   k1-artifacts
```

## judge
- `k1-artifacts`：一张卡片，标题「时刻 · add a greeting…」（没有「Turn」字样），两个文件行（A / M，+/− 数字），一行绿色的 `✓ cargo test 通过`，灰色引语。
