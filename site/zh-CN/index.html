一个终端，装下你和 Agent 的全部工作

Agent 可以并行，你的注意力不能。gilvt 把你的终端、所有 Claude Code 与 Codex 会话、以及对它们工作的 review 收进同一个原生窗口——每一次切换只花一个按键，而不是你的专注力。

通用版（Apple 芯片与 Intel）· macOS 11 及以上 · 经 Apple 签名与公证 · Apache-2.0

一个窗口，三件事

不必再在终端、编辑器、diff 工具和看板之间来回跳。每跳一次都是一次上下文切换，gilvt 把它们省掉。

就是你的日常终端

标签页、分屏、GPU 渲染、真彩色、Kitty 键盘协议、中文输入法和 725 套主题。有没有 Agent，都可以拿它做所有的事。

所有 Agent 尽收眼底

一个左栏列出所有会话，等你的那些自动排到最上面；⇧⌘J 跨标签页、跨窗口直接跳过去。系统通知、Dock 角标和监控官帮你把握全局。

点一下就 review，就地修改

点时间线的一行回到那一刻，打开任意一轮的 diff，预览代码、Markdown 和 Mermaid，在内置编辑器里直接改。Agent 也能用 gilvt view 把文件递到你面前。

完整的工作循环，不出这个窗口

  1. 运行在 pane 里启动 claude 或 codex，一个或者六个。
  2. 被提醒需要你的会话会亮起来，⇧⌘J 直接带你过去。
  3. Review点一下就看到这一轮改了什么，一个文件一个文件地看。
  4. 编辑就地改好，再让 Agent 接着做。

还有这些细节

每一轮都是一条时间线

命令、文件修改、TODO 和失败，按轮次列出；点一行，终端就滚回那里。

每一轮改了什么 ⌥⌘2

每轮的产物和「本轮」diff，不离开终端就能检查 Agent 的工作。

找回并恢复会话 ⇧⌘R

搜索几天前的会话接着做，离线 Review 跑完的会话，在新的 git worktree 里开出新 Agent。

监控官 ⇧⌘O

所有 Agent 和终端排成卡片墙；在任意标签的命令条里问"什么需要我处理"，由你本机的 CLI 回答。

Quick Look 与编辑器

代码高亮与 diff、排版后的 Markdown 和 Mermaid、⌘P 模糊找文件，以及带实时预览的内置编辑器。

725 套主题

内置主题库，也支持你自己的主题，深浅色各选一套，窗口外框跟着主题变。

几条基本原则

  • Agent 始终是原生 TUI。不另做聊天界面，也不提供审批按钮。
  • 只观察，不代答。gilvt 只展示状态、移动焦点，从不向 Agent 输入按键。
  • 不改你的配置。hooks 在启动时注入，你的 rc 文件、~/.claude、~/.codex 原样不动。
  • 没有遥测。gilvt 自己发起的唯一请求是可以关闭的更新检查。隐私说明
