# P4 有 agent 的 pane 重启后：待恢复，单个恢复与全部恢复
requires: sandbox
checklist: P4
scenarios: [default]

三个 pane 各跑一个 agent（标签 1 左右分屏两个、标签 2 一个）。`⌘Q`（agent 都是空闲，不弹确认）后重开：这三个 pane 都是 shell，左栏出现「待恢复 · 3」分区，
`pending` 列出三个会话。点一行恢复其中一个（`cd <cwd> && claude --resume <id>` 打进它原来的 pane）；再点「全部恢复」，其余的每隔约 500 ms 恢复一个。
全部完成后「待恢复」分区消失，`pending` 为 `[]`。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/p4 && cd -P ~/work/p4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/p4"
type   "claude @scenario:default p4 一号\n"
wait   windows[0].sidebar.rows[?name=="p4 一号"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "claude @scenario:default p4 二号\n"
wait   windows[0].sidebar.rows[?name=="p4 二号"].status == "idle" && windows[0].tabs[0].panes[1].foreground == "agent:claude" timeout=20s
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/p4 && claude @scenario:default p4 三号\n"
wait   windows[0].sidebar.rows[?name=="p4 三号"].status == "idle" && windows[0].tabs[1].panes[0].foreground == "agent:claude" timeout=20s
# 三个 agent 都已写进布局（agent 的 kind / session_id / name）
assert windows[0].layout.tabs[0].tree.children[*].pane.agent.kind == "claude"
assert windows[0].layout.tabs[1].tree.pane.agent.name == "p4 三号"
key    cmd+q
sleep  2s
restart
# 重开：三个 pane 都是 shell，三个待恢复
wait   pending[*] exists count=3 timeout=20s
assert pending[*].session contains "claude:"
assert pending[?name=="p4 一号"] exists count=1
assert pending[?name=="p4 二号"] exists count=1
assert pending[?name=="p4 三号"] exists count=1
assert pending[*].cwd contains "/work/p4"
assert windows[0].tabs[*].panes[?foreground=="agent:claude"] !exists
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[?foreground=="shell"] exists count=2 && windows[0].tabs[1].panes[?foreground=="shell"] exists count=1 timeout=15s
assert windows[0].sidebar.sections[?name=="pending"] exists count=1
assert windows[0].sidebar.sections[?name=="pending"].title == "待恢复 · 3"
assert windows[0].sidebar.rows[?section=="pending"] exists count=3
assert windows[0].sidebar.rows[?section=="pending"].line == "待恢复"
shot   p4-pending
# 单个恢复：点「p4 一号」那一行（行上的 pane 是它原来的 pane）
click  'row(section=="pending"&&name=="p4 一号")'
wait   pending[*] exists count=2 timeout=10s
assert pending[?name=="p4 一号"] !exists
wait   windows[0].tabs[*].panes[?foreground=="agent:claude"] exists count=1 timeout=30s
assert windows[0].tabs[*].panes[*].screen_tail[*] contains "claude --resume"
shot   p4-one
# 全部恢复：点分区标题行右端的「全部恢复」（它没有单独的 rect，标题行宽 240 点，按钮靠右）
click  'rect(windows[0].sidebar.sections[?name=="pending"])+(85,0)'
wait   pending[*] exists count=1 timeout=5s
wait   pending == [] timeout=10s
wait   windows[0].tabs[*].panes[?foreground=="agent:claude"] exists count=3 timeout=45s
assert windows[0].sidebar.sections[?name=="pending"] !exists
assert windows[0].sidebar.rows[?section=="pending"] !exists
shot   p4-all
```

## judge
- `p4-pending`：左栏「待恢复 · 3」在「需要你」之后、项目分组之前，右端有「全部恢复」；三行都是「待恢复」状态；三个 pane 都是 shell 提示符，没有 agent 在跑（断言）。
- `p4-one`：被点的那个 pane 里出现了 `cd … && claude --resume <id>` 并起来了；另外两个还是 shell，「待恢复 · 2」。
- 「全部恢复」的间隔约 500 ms：`wait pending[*] exists count=1` 能抓到中间状态（2 → 1 → 0）；这一步依赖轮询正好落在 500 ms 的间隔里，
  偶尔错过属于测量问题，重跑一次；两次都错过再看录屏。
- 点「全部恢复」用的是标题行的 `rect` 加 `+(85,0)`（按钮在行右端）；点不中时 `pending` 不会变，`wait` 超时，截图 `p4-one` 里能看到按钮的位置，改偏移量。
- `p4-all`：「待恢复」分区消失，三个 pane 都在跑 claude，左栏出现三个「p4 …」会话行。
