# Z7 只有一个 pane 的普通标签里按 ⌘⇧T，什么都不变
requires: sandbox
checklist: Z7
scenarios: []

pane 已经独占整个标签，又不是从别的标签移出来的：`⌘⇧T` 不开新标签、不动焦点。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+shift+t
sleep  1s
assert windows[0].tabs[*] exists count=1
assert windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].focused == true
```
