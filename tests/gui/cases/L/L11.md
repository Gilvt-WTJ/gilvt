# L11 Review 位置在重启后保持
requires: sandbox
checklist: L11
scenarios: [hist-claude]

两个待 Review 的会话，Review 完第一个（`⌘↩`），`⌘Q` 重开：第一个不再出现，第二个还在，`store_initialized` 仍为 true（不会再次 baseline 把第二个也吞掉）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l11 && cd -P ~/work/l11 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l11"
seed   hist-claude --cwd work/l11 --id c1a0de00-0000-4000-8000-0000000b1101 --prompt "l11 甲"
seed   hist-claude --cwd work/l11 --id c1a0de00-0000-4000-8000-0000000b1102 --prompt "l11 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
key    space
wait   windows[0].overlay.session_review.session_key contains "0b1101" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
key    cmd+enter
wait   windows[0].overlay.rows[?session_key contains "0b1101"] !exists && windows[0].overlay.session_review.session_key contains "0b1102" timeout=10s
assert windows[0].overlay.store_last_error == null
sh     'awk "/0b1101/{f=1} f&&/reviewed_through/{ok=1} f&&/^    }/{f=0} END{exit !ok}" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
key    esc
key    esc
wait   windows[0].overlay == null
key    cmd+q
sleep  2s
restart
wait   windows[*] exists count=1 timeout=20s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b1102"] exists timeout=15s
assert windows[0].overlay.store_initialized == true && windows[0].overlay.rows[?session_key contains "0b1101"] !exists && windows[0].overlay.rows[1] !exists
assert windows[0].overlay.tabs[?name=="review"].count == 1
key    esc
wait   windows[0].overlay == null
```

## judge
- 重开后「待 Review」只有第二个会话（`l11 乙`），仍是 2 轮待 Review；第一个会话在「全部会话」里还在。
