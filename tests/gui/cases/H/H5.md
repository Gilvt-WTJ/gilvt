# H5 时间线过滤：全部 / Bash / 编辑 / 失败
requires: sandbox
checklist: H5
scenarios: [timeline]

依次点击过滤，只显示匹配的行；切回「全部」后思考行与「↩」行恢复。子 Agent 连同 Task 行一起显示的部分由 H6（真实 claude）覆盖。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h5 && cd -P ~/work/h5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h5"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h5-all
assert windows[0].inspector.filter == "全部" && windows[0].inspector.rows[?kind=="thinking"] exists
click  'rect(windows[0].inspector.chips[?label=="Bash"])'
wait   windows[0].inspector.filter == "Bash" && windows[0].inspector.rows[?kind=="tool"] exists count=3 timeout=3s
assert windows[0].inspector.rows[?label=="Bash echo early"] exists && windows[0].inspector.rows[?label=="Bash cargo test"] exists && windows[0].inspector.rows[?label=="Bash echo late"] exists
shot   h5-bash
click  'rect(windows[0].inspector.chips[?label=="编辑"])'
wait   windows[0].inspector.filter == "编辑" && windows[0].inspector.rows[?kind=="tool"] exists count=2 timeout=3s
assert windows[0].inspector.rows[?label contains "Update README.md"] exists && windows[0].inspector.rows[?label contains "Write hello.txt"] exists
shot   h5-edit
click  'rect(windows[0].inspector.chips[?label=="失败"])'
wait   windows[0].inspector.filter == "失败" && windows[0].inspector.rows[?kind=="tool"] exists count=1 timeout=3s
assert windows[0].inspector.rows[?kind=="tool"].label == "Bash cargo test" && windows[0].inspector.rows[?kind=="tool"].status == "failed"
shot   h5-failed
click  'rect(windows[0].inspector.chips[?label=="全部"])'
wait   windows[0].inspector.filter == "全部" && windows[0].inspector.rows[?kind=="thinking"] exists timeout=3s
shot   h5-all-again
```

## judge
- `h5-bash`：只有 `echo early`、`cargo test`、`echo late` 三个 Bash 行；`h5-edit`：只有 `Edit README.md`、`Write hello.txt`
  （Read 不算编辑）；`h5-failed`：只有 `cargo test`（红色 ✗）。
- `h5-all-again` 与 `h5-all` 一致：思考行（✻）与回复行都回来了。
- 当前选中的过滤项有高亮。
