# N4 「仍然关闭」之后，该会话仍可经 ⌘⇧R 恢复
requires: sandbox
checklist: N4
scenarios: [ask-question]

在问你的会话所在的 pane 按 `⌘W`、确认条上按 `⌘↩`（仍然关闭）：pane 关掉，会话成为已结束；它的记录没有丢，`⌘⇧R` 里还在，`↩` 在空闲 shell 里恢复它
（`cd <cwd> && claude --resume <id>`），接着对话。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/l4 && cd -P ~/work/l4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l4"
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"].status == "awaiting_answer" timeout=15s
key    cmd+w
wait   windows[0].close_confirm.action == "pane" && windows[0].close_confirm.items[0].status == "在问你" timeout=3s
shot   l4-confirm
key    cmd+enter
wait   windows[0].close_confirm == null && windows[0].tabs[0].panes[*] exists count=1 timeout=5s
# 会话结束了，但没有被删：左栏「已结束」里有它，⌘⇧R 里有它（不再运行）
wait   windows[0].sidebar.rows[?section=="ended"] exists count=1 timeout=15s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
assert windows[0].overlay.rows[0].live == false
assert windows[0].overlay.rows[0].agent == "claude"
shot   l4-palette
# 光标在这一行：↩ 在焦点 pane（空闲 shell）就地恢复
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].screen_tail[*] contains "claude --resume" timeout=10s
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
assert windows[0].tabs[0].panes[*] exists count=1
wait   windows[0].sidebar.rows[?section=="project:l4"] exists timeout=15s
shot   l4-resumed
```

## judge
- `l4-confirm`：确认条列出「C · … · 在问你」，默认「取消」，「仍然关闭」是 `⌘↩`。
- `l4-palette`：「会话」浮层里这一行是已结束的会话（右侧是「N 分钟前」，不是「● 运行中」）。
- `l4-resumed`：原来的 pane 里输入了 `cd … && claude --resume <id>`，Claude 显示之前的对话，左栏会话行回到运行中分组，名字没变。
