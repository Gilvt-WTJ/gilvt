# P6 关掉最后一个窗口（不是 ⌘Q）之后重开为空白
requires: sandbox
checklist: P6
scenarios: []

用户主动关掉最后一个窗口（关标签直到窗口关闭，应用随之退出）不算「会话中断」：`workspace.json` 被删除，下次启动是空白窗口。
对照 P1：`⌘Q` 才会保留布局。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/p6 && cd -P ~/work/p6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/p6"
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/p6 && clear\n"
wait   windows[0].tabs[1].panes[0].cwd contains "/work/p6"
# 让定时保存至少写过一次，证明文件之后确实是被删除的
sleep  2500ms
sh     'test -s "$HOME/Library/Application Support/gilvt/state/workspace.json"'
# 关两个标签：最后一个标签关掉后窗口关闭、应用退出
key    cmd+shift+w
wait   windows[0].tabs[*] exists count=1 timeout=5s
key    cmd+shift+w
sleep  2s
sh     'test ! -e "$HOME/Library/Application Support/gilvt/state/workspace.json"'
restart
wait   windows[*] exists count=1 timeout=20s
assert windows[0].tabs[*] exists count=1
assert windows[0].tabs[0].panes[*] exists count=1
assert windows[0].tabs[0].panes[?cwd contains "/work/p6"] !exists
assert pending == []
shot   p6-blank
```

## judge
- `p6-blank`：空白窗口（一个标签、一个 shell，不在 `work/p6`）。
- 步骤里的两条 `sh` 断言：关窗口之前 `workspace.json` 存在且非空，关窗口之后不存在。
