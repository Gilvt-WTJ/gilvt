# Q2 agent 退出后该 pane 变回终端行
requires: sandbox
checklist: Q2
scenarios: [approve-bash]

agent 运行期间该 pane 是 agent 行、没有终端行；`/exit` 之后 agent 行进「已结束」，该 pane 变回终端行。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q2 && cd -P ~/work/q2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q2"
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=1 timeout=10s
type   "claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?status=="awaiting_approval"] exists timeout=15s
assert windows[0].sidebar.rows[?kind=="terminal"] exists count=0
key    n
wait   windows[0].inspector.card.status == "idle" timeout=10s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=1 timeout=10s
assert windows[0].sidebar.rows[?section=="ended"] exists count=1
shot   q2
```

## judge
- `q2`：侧栏里一行灰色终端行，另在「已结束」组（默认折叠）里有刚才的 agent 会话。
