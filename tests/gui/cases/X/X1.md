# X1 点击输入行移动光标（shell）
requires: sandbox
checklist: X1
scenarios: []

在 shell 提示符后输入 `echo` 加 20 个 `a`（不回车），光标在行尾；点击光标左边约 5 格处，光标移到那里（gilvt 向 readline 发了 ←），
再输入 `X` 并回车：`X` 插在 `a` 中间，输出里有 `aXa`。没有这个功能时 `X` 会接在行尾，只有 `aX`。
沙盒提示符 `sandbox$ ` 占 9 格，所以输入后光标在第 34 列（从 0 起）。点击点由 `cursor.rect` 向左平移 40 点：13 号 Menlo 一格约 7.8 点，
落在约 5 格以左，仍在那串 `a` 里；字号略有不同也不影响断言（只要求 `X` 两边都是 `a`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "clear\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] == "sandbox$" timeout=5s
type   "echo aaaaaaaaaaaaaaaaaaaa"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "echo aaaaaaaaaaaaaaaaaaaa" && windows[0].tabs[0].panes[0].cursor.col == 34 timeout=5s
click  'rect(windows[0].tabs[0].panes[0].cursor)+(-40,0)'
wait   windows[0].tabs[0].panes[0].cursor.col != 34 timeout=5s
shot   x1-moved
type   "X"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "aXa" timeout=5s
key    enter
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "aXa" count=2 timeout=5s
assert windows[0].tabs[0].panes[0].screen_tail[*] contains "^[" count=0
```

## judge
- `x1-moved`：光标（方块）在那串 `a` 的中间，不在行尾；输入行没有被选中的高亮。
