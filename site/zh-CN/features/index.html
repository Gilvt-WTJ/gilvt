终端本身

首先是一个真正的终端

gilvt 是一个完整的日常终端。有没有 Agent 都可以用它做所有的事；把两侧栏都收起来（⌘B、⌘I），它就是一个纯粹的终端。

  • 标签页与分屏：⌘T ⌘D ⌘⇧D，键盘移动和调整 pane，⌘⇧⏎ 最大化当前 pane。
  • GPU 渲染、真彩色、Kitty 键盘协议、中文输入法、查找和超长回滚。
  • zsh、bash、fish 的 Shell 集成：新 pane 继承当前目录，命令有标记可以来回跳。你的 rc 文件一个字不改。
  • ⌘+点击 src/main.rs:42 这样的路径直接预览，点击链接在浏览器打开。
  • 退出或崩溃后，窗口、标签页、分屏和目录都会恢复；Agent 会话列在「待恢复」里，一键接着做。
  • 关闭会打断 Agent 的 pane、标签页或窗口时，先确认再关。
Agent 会话

谁在等你，不用去找

在任意 pane 里运行 claude 或 codex，gilvt 会自动识别并实时跟踪它的状态；你照常在 Agent 自己的界面里工作。

  • 左栏列出所有会话，「需要你」固定在最上面：等待审批或在问你问题的，等得最久的排第一。
  • 每一行显示当前动作、所在位置、git 分支与改动数，以及上下文用了多少。
  • ⌘⇧J 跨标签页、跨窗口在需要你的会话之间循环跳转；⌘⇧↑ ⌘⇧↓ 按顺序切换。
  • pane 描边和标签圆点四种颜色：黄色需要你、红色出错、蓝色执行中、绿色已完成未查看。
  • 在别的应用里时，系统通知和 Dock 角标会提醒你；点通知直接落到对应的 pane。
每一轮都看得清

Agent 每一轮做了什么

右侧的检查器跟随当前聚焦的 pane。它只展示和导航，从不向 Agent 输入任何东西。

  • 过程 ⌥⌘1：状态卡、TODO 和时间线，列出每条命令和每次编辑；失败的命令直接显示关键报错。点一行，终端滚回那里。
  • 产物 ⌥⌘2：每个任务一张卡片，列出改了哪些文件、+a −b、测试是否通过；点开任意文件就是「本轮」diff。
  • 配置 ⌥⌘3：会话的模型、权限、MCP、Hooks、Skills 和记忆文件，只读并脱敏。
Review 与编辑

点一下就 review，看到问题就地改

Agent 改过的每个文件，点一下就是清楚的 diff，再按一个键就进入编辑器，不用切到别的应用。

  • Quick Look：语法高亮、词级 diff，可与 HEAD 或任意分支比较；左右对比或统一视图；回车固定成 pane，文件保存后自动刷新。
  • Markdown 排版显示并标出改动，Mermaid 图离线渲染。
  • 按 E 进入内置编辑器：语法高亮、中文输入法、实时预览（⌘⇧V）；Agent 同时改了这个文件时会提示你，绝不悄悄覆盖。
  • ⌘P 在仓库里模糊搜索任意文件；从访达拖进文件，可以预览，也可以交给 Agent。
  • 在任何 shell 里，gilvt view 文件:行号 和 gilvt diff 都能打开预览；Agent 也能用它们，把文件直接递到你面前。
跨时间的会话管理

任何会话都能接着做，跑完的可以离线 review

Session Center（⌘⇧R）覆盖这台 Mac 上所有的 Claude Code 和 Codex 会话，不只是开着的那些。

  • 按标题、首条提示、项目或目录搜索；原地、新标签页或分屏恢复。
  • 「待 Review」收集你还没看过的每一轮结果，失败的排前面；只读查看，不会启动 Agent。
  • 重命名、归档，把旧会话移到废纸篓；清理向导（⌘⇧K）可以批量处理。
  • 新建 Agent（⌘⇧N）：选 Agent、目录、初始任务、模型和权限模式，还可以放进新的 git worktree。
监控官

把握全局，还能直接问

监控官（⌘⇧O）把所有窗口里的 Agent 和终端按状态排成卡片墙，不用挨个去看也能跟上进度。

  • 卡片显示当前动作、轮次、改动行数和 TODO 进度；终端卡片显示正在运行或上一条命令。
  • 可选的 AI 总结：每个会话的目标和进展，由你本机的 claude 或 codex 生成，默认关闭。
  • 在对话面板里，或在任意标签页底部的命令条（⌘⇧M）里问「什么需要我处理」，回答里的会话名可以直接点过去。
  • 设计上只读，通过 MCP（gilvt mcp）也一样：只能看，不能输入。
主题与设置

按你的习惯来

  • 725 套内置主题，也支持你自己的主题；深浅色各选一套，窗口外框和状态颜色都跟着变。
  • 设置（⌘,）即改即生效，并写回 config.toml，保留你的注释；手动改文件也会实时重新加载。
  • 界面支持简体中文和 English，切换不需要重启。
不打扰你

放心把工作交给它

  • Agent 始终是原生 TUI。gilvt 只观察、移动焦点，从不替你回答。
  • 不改你的配置：hooks 在启动时注入，不写进你的 rc 文件、~/.claude 或 ~/.codex。
  • 解析出问题时，gilvt 退回轻量模式或普通终端，输入输出始终正常。
  • 没有遥测。它自己发起的唯一请求是可以关闭的更新检查；更新在你退出时安装，不会打断 Agent。隐私说明
