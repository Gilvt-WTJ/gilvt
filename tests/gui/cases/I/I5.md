# I5 运行中的会话：跳过去，不再恢复一份
requires: sandbox
checklist: I5
scenarios: [ask-question]

浮层里运行中的会话显示「● 运行中 · <位置>」；`↩` 跳到它所在的 pane（必要时切换标签 / 窗口）；该行不能被 `⇧` / `⌘` 点击选中。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i5 && cd -P ~/work/i5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i5"
# 窗口 2 里运行会话。两个窗口时 windows[] 的顺序不固定：一律用 key window 区分（键盘输入也跟着 key window 走）。
# gilvt 在后台时新窗口不会成为 key window（没有任何窗口 key==true），所以先点一下把 gilvt 带到前台
click  pane(focused)
wait   front == true timeout=5s
key    cmd+n
wait   windows[*] exists count=2 && windows[?key==true].tabs[0].panes[0].foreground == "shell" && windows[?key==true].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# 键盘输入默认对准 session.env 的窗口 1；这里要打进新开的窗口 2（key window）
type   --window key "cd -P ~/work/i5 && claude @scenario:ask-question\n"
wait   windows[?key==true].tabs[0].panes[0].foreground == "agent:claude" && windows[?key==true].sidebar.rows[?section=="project:i5"].status == "awaiting_answer" timeout=15s
# 回到窗口 1（session.env 记录的窗口）：新窗口盖在它上面，点它的 pane 会点到窗口 2，所以用辅助功能把它提到最前
raise
wait   windows[?key==true].tabs[0].panes[0].foreground == "shell" timeout=5s
key    cmd+shift+r
wait   windows[?key==true].overlay.kind == "sessions" && windows[?key==true].overlay.items == 1 timeout=15s
shot   i5-palette
assert windows[?key==true].overlay.rows[?live==true].right contains "● 运行中"
click  'rect(windows[?key==true].overlay.rows[?live==true])' shift
shot   i5-shift-click
key    enter
# 跳到窗口 2 的 pane：key window 换成了跑着 claude 的那个，没有新开标签
wait   windows[?key==true].tabs[0].panes[0].foreground == "agent:claude" && windows[?key==true].tabs[0].panes[0].focused == true timeout=5s
assert windows[*] exists count=2 && windows[?key==true].tabs[*] exists count=1
# 同一窗口、另一个标签
key    cmd+t
wait   windows[?key==true].tabs[*] exists count=2 && windows[?key==true].tabs[1].panes[0].foreground == "shell" timeout=10s
type   --window key "cd -P ~/work/i5 && clear\n"
key    cmd+shift+r
wait   windows[?key==true].overlay.kind == "sessions" && windows[?key==true].overlay.items == 1 timeout=15s
key    enter
wait   windows[?key==true].tabs[0].active == true && windows[?key==true].tabs[0].panes[0].focused == true && windows[?key==true].tabs[*] exists count=2 timeout=5s
# 关掉窗口 2 的两个标签（窗口随之关闭），只留窗口 1
key    cmd+shift+w
key    cmd+shift+w
wait   windows[*] exists count=1 timeout=5s
```

## judge
- `i5-palette`：这一行第二行是「● 运行中 · 窗口 2 · 标签 1」一类的位置，与左栏该会话的位置行一致。
- `i5-shift-click`：`⇧`+点击没有把它加进多选（没有勾选、没有「已选 N 个」）。
- 两次 `↩` 都只是跳转：窗口 2 来到前面并聚焦该 pane、同窗口切回标签 1；没有新开标签（断言）。
- 如果 `⌘⇧W` 关标签时 gilvt 先问是否结束正在运行的程序，确认后继续（报告里注明）。
