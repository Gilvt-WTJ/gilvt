# K8 Space 打开「本轮」diff，+/− 与卡片一致
requires: sandbox
checklist: K8
scenarios: [artifacts-basic]

选中卡片里的 `README.md` 按 Space。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k8 && cd work/k8 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k8"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=30s
click  'rect(windows[0].inspector.artifacts.cards[0].files[?path=="README.md"])'
wait   windows[0].inspector.artifacts.cards[0].files[?path=="README.md"].selected == true timeout=5s
key    space
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.base == "本轮（第 1 轮前 → 后）" && windows[0].overlay.path contains "README.md" timeout=10s
shot   k8-turn-diff
```

## judge
- `k8-turn-diff` 的头部写着「本轮（第 1 轮前 → 后）」，diff 的 +/− 行数与卡片里 `README.md` 一行的数字相同（把两个数字抄进报告）。
