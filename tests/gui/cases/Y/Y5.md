# Y5 筛选条
requires: sandbox
checklist: Y5
scenarios: [long-tool]

点筛选条「终端」只剩终端分组；再点一次恢复全部。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "claude @scenario:long-tool\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists count=1 timeout=15s
key    cmd+shift+o
wait   windows[0].monitor.groups[?name=="running"] exists count=1 && windows[0].monitor.groups[?name=="terminals"] exists count=1 timeout=10s
assert windows[0].monitor.filter == "all"
click  'rect(windows[0].monitor.chips[?label contains "终端"])'
wait   windows[0].monitor.filter == "terminals" timeout=5s
assert windows[0].monitor.groups[?name=="running"] exists count=0
assert windows[0].monitor.groups[?name=="terminals"] exists count=1
assert windows[0].monitor.chips[?label contains "运行中"] exists count=1
click  'rect(windows[0].monitor.chips[?label contains "终端"])'
wait   windows[0].monitor.filter == "all" timeout=5s
assert windows[0].monitor.groups[?name=="running"] exists count=1
```
