# V1 内置编辑器：从配置弹窗编辑并保存
requires: sandbox
checklist: V1
scenarios: [default]

配置标签的 Skills 弹窗里悬停一行，点行尾的「编辑」：编辑 pane 出现在 Agent 终端的**右边**（同一个标签多一个 pane，键盘留在终端）。
点进编辑区输入，pane 头部和标签显示 ●；`⌘S` 保存后 ● 消失，磁盘文件正是「输入 + 原内容」。再从同一弹窗点这一行打开 Quick Look
预览，按 `E`：文件已经在编辑 pane 里，所以只是聚焦那个 pane、关掉预览，不开第二份。

默认路由在分屏后任一半 < 60 列时改开新标签。沙盒窗口是 960 + 320（检查器）点宽，减去左栏 240 点，终端区约 720 点：
13 号 Menlo 约 92 列（会开新标签，V2–V4 用的就是这个），所以本用例先 `restart --set font_size=9`（约 132 列，两半各约 66 列，
默认分屏），结束时改回 13。终端列数不在 `debug state` 里，这里由路由结果间接证明。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/v1/.git work/v1/.claude/skills/code-review"
sh     "printf -- '---\nname: code-review\ndescription: Review a diff for bugs\n---\n# Code review\n\nbody\n' > work/v1/.claude/skills/code-review/SKILL.md && cp work/v1/.claude/skills/code-review/SKILL.md work/v1/SKILL.orig"
type   "cd -P ~/work/v1 && clear && claude @scenario:default v1 editor\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" && windows[0].inspector.card.status == "idle" timeout=20s
key    cmd+alt+3
wait   windows[0].inspector.tab == "config" && windows[0].inspector.config.loading == false && windows[0].inspector.config.skills == 1 timeout=10s
assert windows[0].editors[*] !exists && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1
click  'rect(windows[0].inspector.config.group_rects[0])'
wait   windows[0].inspector.config.dialog.group == "skills" && windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect != null timeout=5s
# 「编辑」只在悬停时画出来（隐藏时也记录 rect，但不接收点击）：先悬停在这一行上，再点它的 edit_rect
hover  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].rect)'
click  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].edit_rect)'
wait   windows[0].editors[0].path contains "/work/v1/.claude/skills/code-review/SKILL.md" && windows[0].inspector.config.dialog == null timeout=5s
# 分屏：同一个标签，pane 数 1 → 2，编辑 pane 在右边，键盘留在 Agent 终端
assert windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].kind == "editor" && windows[0].editors[0].tab == 0
assert windows[0].tabs[0].panes[0].foreground == "agent:claude" && windows[0].tabs[0].panes[0].focused == true
assert windows[0].editors[0].dirty == false && windows[0].editors[0].readonly == false && windows[0].editors[0].bar == "none" && windows[0].editors[0].rect != null
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+up
wait   windows[0].editors[0].cursor.line == 1 && windows[0].editors[0].cursor.col == 1 timeout=5s
type   "hello "
wait   windows[0].editors[0].dirty == true && windows[0].editors[0].cursor.line == 1 && windows[0].editors[0].cursor.col == 7 timeout=5s
assert windows[0].tabs[0].title == "● SKILL.md"
sh     "cmp work/v1/SKILL.orig work/v1/.claude/skills/code-review/SKILL.md"
shot   v1-dirty
key    cmd+s
wait   windows[0].editors[0].dirty == false && windows[0].editors[0].bar == "none" timeout=5s
assert windows[0].tabs[0].title == "SKILL.md"
sh     "printf 'hello ' | cat - work/v1/SKILL.orig | cmp - work/v1/.claude/skills/code-review/SKILL.md"
# 预览里按 E：文件已在编辑 pane 里 → 聚焦它，不开第二份。先把键盘还给 Agent 终端，配置标签才跟着它
key    cmd+alt+left
wait   windows[0].tabs[0].panes[0].focused == true && windows[0].inspector.config.loading == false && windows[0].inspector.config.skills == 1 timeout=10s
click  'rect(windows[0].inspector.config.group_rects[0])'
wait   windows[0].inspector.config.dialog.group == "skills" timeout=5s
click  'rect(windows[0].inspector.config.dialog.rows[?name=="code-review"].rect)'
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/v1/.claude/skills/code-review/SKILL.md" timeout=10s
assert windows[0].editors[*] exists count=1
key    e
wait   windows[0].overlay == null && windows[0].tabs[0].panes[1].focused == true timeout=5s
assert windows[0].editors[*] exists count=1 && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=2 && windows[0].editors[0].dirty == false
shot   v1-saved
restart --set font_size=13
```

## judge
- `v1-dirty`：编辑 pane 在 Agent 终端右边，各占约一半；头部文件名 `SKILL.md` 前（或旁）有 ●，「保存 ⌘S」与「✕」在头部；标签栏标题是 `● SKILL.md`
  （断言已覆盖标题）；第 1 行是 `hello ---`，光标在 `hello ` 之后；行号栏从 1 开始。
- `v1-saved`：● 已消失；编辑 pane 有焦点（分屏时的蓝色焦点边框在编辑 pane 上）；Quick Look 已关闭；窗口里只有这一个编辑 pane。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
