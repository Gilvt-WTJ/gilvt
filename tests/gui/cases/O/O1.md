# O1 默认主题外观不变
requires: sandbox
checklist: O1
scenarios: []

不改主题配置（`theme = "light"`）时外观与改动前一致；`theme = "dark"` 也一样。对照 `master` 上同一场景的截图（或 W / Y 节已有截图）判断。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "gilvt Light"
assert theme.source == "builtin"
assert windows[0].inspector.visible == true
shot   o1-light
restart --set 'theme="dark"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "gilvt Dark"
assert theme.dark == true
assert windows[0].inspector.visible == true
shot   o1-dark
restart --set 'theme="light"'
```

## judge
- `o1-light`：浅色；左栏底色浅灰、终端白底、检查器浅色卡片，与改动前一致。
- `o1-dark`：深色；与改动前的深色外观一致。
