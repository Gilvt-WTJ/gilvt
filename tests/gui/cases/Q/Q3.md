# Q3 按状态分组时终端行归入默认折叠的「终端」组
requires: sandbox
checklist: Q3
scenarios: []

「按状态」下终端行不进任何状态组，而是末尾的 `terminals` 分区（默认折叠）；点标题展开后行可见；切回「按项目」终端行回到项目分组。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q3 && cd -P ~/work/q3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q3"
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=1 timeout=10s
click  'rect(windows[0].sidebar.group_buttons[?name=="status"])'
wait   windows[0].sidebar.group_by == "status" timeout=5s
assert windows[0].sidebar.sections[?name=="terminals"].collapsed == true
assert windows[0].sidebar.sections[?name=="terminals"].count == 1
assert windows[0].sidebar.rows[?kind=="terminal"].section == "terminals"
assert windows[0].sidebar.rows[?kind=="terminal"].visible == false
click  'rect(windows[0].sidebar.sections[?name=="terminals"])'
wait   windows[0].sidebar.rows[?kind=="terminal"].visible == true timeout=5s
shot   q3
click  'rect(windows[0].sidebar.group_buttons[?name=="project"])'
wait   windows[0].sidebar.group_by == "project" timeout=5s
assert windows[0].sidebar.rows[?kind=="terminal"].section == "project:q3"
```

## judge
- `q3`：「按状态」下末尾有「终端 · 1」分组，已展开，里面是那一行灰色终端行。
