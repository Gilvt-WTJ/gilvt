# H11 已拒绝与已中断
requires: sandbox
checklist: H11
scenarios: [approve-bash, long-tool]

审批菜单选「No」拒绝一次工具调用；另一次在工具执行中按 `Esc` 中断。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h11 && cd -P ~/work/h11 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h11"
type   "claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?status=="awaiting_approval"].detail contains "rm -rf build" timeout=15s
key    n
wait   windows[0].inspector.card.status == "idle" timeout=10s
shot   h11-rejected
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
type   "clear && claude @scenario:long-tool\n"
wait   windows[0].sidebar.rows[?section=="project:h11"].detail contains "sleep 30" && windows[0].inspector.card.status == "running_tool" timeout=15s
key    esc
wait   windows[0].inspector.card.status == "idle" timeout=10s
assert windows[0].tabs[0].panes[0].screen_tail[*] contains "Interrupted · What should Claude do instead?"
shot   h11-interrupted
```

## judge
- `h11-rejected`：`rm -rf build` 行显示黄色「⊘ 已拒绝」；前面的 `ls build` 正常完成；没有「Removed build/.」回复行。
- `h11-interrupted`：`sleep 30` 行显示黄色「⊘ 已中断」。
- 两次都不出现「完成未看」（左栏行第二行不是 `✓ 完成未看`）。
