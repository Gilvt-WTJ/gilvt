# H7 TodoWrite 的 TODO 块
requires: sandbox
checklist: H7
scenarios: [todo-states]

`todo-states` 剧本同时有已完成、进行中、待办三种状态，并保持 5 秒；之后全部完成。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h7 && cd -P ~/work/h7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h7"
type   "claude @scenario:todo-states\n"
wait   windows[0].sidebar.rows[?section=="project:h7"].detail contains "sleep 5" timeout=15s
shot   h7-progress
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "三件事都完成了。" timeout=15s
shot   h7-done
```

## judge
- `h7-progress`：TODO 块标题「TODO · 1 / 3」；「☑ 写测试」划线，「◐ 改实现」加粗，「☐ 更新文档」普通字重。
- `h7-done`：标题「TODO · 3 / 3」，三项都是 ☑ 并划线。
- 中文项目文字没有乱码、没有被截成半个字。
