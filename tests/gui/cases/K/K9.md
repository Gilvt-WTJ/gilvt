# K9 ←/→ 切换同一张卡片的文件
requires: sandbox
checklist: K9
scenarios: [artifacts-basic]

卡片文件按路径排序：`README.md` 在 `hello.txt` 之前，所以 `→` 到 `hello.txt`。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k9 && cd work/k9 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k9 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k9"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=30s
click  'rect(windows[0].inspector.artifacts.cards[0].files[?path=="README.md"])'
wait   windows[0].inspector.artifacts.cards[0].files[?path=="README.md"].selected == true timeout=5s
key    space
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "README.md" timeout=10s
key    right
wait   windows[0].overlay.path contains "hello.txt" timeout=5s
key    left
wait   windows[0].overlay.path contains "README.md" timeout=5s
```

## judge
- 无视觉判断：路径断言即可（`→` 到 hello.txt，`←` 回到 README.md）。
