# R5 总结跨重启保留
requires: sandbox
checklist: R5
scenarios: [monitor-slow]

先得到一份覆盖到最后一轮的总结（运行中的自动总结落定后选中卡片按 `s`）；关闭自动刷新后重启（会话随 pane 结束，进入「已结束」），同一份总结仍在。「有新进展」的判定由单元测试 `ready_header_has_age_and_coverage` 覆盖。

## steps
```gilvt-steps
sh     rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=true' --set 'monitor.exclude_paths=[]'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r5 && cd -P ~/work/r5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r5"
type   "claude @scenario:monitor-slow\n"
key    cmd+shift+o
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=30s
wait   windows[0].monitor.cards[?group=="done"].summary.state != "none" && windows[0].monitor.cards[?group=="done"].summary.state != "pending" timeout=30s
click  'rect(windows[0].monitor.cards[?group=="done"])'
key    s
sleep  2s
wait   windows[0].monitor.cards[?group=="done"].summary.state == "ready" timeout=40s
assert windows[0].monitor.cards[?group=="done"].summary.recent contains "fake 总结 #"
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=false'
key    cmd+shift+o
wait   windows[0].monitor.groups[?name=="ended"] exists count=1 timeout=15s
click  'rect(windows[0].monitor.groups[?name=="ended"])'
wait   windows[0].monitor.cards[?group=="ended"].summary.state == "ready" timeout=10s
assert windows[0].monitor.cards[?group=="ended"].summary.recent contains "fake 总结 #"
shot   r5
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=false' --set 'monitor.auto_summary=true'
```

## judge
- `r5`：重启后「已结束」组里这张卡片的 ✦ 块仍是重启前那份，头部的时间是重启前生成的时间。
