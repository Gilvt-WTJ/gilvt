# Z1 把固定预览的标题栏拖到标签栏：移到新标签
requires: sandbox
checklist: Z1
scenarios: []

`gilvt view --pin` 把预览固定在终端右边；按住预览 pane 的标题栏拖到标签栏上松开，这个 pane 离开分屏，独占一个新标签（插在原标签右边）并拿到键盘，
原标签只剩终端。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/z1 && printf 'line 1\nline 2\nline 3\n' > work/z1/notes.txt"
type   "cd -P ~/work/z1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/z1"
type   "gilvt view --pin notes.txt\n"
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].kind == "preview" && windows[0].tabs[0].panes[1].header exists timeout=10s
assert windows[0].tab_bar exists
shot   z1-split
drag   'rect(windows[0].tabs[0].panes[1].header)' 'rect(windows[0].tab_bar)'
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].kind == "preview" timeout=5s
assert windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].kind == "terminal"
assert windows[0].tabs[1].panes[*] exists count=1 && windows[0].tabs[1].panes[0].focused == true
assert windows[0].tabs[1].title contains "notes.txt"
shot   z1-moved
```

## judge
- `z1-split`：终端在左、预览 pane 在右，预览标题栏显示 `notes.txt` 和「T 新标签」提示。
- `z1-moved`：标签栏有两个标签，第二个「👁 notes.txt」是当前标签；预览占满整个 pane 区域（不再是半屏）。
