# K4 进行中的轮实时更新
requires: sandbox
checklist: K4
scenarios: [artifacts-running]

`artifacts-running` 写出 `live.txt` 后让工具再跑 30 秒；轮进行中卡片是虚线边框。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k4 && cd work/k4 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k4"
type   "claude @scenario:artifacts-running\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[0].state == "running" timeout=20s
wait   windows[0].inspector.artifacts.cards[0].files[?path=="live.txt"].status == "A" timeout=20s
shot   k4-running
key    ctrl+c
```

## judge
- `k4-running`：卡片是虚线边框，文件列表里有 `A live.txt`。
