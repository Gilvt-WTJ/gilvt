# H3 展开详情与「复制」
requires: sandbox
checklist: H3
scenarios: [timeline]

点击行首 `▸` 就地展开完整命令与输出（前 20 行、等宽字体）；「复制」把详情文本放进剪贴板并提示「已复制」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h3 && cd -P ~/work/h3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h3"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h3-before
# ▸ 只在鼠标悬停时画出来（隐藏时不接收点击）：先悬停在这一行上
hover  'rect(windows[0].inspector.rows[?label contains "cargo test"])'
click  'rect(windows[0].inspector.rows[?label contains "cargo test"].toggle)'
wait   windows[0].inspector.rows[?label contains "cargo test"].expanded == true timeout=3s
shot   h3-expanded
click  'rect(windows[0].inspector.rows[?label contains "cargo test"].copy)'
wait   windows[0].inspector.toast == "已复制" timeout=3s
clipboard contains "cargo test"
clipboard contains "test result: FAILED. 1 passed; 1 failed; 0 ignored"
shot   h3-copied
```

## judge
- `h3-expanded`：`cargo test` 行下方就地展开，完整命令 `cargo test` 与输出（`Exit code 101`、`Compiling demo …` 直到
  `Finished in 0.02s`，不足 20 行所以全部显示），等宽字体；其他行的位置随之下移，没有弹出窗口。
- `h3-copied`：「复制」旁边出现「已复制」提示。剪贴板断言已经核对了内容。
- 注意：这个用例会覆盖用户的剪贴板（报告里注明）。
