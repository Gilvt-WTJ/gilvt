# L12 保存失败：不假装成功，队列不变
requires: sandbox
checklist: L12
scenarios: [hist-claude]

`reviews.json` 被换成一个目录，状态写入会失败。`⌘↩` 之后 Review 里出现红色「保存失败，没有标记为已 Review」，会话仍在队列里、没有切到下一个；
恢复文件后再按 `⌘↩` 成功，红色提示消失。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l12 && cd -P ~/work/l12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l12"
seed   hist-claude --cwd work/l12 --id c1a0de00-0000-4000-8000-0000000b1201 --prompt "l12 甲"
seed   hist-claude --cwd work/l12 --id c1a0de00-0000-4000-8000-0000000b1202 --prompt "l12 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
key    space
wait   windows[0].overlay.session_review.session_key contains "0b1201" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
sh     'S="$HOME/Library/Application Support/gilvt/state"; mv "$S/reviews.json" "$S/reviews.json.keep" && mkdir "$S/reviews.json"'
key    cmd+enter
wait   windows[0].overlay.session_review.notice contains "保存失败" timeout=10s
assert windows[0].overlay.session_review.session_key contains "0b1201" && windows[0].overlay.rows[?session_key contains "0b1201"] exists && windows[0].overlay.tabs[?name=="review"].count == 2 && windows[0].overlay.store_last_error != null
shot   l12-error
sh     'S="$HOME/Library/Application Support/gilvt/state"; rmdir "$S/reviews.json" && mv "$S/reviews.json.keep" "$S/reviews.json"'
key    cmd+enter
wait   windows[0].overlay.rows[?session_key contains "0b1201"] !exists && windows[0].overlay.session_review.session_key contains "0b1202" timeout=10s
assert windows[0].overlay.session_review.notice == null && windows[0].overlay.store_last_error == null && windows[0].overlay.tabs[?name=="review"].count == 1
key    esc
key    esc
wait   windows[0].overlay == null
```

## judge
- `l12-error`：Review 顶部有红色提示「保存失败，没有标记为已 Review：…」；左侧队列仍是两行；Session Center 底部还有一行红字「Review 状态文件有问题，进度可能不会保存：…」。
- 如果这个用例中途失败，沙盒的 `state/reviews.json` 可能还是个目录：`sandbox.sh down` 照常删除沙盒，不需要手动处理。
