# S4 config.toml 没有 language、系统是中文：界面中文
requires: sandbox
checklist: S4
scenarios: []

同 S3，但假装 macOS 的首选语言是 `zh-Hans-CN`：界面为简体中文，来源是 `system`。

## steps
```gilvt-steps
sh     "sed -i '' '/^language = /d' .config/gilvt/config.toml && ! grep -q '^language' .config/gilvt/config.toml"
restart --env GILVT_TEST_SYSTEM_LANGUAGE=zh-Hans-CN
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
raise
key    cmd+,
wait   settings.key == true && settings.language == "zh-CN" timeout=5s
assert settings.language_source == "system"
assert settings.pages[?id=="language"].label == "文A 语言"
assert settings.languages[?id=="zh-CN"].selected == true
key    cmd+w
restart --set 'language="zh-CN"'
```
