# I2 就地恢复 Claude 会话
requires: sandbox
checklist: I2
scenarios: [hist-claude]

焦点 pane 是空闲 shell 时，`↩` 就地输入 `cd <cwd> && claude --resume <id>`；左栏出现同名会话，时间线补出之前的轮次。
fake claude 在 `--resume` 时接着写同一份会话记录，但不会重放之前的对话、也没有真正的上下文——那部分属于真实 CLI，
由 I3（真实 codex）验证。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i2 --age 1h --id c1a0de00-0000-4000-8000-000000000201 --prompt "i2 要恢复的会话"
type   "cd -P ~/work/i2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i2"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].screen_tail[*] contains "&& claude --resume c1a0de00-0000-4000-8000-000000000201" timeout=5s
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=10s
assert windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1
wait   windows[0].sidebar.rows[?section=="project:i2"].session == "claude:c1a0de00-0000-4000-8000-000000000201" && windows[0].inspector.timeline_rows != 0 timeout=10s
assert windows[0].sidebar.rows[?section=="project:i2"].name == "i2 要恢复的会话"
shot   i2-resumed
type   "接着上次的话题\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: 接着上次的话题" && windows[0].inspector.card.status == "idle" timeout=10s
shot   i2-continued
```

## judge
- 输入的命令是 `cd <会话目录> && claude --resume c1a0de00-…0201`（断言）；没有开新标签（断言）。
- 左栏这一行名为「i2 要恢复的会话」，不是「新会话」（断言）。
- `i2-resumed`：检查器时间线里有之前的两轮（「第 1 轮 · i2 要恢复的会话」「第 2 轮 · 历史会话：再补一段用法」），
  `i2-continued` 里新的一轮排在最上面。
