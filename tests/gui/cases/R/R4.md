# R4 失败命令的报错行来自精确捕获
requires: sandbox
checklist: R4
scenarios: []

一条失败命令输出两行后立刻回到提示符：`error_line` 是输出的最后一行，不会是提示符；终端卡片的 ✦ 近期提到这条命令（`summary_interval` 设为最短的 30 秒：重启时的 pane 检查命令先被总结了一次）。命令用两个 `echo` 造输出，避免在 `type` 里转义反斜杠。

## steps
```gilvt-steps
sh     rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count
# restart 的 pane 检查（echo CHK…）本身就会被总结一次；最短间隔 30 秒后才轮到下面这条失败命令
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=true' --set 'monitor.exclude_paths=[]' --set 'monitor.summary_interval="30s"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "echo ok pkg/a; echo FAIL pkg/cache TestEvictTTL; false\n"
wait   windows[0].tabs[0].panes[0].commands[0].exit == 1 timeout=10s
assert windows[0].tabs[0].panes[0].commands[0].error_line == "FAIL pkg/cache TestEvictTTL"
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"].meta_line == "FAIL pkg/cache TestEvictTTL" timeout=10s
wait   windows[0].monitor.cards[?kind=="terminal"].summary.state == "ready" && windows[0].monitor.cards[?kind=="terminal"].summary.recent contains "FAIL" timeout=75s
assert windows[0].monitor.cards[?kind=="terminal"].summary.recent contains "echo"
assert windows[0].monitor.cards[?kind=="terminal"].summary.goal == ""
shot   r4
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=false' --set 'monitor.summary_interval="2m"'
```

## judge
- `r4`：终端卡片红字「最后一条：✗ echo ok pkg/a; … · exit 1」，下面一行红色等宽「FAIL pkg/cache TestEvictTTL」；✦ 块只有「近期：fake 总结 #N · echo …」。
