# R12 Codex 缺少 shell_tool 时对话拒绝启动，总结照常
requires: sandbox
checklist: R12
scenarios: [codex-basic]

假 `codex features list` 不列 `shell_tool`：对话拒绝启动并说明原因；`codex exec` 的 ✦ 总结不受影响。关掉自动总结，手动按 `s`，不等自动总结。

## steps
```gilvt-steps
sh     "rm -f ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-chat.log ~/.gilvt-fake-brain-count && printf 'features-no-shell\n' > ~/.gilvt-fake-brain"
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=false' --set 'monitor.provider="codex"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r12 && cd -P ~/work/r12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r12"
type   "codex @scenario:codex-basic\n"
key    cmd+shift+o
# 沙盒里监控官标签约 720px（< 760px 会收成竖条）：收起检查器让面板完整出现
key    cmd+i
wait   windows[0].inspector.visible == false && windows[0].monitor.chat.collapsed == false timeout=5s
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=30s
click  'rect(windows[0].monitor.cards[?group=="done"])'
key    s
wait   windows[0].monitor.cards[?group=="done"].summary.state == "ready" timeout=40s
click  'rect(windows[0].monitor.chat.quick[?label=="哪些需要我？"])'
wait   windows[0].monitor.chat.status == "error" timeout=20s
assert windows[0].monitor.chat.provider == "codex"

shot   r12
sh     rm -f ~/.gilvt-fake-brain
# restart 的沙盒检查只看聚焦的 pane：先开一个新标签停在提示符，等布局保存

wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
# 把检查器放回来（ui.json 里的 inspector_hidden 不留给后面的用例）

wait   windows[0].inspector.visible == true timeout=5s
sleep  2s
restart --set 'monitor.enabled=false' --set 'monitor.provider="claude"' --set 'monitor.auto_summary=true'
```
