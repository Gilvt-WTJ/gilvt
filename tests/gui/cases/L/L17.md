# L17 一页看不完时，翻到最后一页才能确认
requires: sandbox
checklist: L17
scenarios: [hist-claude]

一个会话有 22 轮待 Review，一页只显示 20 轮。第一页上「已 Review，下一个」不可用（确认会标记还没看到的 2 轮），并提示翻页；用 `L` 翻到最后一页后才可用（不用 `]`：拼音输入法下它到达的是 `】`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l17 && cd -P ~/work/l17 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l17"
seed   hist-claude --cwd work/l17 --id c1a0de00-0000-4000-8000-0000000b1701 --prompt "l17 很多轮"
sh     'cd "$HOME/work/l17" && i=1 && while [ $i -le 10 ]; do claude --headless --append --session-id c1a0de00-0000-4000-8000-0000000b1701 "@scenario:hist-claude l17 追加 $i" >/dev/null || exit 1; i=$((i + 1)); done'
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b1701"].unreviewed_count == 22 timeout=15s
key    space
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[19] exists && windows[0].overlay.session_review.has_later == true timeout=10s
assert windows[0].overlay.session_review.turns[20] !exists && windows[0].overlay.session_review.actions.review_next.enabled == false && windows[0].overlay.session_review.actions.later.enabled == true
shot   l17-first-page
# ⌘↩ 在第一页什么都不做
key    cmd+enter
sleep  500ms
assert windows[0].overlay.tabs[?name=="review"].count == 1 && windows[0].overlay.session_review != null && windows[0].overlay.store_last_error == null
key    l
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.has_later == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.turns[2] !exists && windows[0].overlay.session_review.actions.review_next.enabled == true
key    cmd+enter
wait   windows[0].overlay.session_review == null && windows[0].overlay.rows[0] !exists timeout=10s
key    esc
wait   windows[0].overlay == null
```

## judge
- `l17-first-page`：底部「已 Review，下一个」是灰的，旁边有提示「还有更晚的 turn：翻到最后一页（L）后才能确认」；页尾有按钮「更新的 turn L」。
