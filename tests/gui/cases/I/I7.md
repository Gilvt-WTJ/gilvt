# I7 ⌘R 改名、清空还原、原样 ⏎ 不改名
requires: sandbox
checklist: I7
scenarios: [default]

会话仍在本次运行中，所以改名同时出现在浮层与左栏。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i7 && cd -P ~/work/i7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i7"
type   "claude @scenario:default i7 原来的名字\n"
wait   windows[0].sidebar.rows[?section=="project:i7"].name == "i7 原来的名字" && windows[0].inspector.card.status == "idle" timeout=15s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+r
shot   i7-rename-field
# 改名框预填当前名字（8 个字符），只能在末尾删除
key    backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace
type   "测试改名\n"
shot   i7-renamed
key    esc
wait   windows[0].overlay == null && windows[0].sidebar.rows[?section=="project:i7"].name == "测试改名" timeout=5s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+r
key    backspace backspace backspace backspace backspace backspace
key    enter
key    esc
wait   windows[0].overlay == null && windows[0].sidebar.rows[?section=="project:i7"].name == "i7 原来的名字" timeout=5s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+r
key    enter
key    esc
wait   windows[0].overlay == null
assert windows[0].sidebar.rows[?section=="project:i7"].name == "i7 原来的名字"
```

## judge
- `i7-rename-field`：该行变成改名框，预填「i7 原来的名字」。`i7-renamed`：浮层里这一行显示「测试改名」。
- 左栏名字的三次变化都由断言核对：改名、清空后回到首条提示词、在首条提示词上原样 `⏎` 仍是首条提示词。
- 如果按 `⏎` 提交改名后浮层也一起关闭了，后面的 `key esc` 无害。
