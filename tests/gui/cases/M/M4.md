# M4 ⌘⇧N 勾选「在新 worktree 中运行」：创建、命名；失败时面板内报错且不启动
requires: sandbox
checklist: M4
scenarios: [default]

目录在 git 仓库里时，`⌘⇧N` 面板多一行「在新 worktree 中运行（⌥W）」（`overlay.worktree`：未勾 `false`、勾上 `true`、不在仓库里 `null`）。
勾上后 `↩`：在 `<仓库>.worktrees/<分支名，/ 换成 ->` 建 worktree，分支名 `gilvt/<任务的 slug>-<4 位十六进制>`，agent 在那个目录里起来。
建不出来时（这里让 `<仓库>.worktrees` 已经是一个普通文件）面板保持打开，红色提示写在 `overlay.error`，不启动任何东西。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# --- 失败：<仓库>.worktrees 是个文件，建不了 ---
sh     'git init -q -b main ~/work/k4c && cd ~/work/k4c && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m init && touch ~/work/k4c.worktrees'
type   "cd -P ~/work/k4c && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k4c"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.worktree == false timeout=10s
type   "冲突任务"
key    alt+w
wait   windows[0].overlay.worktree == true timeout=3s
key    enter
wait   windows[0].overlay.error contains "k4c.worktrees" timeout=15s
assert windows[0].overlay.kind == "new_agent"
assert windows[0].tabs[*] exists count=1
assert windows[0].tabs[0].panes[*] exists count=1
assert windows[0].tabs[0].panes[0].foreground == "shell"
assert windows[0].sidebar.rows[?kind=="agent"] !exists
shot   k4-error
key    esc
wait   windows[0].overlay == null
# --- 成功：普通仓库 ---
sh     'git init -q -b main ~/work/k4 && cd ~/work/k4 && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m init'
type   "cd -P ~/work/k4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k4"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.worktree == false timeout=10s
type   "fix login bug"
key    alt+w
wait   windows[0].overlay.worktree == true timeout=3s
shot   k4-checked
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=30s
# 路径与分支名：<仓库>.worktrees/gilvt-fix-login-bug-<4 位>，分支 gilvt/fix-login-bug-<4 位>
# pane 的 cwd 字段在 agent 运行期间不更新（OSC 7 只在 shell 提示符处发），所以用屏幕上的 `cd … && claude` 行来证明目录
assert windows[0].tabs[0].panes[0].screen_tail[*] contains "/work/k4.worktrees/gilvt-fix-login-bug-"
wait   windows[0].sidebar.rows[?name=="fix login bug"].git.linked_worktree == true timeout=30s
assert windows[0].sidebar.rows[?name=="fix login bug"].git.branch contains "gilvt/fix-login-bug-"
assert windows[0].sidebar.rows[?name=="fix login bug"].section == "project:k4"
sh     'git -C ~/work/k4 worktree list | grep -q "/work/k4.worktrees/gilvt-fix-login-bug-"'
sh     'git -C ~/work/k4 branch --list "gilvt/fix-login-bug-*" | grep -q .'
sh     'test -d ~/work/k4.worktrees && ls ~/work/k4.worktrees | grep -Eq "^gilvt-fix-login-bug-[0-9a-f]{4}$"'
shot   k4-created
```

## judge
- `k4-error`：面板仍在，任务框里的字还在，勾选框已勾上，面板里有一行红字「无法创建 …/work/k4c.worktrees：…」；终端没有新命令，没有新标签 / pane（断言）。
- `k4-checked`：面板里有「☑ 在新 worktree 中运行（⌥W）」；预览行不变。
- `k4-created`：pane 在 `…/work/k4.worktrees/gilvt-fix-login-bug-xxxx` 里跑着 claude，左栏该会话归「k4」分区，git 行是 `k4.worktrees 下的目录名 · ⎇ gilvt/fix-login-bug-xxxx`（`xxxx` 是 4 位十六进制，每次不同）。
- 主目录 `~/work/k4` 没有被改动（`git status` 干净，仍在 `main`；worktree 从当前 HEAD 派生）。
