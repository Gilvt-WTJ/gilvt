# H9 Codex update_plan 整体替换 TODO
requires: sandbox
checklist: H9
scenarios: [timeline-codex]

`timeline-codex` 在一轮里调用四次 `update_plan`：TODO 块每次整体替换为最新的 plan，而不是追加。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h9 && cd -P ~/work/h9 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h9"
type   "codex @scenario:timeline-codex\n"
# cargo test 运行 4 秒：这时 plan 是 ☑ 读代码、☑ 改代码、◐ 跑测试
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" && windows[0].sidebar.rows[?section=="project:h9"].detail contains "cargo test" timeout=15s
shot   h9-progress
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Refactored greet()" timeout=15s
shot   h9-done
```

## judge
- `h9-progress`：只有一个 TODO 块、三项：「☑ 读代码」「☑ 改代码」「◐ 跑测试」（不是 3 + 3 + 3 项的累积）。
- `h9-done`：同一个块三项都是 ☑，标题「TODO · 3 / 3」。
