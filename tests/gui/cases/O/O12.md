# O12 状态色被回退的主题仍清晰
requires: sandbox
checklist: O12
scenarios: [approve-bash]

`Atlas Ragnarok` 的 `attention` 状态色在快照（`crates/gilvt-theme/tests/fallbacks.snap`）里被回退；用一个停在审批的 `approve-bash` 会话检查「需要你」。

## steps
```gilvt-steps
restart --set 'theme="Atlas Ragnarok"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "Atlas Ragnarok"
type   "mkdir -p ~/work/o12 && cd -P ~/work/o12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/o12"
type   "claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 timeout=15s
shot   o12
restart --set 'theme="light"'
```

## judge
- `o12`：pane 有清晰的黄色描边；左栏「需要你」分组的状态文字是可读的黄色 / 琥珀色，与背景对比明显。
