# L1 Session Center 列表、搜索与兼容入口
requires: sandbox
checklist: L1
scenarios: [hist-claude, hist-codex]

先让空沙盒完成首次 History refresh 和 Review baseline，再写入两个新的历史 session。`⌘⇧R` 仍默认显示 M3c
「全部会话」，`⌘2` 进入待 Review 队列。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.store_initialized == true && windows[0].overlay.refreshing == false timeout=15s
key    esc
wait   windows[0].overlay == null
seed   hist-claude --cwd work/l1 --id c1a0de00-0000-4000-8000-000000000b01 --prompt "l1 Claude review"
seed   hist-codex --cwd work/l1 --id 01990000-0000-7000-8000-000000000b01 --prompt "l1 Codex review"
type   "cd -P ~/work/l1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l1"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
assert windows[0].overlay.tabs[?name=="review"].count == 2 && windows[0].overlay.rows[0].selected == true
shot   l1-review
key    down
wait   windows[0].overlay.rows[1].selected == true
type   "Codex"
wait   windows[0].overlay.query == "Codex" && windows[0].overlay.rows[0].session_key contains "01990000" && windows[0].overlay.rows[1] !exists
shot   l1-search
key    esc
wait   windows[0].overlay.query == "" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists
key    cmd+4
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=5s
shot   l1-all
key    esc
wait   windows[0].overlay == null
```

## judge
- 「待 Review」页显示四个 tab、排序控件和两行 session；每行包含 Agent、项目、待 Review 轮数、工具/修改摘要和状态。
- 方向键只移动 Session Center selection，不进入 terminal；搜索只保留 Codex 行。
- `⌘4` 回到原「全部会话」界面，原搜索、恢复、重命名和清理能力没有被替换。
