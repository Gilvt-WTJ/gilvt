# Y8 方向键选卡片，⏎ 跳过去
requires: sandbox
checklist: Y8
scenarios: []

方向键选中卡片，⏎ 把焦点交给那张卡片的 pane 的终端：之后打的字进了终端。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"] exists count=1 timeout=10s
key    down
wait   windows[0].monitor.cards[0].selected == true timeout=5s
key    enter
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].focused == true timeout=5s
type   "echo y8-ok\n"
wait   windows[0].tabs[1].panes[0].screen_tail[*] contains "y8-ok" timeout=10s
```
