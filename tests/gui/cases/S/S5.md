# S5 config.toml 写了 language 时优先于系统语言
requires: sandbox
checklist: S5
scenarios: []

沙盒配置里是 `language = "zh-CN"`，系统假装是英文：以配置为准，界面中文，来源是 `config`。

## steps
```gilvt-steps
restart --set 'language="zh-CN"' --env GILVT_TEST_SYSTEM_LANGUAGE=en-US
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
raise
key    cmd+,
wait   settings.key == true && settings.language == "zh-CN" timeout=5s
assert settings.language_source == "config"
assert settings.pages[?id=="language"].label == "文A 语言"
key    cmd+w
restart
```
