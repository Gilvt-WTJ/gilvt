# R10 设置窗口写回只改一行，外部修改同步
requires: sandbox
checklist: R10
scenarios: []

`⌘,` 打开设置（窗口唯一：已打开时再按 `⌘,` 只聚焦；第一次停在「外观」页，点左栏换到「◎ 监控官」）；手改 config.toml 后页面同步；在下拉里选模型只改那一行（行尾注释、其他注释都在）；语法错误时只读并保留上次有效值，修好后可以再改；`⌘W` 关闭、`⌘,` 重新打开。结束时恢复原来的 config.toml。

## steps
```gilvt-steps
sh     'cp ~/.config/gilvt/config.toml ~/r10-orig.toml'
restart --set 'monitor.enabled=true'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# 设置窗口唯一：打开前没有 settings；开着时再按一次 ⌘, 不会多出第二个窗口
assert settings !exists
key    cmd+,
wait   settings.page == "appearance" && settings.key == true timeout=5s
click  'rect(settings.pages[?id=="monitor"])'
wait   settings.page == "monitor" timeout=5s
state  settings.id
key    cmd+,
sleep  1s
assert settings.key == true
state  settings.id
assert settings.readonly == false
assert settings.fields[?id=="enabled"].value == true
# 外部改 config.toml：页面在去抖之后跟着刷新
sh     'printf "%s\n" "# 我的注释：监控官" "model = \"opus\"  # 行尾注释" >> ~/.config/gilvt/config.toml'
wait   settings.fields[?id=="model"].value == "opus" timeout=5s
sh     'cp ~/.config/gilvt/config.toml ~/r10-before.toml'
# 在下拉里选 sonnet：只有 model 这一行变
click  'rect(settings.fields[?id=="model"])'
wait   settings.fields[?id=="model"].open == true timeout=3s
click  'rect(settings.fields[?id=="model"].options[?label=="sonnet"])'
wait   settings.fields[?id=="model"].value == "sonnet" timeout=3s
sleep  1s
sh     'grep -qx "model = \"sonnet\"  # 行尾注释" ~/.config/gilvt/config.toml'
sh     'grep -qx "# 我的注释：监控官" ~/.config/gilvt/config.toml'
sh     'grep -q "^# gilvt GUI test sandbox" ~/.config/gilvt/config.toml'
sh     'test "$(diff ~/r10-before.toml ~/.config/gilvt/config.toml | grep -c "^[<>]")" = 2'
shot   r10-written
sh     'printf "%s\n" "summary_interval = \"5m\"" >> ~/.config/gilvt/config.toml'
wait   settings.fields[?id=="summary_interval"].value == "5m" timeout=5s
assert settings.fields[?id=="summary_interval"].options[?label=="5m"].selected == true
# 语法错误：只读、黄条、模型仍是上次有效的 sonnet
sh     'cp ~/.config/gilvt/config.toml ~/r10-good.toml && printf "%s\n" "oops =" >> ~/.config/gilvt/config.toml'
wait   settings.readonly == true timeout=5s
assert settings.error contains "config.toml"
assert settings.fields[?id=="model"].value == "sonnet"
shot   r10-readonly
# 修好之后恢复可写，并且可以再改
sh     'cp ~/r10-good.toml ~/.config/gilvt/config.toml'
wait   settings.readonly == false timeout=5s
assert settings.error == null
click  'rect(settings.fields[?id=="summary_interval"].options[?label=="10m"])'
wait   settings.fields[?id=="summary_interval"].value == "10m" timeout=3s
sleep  1s
sh     'grep -qx "summary_interval = \"10m\"" ~/.config/gilvt/config.toml'
sh     'grep -qx "model = \"sonnet\"  # 行尾注释" ~/.config/gilvt/config.toml'
# ⌘W 关掉的是唯一的那个设置窗口（若多开了一个，settings 仍然存在）；重开后停在上次看的「◎ 监控官」，状态一致
key    cmd+w
wait   settings !exists timeout=5s
key    cmd+,
wait   settings.page == "monitor" && settings.key == true timeout=5s
assert settings.fields[?id=="model"].value == "sonnet"
assert settings.fields[?id=="summary_interval"].value == "10m"
key    cmd+w
wait   settings !exists timeout=5s
# restart 的沙盒检查只看聚焦的 pane：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
sh     'cp ~/r10-orig.toml ~/.config/gilvt/config.toml && rm -f ~/r10-orig.toml ~/r10-before.toml ~/r10-good.toml'
restart
```

## judge
- `r10-written`：独立的「设置」窗口，左侧两页「◐ 外观」「◎ 监控官」，「◎ 监控官」是紫底的当前页；右侧四个分区（总开关、模型、✦ AI 总结、隐私）与界面稿 `s2-settings.html` 一致；「对话模型」下拉显示 sonnet；页脚写着 config.toml 的路径和「在编辑器中打开」。
- `r10-readonly`：页面顶部黄色提示，含 config.toml 的路径和语法错误原因，后面是「在编辑器中打开」；所有控件变灰、点不动；「对话模型」仍是 sonnet。
- 两次 `state settings.id` 的输出相同（同一个窗口，没有多开）。
