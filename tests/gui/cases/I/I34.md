# I34 待 Review 不含归档的会话；「标记已 Review 并归档」（⇧⌘E）
requires: sandbox
checklist: I34
scenarios: [hist-claude]

三个刚完成、没有 Review 的会话都进「待 Review」。在会话面板里 `⌘E` 归档其中一个：它离开队列，Session Center 的 tab 计数与左栏
「待 Review N」都少一个。打开另一个的 Review，按 `⇧⌘E`（「标记已 Review 并归档」）：它被标记为已 Review 并归档，离开队列，
Review 接着打开下一项。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/i34 && cd -P ~/work/i34 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i34"
seed   hist-claude --cwd work/i34 --id c1a0de00-0000-4000-8000-000000003401 --prompt "i34 甲"
seed   hist-claude --cwd work/i34 --id c1a0de00-0000-4000-8000-000000003402 --prompt "i34 乙"
seed   hist-claude --cwd work/i34 --id c1a0de00-0000-4000-8000-000000003403 --prompt "i34 丙 先归档"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.tabs[?name=="review"].count == 3 timeout=15s
wait   windows[0].sidebar.review_entry.count == 3 timeout=5s
# 在全部会话里归档丙
key    cmd+4
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=5s
type   "i34 丙"
wait   windows[0].overlay.items == 1 && windows[0].overlay.rows[0].title contains "i34 丙" timeout=5s
key    cmd+e
wait   windows[0].overlay.banner == "已归档 1 个会话" && windows[0].overlay.items == 0 timeout=3s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.tabs[?name=="review"].count == 2 timeout=10s
assert windows[0].overlay.rows[?session_key contains "3403"] !exists && windows[0].overlay.rows[?session_key contains "3401"] exists && windows[0].overlay.rows[?session_key contains "3402"] exists
# 队列行也显示会话目录（与会话浮层同样缩短：沙盒 HOME 是 /var/… 的符号链接，仍显示 `~`）
assert windows[0].overlay.rows[?session_key contains "3401"].dir == "~/work/i34" && windows[0].overlay.rows[?session_key contains "3401"].dir_missing == false
wait   windows[0].sidebar.review_entry.count == 2 timeout=5s
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i34-queue
# 打开第一项的 Review，⇧⌘E：标记已 Review 并归档，接着打开下一项
key    space
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.actions.review_next_archive.enabled == true timeout=10s
sleep  1s
shot   i34-review
key    cmd+shift+e
wait   windows[0].overlay.tabs[?name=="review"].count == 1 && windows[0].overlay.rows[1] !exists timeout=10s
# 下一项（队列里剩下的那一个）的 Review 已经打开
wait   windows[0].overlay.session_review.session_key contains "c1a0de00-0000-4000-8000-00000000340" && windows[0].overlay.session_review.loading == false timeout=10s
assert windows[0].overlay.store_last_error == null && windows[0].overlay.session_review.notice == null
sh     'python3 -c "import json,sys; s=json.load(open(sys.argv[1]))[\"sessions\"]; done=[k for k in (\"3401\",\"3402\") if \"archived_at\" in s[\"claude:c1a0de00-0000-4000-8000-00000000\" + k] and \"reviewed_through\" in s[\"claude:c1a0de00-0000-4000-8000-00000000\" + k]]; sys.exit(0 if len(done) == 1 else 1)" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
key    esc
key    esc
wait   windows[0].overlay == null
wait   windows[0].sidebar.review_entry.count == 1 timeout=5s
# 两个归档的会话都不在默认列表里
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    esc
wait   windows[0].overlay == null
```

## judge
- `i34-queue`：「待 Review」tab 写 2，列表里没有「i34 丙 先归档」；每行标题下的灰字以目录开头「~/work/i34 · Claude …」；左栏标题下「待 Review 2」。
- `i34-review`：Review 底部的按钮里有「标记已 Review 并归档 ⇧⌘E」（与「已 Review，下一个」并列）。
  标题下的灰字是「~/work/i34 · Claude · 未 Review · N 轮」。
