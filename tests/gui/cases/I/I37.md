# I37 其他终端与导航失败降级
requires: manual
checklist: I37
scenarios: []

## steps
```gilvt-steps
# 手动：在 Warp 或 VS Code 终端中运行测试 Agent，从 Session Center 按回车跳转
# 手动：准备终端已关闭但 gilvt 尚未完成下一次轮询的短暂场景，再次尝试跳转
# 手动：核对前台应用、失败提示和剪贴板中的 PID/TTY，并确认 gilvt 没有执行 resume
```

## judge
- 能识别终端应用时，`↩` 至少把该应用激活到前台。
- 无法定位时，gilvt 顶部显示失败提示并说明 PID/TTY 已复制。
- 粘贴板含 PID 和 TTY，gilvt 不执行任何 `resume` 命令。
