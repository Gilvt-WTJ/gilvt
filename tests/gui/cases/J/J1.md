# J1 统一视图拖选并 ⌘C
requires: sandbox
checklist: J1
scenarios: []

Quick Look 的统一 diff 视图里从第 2 行拖到第 4 行（删除行、新增行），选区文字与源码一致（Tab 保持为 Tab），`⌘C` 复制。会覆盖用户的剪贴板。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j1 && cd work/j1 && git init -q && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 2;\n\tlet c = a + b;\n}\n' > main.rs && git add main.rs && git -c user.name=t -c user.email=t@t commit -qm init && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 3;\n\tlet c = a + b;\n}\n' > main.rs"
type   "cd -P ~/work/j1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j1"
type   "gilvt view main.rs\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.base == "与 HEAD 相比" && windows[0].overlay.code exists timeout=10s
assert windows[0].overlay.mode == "unified" && windows[0].overlay.selection == null
# rect(…) 是矩形的中心，偏移加在中心上。代码区 (265,107,670,524)：起点在第 2 行行号槽里（偏移 0），终点在第 4 行行尾之外；行高 16 点
drag   'rect(windows[0].overlay.code)+(-330,-238)' 'rect(windows[0].overlay.code)+(200,-206)'
wait   windows[0].overlay.selection contains "let a = 1;" && windows[0].overlay.selection contains "let b = 2;" && windows[0].overlay.selection contains "let b = 3;" timeout=5s
shot   j1-selected
key    cmd+c
clipboard contains "let a = 1;"
clipboard contains "let b = 3;"
# Tab 保持为 Tab：剪贴板第一行的第一个字符是 TAB
sh     "test \"$(pbpaste | head -c1 | od -An -c | tr -d ' ')\" = '\\t'"
```

## judge
- `j1-selected`：第 2–4 行有选区高亮，终点那行高亮到行尾。
- 点是 `overlay.code` 中心加偏移（窗口 1280×648 时代码区为 (265,107,670,524)，行高 16 点，第 n 行中心 y = 107+16n+8）；窗口大小或行高变了、选中的行数不对时，按实际值调整偏移后重跑。
- 会覆盖用户的剪贴板（报告里注明）。
