# L2 首次启用不灌满队列：旧会话只在「全部会话」里
requires: sandbox
checklist: L2
scenarios: [hist-claude, hist-codex]

沙盒启动时已经完成了首次完整扫描和 baseline（`initialized_at`）。之后才出现、但最后一轮早于它完成的会话（`--age 3d`）当作「已经看过」，
不进待 Review，只在「全部会话」里；`initialized_at` 之后才完成的会话正常进队列。先清空会话记录，保证这个用例只看自己写入的会话。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l2 && cd -P ~/work/l2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l2"
seed   hist-claude --age 3d --cwd work/l2 --id c1a0de00-0000-4000-8000-0000000b0201 --prompt "l2 旧 Claude"
seed   hist-codex --age 3d --cwd work/l2 --id 01990000-0000-7000-8000-0000000b0201 --prompt "l2 旧 Codex"
seed   hist-claude --cwd work/l2 --id c1a0de00-0000-4000-8000-0000000b0202 --prompt "l2 新 Claude"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b0202"] exists timeout=15s
assert windows[0].overlay.store_initialized == true && windows[0].overlay.rows[0] exists && windows[0].overlay.rows[1] !exists
assert windows[0].overlay.tabs[?name=="review"].count == 1 && windows[0].overlay.store_pending_count == 1
assert windows[0].overlay.rows[?session_key contains "0b0201"] !exists
shot   l2-review
key    cmd+4
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=5s
shot   l2-all
key    esc
wait   windows[0].overlay == null
```

## judge
- 「待 Review」只有一行（`l2 新 Claude`）；两个 3 天前的旧会话没有出现在队列里，但在「全部会话」里能看到（共 3 行），可以照常恢复、搜索。
- 左栏标题下的「待 Review」入口数字是 1。
