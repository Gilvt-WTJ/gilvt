# J3 单击不留选区，切换 / 刷新后清除
requires: sandbox
checklist: J3
scenarios: []

单击代码不留选区（单击会清除已有选区）；拖出选区后 `U`（切换统一 / 并排）、`R`（刷新）都会清除它。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j3 && cd work/j3 && git init -q && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 2;\n\tlet c = a + b;\n}\n' > main.rs && git add main.rs && git -c user.name=t -c user.email=t@t commit -qm init && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 3;\n\tlet c = a + b;\n}\n' > main.rs"
type   "cd -P ~/work/j3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j3"
type   "gilvt view main.rs\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.base == "与 HEAD 相比" && windows[0].overlay.code exists timeout=10s
drag   'rect(windows[0].overlay.code)+(-330,-238)' 'rect(windows[0].overlay.code)+(200,-206)'
wait   windows[0].overlay.selection != null timeout=5s
click  'rect(windows[0].overlay.code)+(0,-206)'
wait   windows[0].overlay.selection == null timeout=5s
drag   'rect(windows[0].overlay.code)+(-330,-238)' 'rect(windows[0].overlay.code)+(200,-206)'
wait   windows[0].overlay.selection != null timeout=5s
key    u
wait   windows[0].overlay.mode == "split" && windows[0].overlay.selection == null timeout=5s
drag   'rect(windows[0].overlay.code)+(5,-222)' 'rect(windows[0].overlay.code)+(300,-222)'
wait   windows[0].overlay.selection != null timeout=5s
key    r
wait   windows[0].overlay.selection == null timeout=5s
```

## judge
- 只有状态断言，不需要截图判断。展开折叠行后清除选区需要带折叠的长文件，不在本用例内，手动检查。
