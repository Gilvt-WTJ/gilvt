# H14 检查器折叠、宽度限制与重开后保持
requires: sandbox
checklist: H14
scenarios: []

`⌘I` 折叠 / 展开；拖动分界线到两端，宽度被限制在 240–560；三个标签都能切换；重启 gilvt 后宽度与折叠状态保持。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert windows[0].inspector.visible == true
key    cmd+i
wait   windows[0].inspector.visible == false
key    cmd+i
wait   windows[0].inspector.visible == true
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts"
key    cmd+alt+3
wait   windows[0].inspector.tab == "config" && windows[0].inspector.config.empty == "shell"
shot   h14-tabs
key    cmd+alt+1
wait   windows[0].inspector.tab == "process"
shot   h14-before-drag
drag   'rect(windows[0].dividers[?between=="center|inspector"])' 'rect(windows[0].dividers[?between=="center|inspector"])+(-700,0)'
wait   windows[0].inspector.width == 560 timeout=3s
sh     "grep -q '\"inspector_width\": 560' 'Library/Application Support/gilvt/state/ui.json'"
shot   h14-widest
# 往右 700 点仍在窗口里：分界线此时在窗口右边缘左侧 560 点处
drag   'rect(windows[0].dividers[?between=="center|inspector"])' 'rect(windows[0].dividers[?between=="center|inspector"])+(500,0)'
wait   windows[0].inspector.width == 240 timeout=3s
sh     "grep -q '\"inspector_width\": 240' 'Library/Application Support/gilvt/state/ui.json'"
shot   h14-narrowest
key    cmd+i
wait   windows[0].inspector.visible == false
sh     "grep -q '\"inspector_hidden\": true' 'Library/Application Support/gilvt/state/ui.json'"
restart
wait   windows[0].inspector.visible == false timeout=15s
key    cmd+i
wait   windows[0].inspector.visible == true
shot   h14-after-restart
# 还原默认的检查器设置，免得影响后面的用例
sh     "rm -f 'Library/Application Support/gilvt/state/ui.json'"
restart
```

## judge
- `h14-tabs`：普通 shell 下「配置」显示空状态；断言已核对三个标签都能切换。
- `h14-widest` / `h14-narrowest`：检查器宽度分别为 560 与 240 点（`inspector.width` 与 `ui.json` 的断言已核对；拖过头也不会
  更宽或更窄），截图里分界线的位置与之相符。
- `h14-after-restart`：重启后检查器仍是折叠的（断言），`⌘I` 展开后宽度与 `h14-narrowest` 相同（240）。
- 拖动是前台动作；锁屏时 `drag` 退出 5，宽度部分记为 ⏭。
