# L18 带修饰键的字母不是 Review 快捷键
requires: sandbox
checklist: L18
scenarios: [hist-claude]

在 Review 里按 `⌘S`、`⌘Z`、`⌥P`：什么都不发生（不跳过、不打开提醒菜单、不写入置顶）。不带修饰键的 `S` 仍然跳过。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l18 && cd -P ~/work/l18 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l18"
seed   hist-claude --cwd work/l18 --id c1a0de00-0000-4000-8000-0000000b1801 --prompt "l18 甲"
seed   hist-claude --cwd work/l18 --id c1a0de00-0000-4000-8000-0000000b1802 --prompt "l18 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
key    space
wait   windows[0].overlay.session_review.session_key contains "0b1801" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
key    cmd+s
key    cmd+z
key    alt+p
sleep  700ms
assert windows[0].overlay.session_review.session_key contains "0b1801" && windows[0].overlay.session_review.snooze_menu == false && windows[0].overlay.session_review.pinned == false && windows[0].overlay.rows[0].pinned == false
assert windows[0].overlay.tabs[?name=="review"].count == 2 && windows[0].overlay.store_last_error == null
sh     'test ! -e "$HOME/Library/Application Support/gilvt/state/reviews.json" || awk "/0b180[12]/{f=1} f&&/pinned|snoozed_until|reviewed_through/{bad=1} f&&/^    }/{f=0} END{exit bad}" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
# 不带修饰键的 S 仍然跳过
key    s
wait   windows[0].overlay.session_review.session_key contains "0b1802" && windows[0].overlay.session_review.loading == false timeout=10s
key    esc
key    esc
wait   windows[0].overlay == null
```

## judge
- 修饰键组合期间 Review 没有任何变化；回到终端后输入行是干净的。
