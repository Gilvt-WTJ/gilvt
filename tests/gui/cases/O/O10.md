# O10 「外观」页：config.toml 只读
requires: sandbox
checklist: O10
scenarios: []

`config.toml` 只读时点一个主题：主题照样在所有窗口生效，页面顶部红色提示先写「config.toml 是只读的」，文件路径在下一行；文件不变。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "cp .config/gilvt/config.toml o10-before.toml && chmod 444 .config/gilvt/config.toml"
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="appearance"])'
wait   settings.page == "appearance" timeout=5s
click  'rect(settings.appearance.search_rect)'
type   --window key "nord"
wait   settings.appearance.rows[?name=="Nord"].rect != null timeout=5s
click  'rect(settings.appearance.rows[?name=="Nord"])'
wait   theme.name == "Nord" timeout=5s
wait   settings.write_error contains "config.toml 是只读的" timeout=5s
assert settings.readonly == false
sh     "cmp -s .config/gilvt/config.toml o10-before.toml"
shot   --window key o10
key    cmd+w
wait   settings !exists timeout=5s
assert theme.name == "Nord"
# restart --set 要改 config.toml，先恢复可写
sh     "chmod 644 .config/gilvt/config.toml && rm -f o10-before.toml"
restart --set 'theme="light"'
```

## judge
- `o10`：设置窗口已是 Nord 的深色；页面顶部红色提示第一行以「config.toml 是只读的，没有写入（修改已在本次运行中生效）」开头、完整可见，下一行是灰色的文件路径。
