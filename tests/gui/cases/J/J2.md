# J2 并排视图只复制所在那一半
requires: sandbox
checklist: J2
scenarios: []

`U` 切到并排，从右半边（新文本）拖选改动行，只得到右半边的文字；`⌘C` 复制。会覆盖用户的剪贴板。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j2 && cd work/j2 && git init -q && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 2;\n\tlet c = a + b;\n}\n' > main.rs && git add main.rs && git -c user.name=t -c user.email=t@t commit -qm init && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 3;\n\tlet c = a + b;\n}\n' > main.rs"
type   "cd -P ~/work/j2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j2"
type   "gilvt view main.rs\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.base == "与 HEAD 相比" && windows[0].overlay.code exists timeout=10s
key    u
wait   windows[0].overlay.mode == "split" timeout=5s
# 改动行是并排的第 3 行（行下标 2，y=147）；偏移加在 overlay.code 的中心 (600,369) 上：起点在右半边（x≥595）的行号槽里，终点越过行尾
drag   'rect(windows[0].overlay.code)+(5,-222)' 'rect(windows[0].overlay.code)+(300,-222)'
wait   windows[0].overlay.selection == "\tlet b = 3;" timeout=5s
shot   j2-selected
key    cmd+c
clipboard contains "let b = 3;"
```

## judge
- `j2-selected`：只有右半边的 `let b = 3;` 高亮，左半边的 `let b = 2;` 没有。
- 起点 x=605 假设右半边从 x≈595 开始（代码区宽 670、中心 x=600）；窗口宽度不同时按 `overlay.code` 的宽度调整。
- 会覆盖用户的剪贴板（报告里注明）。
