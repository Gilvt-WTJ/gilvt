# I12 会话记录或目录不存在时不开 pane
requires: sandbox
checklist: I12
scenarios: [hist-claude]

浮层打开期间把一个会话记录 `mv` 走、把另一个会话的 cwd 改名，然后对它们按 `↩`。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i12 --age 2h --id c1a0de00-0000-4000-8000-000000001201 --prompt "i12 留下的会话"
seed   hist-claude --cwd work/i12 --age 1h --id c1a0de00-0000-4000-8000-000000001202 --prompt "i12 被移走的会话"
seed   hist-claude --cwd work/i12-gone --age 3h --id c1a0de00-0000-4000-8000-000000001203 --prompt "i12 目录被改名"
type   "cd -P ~/work/i12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i12"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 && windows[0].overlay.selected == 0 timeout=15s
# 第一行是最近的「i12 被移走的会话」
sh     "mv .claude/projects/*-work-i12/c1a0de00-0000-4000-8000-000000001202.jsonl ~/i12-moved.jsonl"
key    enter
wait   windows[0].overlay.items == 1 timeout=10s
assert windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].foreground == "shell"
shot   i12-transcript-gone
type   "i12-gone"
wait   windows[0].overlay.query == "i12-gone" && windows[0].overlay.items == 1 timeout=5s
sh     "mv work/i12-gone work/i12-renamed"
key    enter
sleep  1s
assert windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].foreground == "shell"
shot   i12-dir-gone
key    esc
```

## judge
- `i12-transcript-gone`：提示「该会话已不存在」，列表刷新后只剩「i12 留下的会话」（断言 `items == 1`）；没有开 pane、
  shell 里没有输入任何命令（断言）。
- `i12-dir-gone`：提示「会话目录已不存在：…/work/i12-gone」；同样不开 pane。提示可能在浮层里，也可能在窗口顶部的错误横幅里
  （点击才关闭，见已知限制）。
