# H18 ⌘K 之后的锚点
requires: sandbox
checklist: H18
scenarios: [timeline]

`echo early` 已滚出屏幕、`echo late` 仍在屏幕上时按 `⌘K` 清空回滚缓冲：点击前者提示「已超出回滚范围」且不跳转；后者照常跳转。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h18 && cd -P ~/work/h18 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h18"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
assert windows[0].tabs[0].panes[0].screen_tail[*] != "⏺ Bash(echo early)"
assert windows[0].tabs[0].panes[0].screen_tail[*] == "⏺ Bash(echo late)"
key    cmd+k
shot   h18-cleared
click  'rect(windows[0].inspector.rows[?label contains "echo early"])'
wait   windows[0].inspector.toast == "已超出回滚范围" timeout=3s
shot   h18-out-of-range
assert windows[0].tabs[0].panes[0].screen_tail[*] != "⏺ Bash(echo early)"
assert windows[0].tabs[0].panes[0].screen_tail[*] == "⏺ Bash(echo late)"
click  'rect(windows[0].inspector.rows[?label contains "echo late"])'
shot   h18-late
assert windows[0].tabs[0].panes[0].screen_tail[*] == "⏺ Bash(echo late)"
```

## judge
- `h18-out-of-range`：出现「已超出回滚范围」提示，终端画面与 `h18-cleared` 相同（没有跳转，断言也确认了）。
- `h18-late`：`⏺ Bash(echo late)` 起 3 行高亮（1 秒内拍到才算；没拍到记 ⚠️）。
- `⌘K` 不向 fake claude 写入任何字符：`❯` 后面仍然是空的。
