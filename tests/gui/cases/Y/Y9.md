# Y9 重启后监控官标签恢复
requires: sandbox
checklist: Y9
scenarios: []

打开监控官后切回终端标签再重启：重启后最左仍是监控官标签，活动的仍是终端标签。重启前切回终端，是因为 `restart` 的沙盒安全检查
只看聚焦的 pane 是否为沙盒 shell；监控官标签本身是活动标签时的恢复由单元测试 `restored_active` 覆盖。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+shift+o
wait   windows[0].tabs[0].panes[0].kind == "monitor" && windows[0].tabs[0].active == true
key    cmd+2
wait   windows[0].tabs[1].active == true && windows[0].layout.monitor == true && windows[0].layout.monitor_active == false timeout=10s
# 布局每秒保存一次：等它写进 workspace.json 再重启
sleep  2s
restart
wait   windows[0].tabs[0].panes[0].kind == "monitor" timeout=20s
assert windows[0].layout.monitor == true
assert windows[0].tabs[1].panes[0].kind == "terminal"
assert windows[0].tabs[1].active == true
```
