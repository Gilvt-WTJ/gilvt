# O2 内置主题：终端和外框一起换色
requires: sandbox
checklist: O2
scenarios: []

## steps
```gilvt-steps
restart --set 'theme="Catppuccin Mocha"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "Catppuccin Mocha"
assert theme.dark == true
assert theme.source == "builtin"
assert windows[0].inspector.visible == true
shot   o2
restart --set 'theme="light"'
```

## judge
- `o2`：终端背景深紫灰（#1e1e2e）；左栏、标签栏、检查器都是同色调的深色，没有残留的 gilvt 灰色块。
