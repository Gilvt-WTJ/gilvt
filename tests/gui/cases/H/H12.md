# H12 历史轮次列表与就地展开
requires: sandbox
checklist: H12
scenarios: [three-turns]

`three-turns` 连续跑三轮：第 1 轮成功、第 2 轮 API 错误、第 3 轮是当前轮。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h12 && cd -P ~/work/h12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h12"
type   "claude @scenario:three-turns\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "测试通过。" timeout=15s
assert windows[0].inspector.card.turn == 3
shot   h12
assert windows[0].inspector.rows[?kind=="history_turn"] exists count=2
click  'rect(windows[0].inspector.rows[?label contains "第 1 轮"])'
wait   windows[0].inspector.rows[?label contains "第 1 轮"].expanded == true && windows[0].inspector.rows[?history==true] exists timeout=3s
shot   h12-expanded
click  'rect(windows[0].inspector.rows[?label contains "第 1 轮"])'
wait   windows[0].inspector.rows[?label contains "第 1 轮"].expanded == false && windows[0].inspector.rows[?history==true] !exists timeout=3s
shot   h12-collapsed
```

## judge
- `h12`：当前轮（第三轮：跑测试）下方按轮列出，最近的在上：
  「▸ 第 2 轮 · 第二轮：拉取依赖 · … 步 · <耗时> ✗」在「▸ 第 1 轮 · 第一轮：列出文件 · 1 步 · <耗时> ✓」之上。
- `h12-expanded`：第 1 轮就地展开出 `Bash ls` 与回复；`h12-collapsed` 恢复成一行。
- 中文提示词首行显示完整、没有乱码。
