# Y4 终端卡片显示命令块
requires: sandbox
checklist: Y4
scenarios: []

`false` 之后终端卡片显示「✗ false · exit 1」；`sleep 8` 运行期间显示「● sleep 8」；`panes[].commands[0]` 与之对应。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "false\n"
wait   windows[0].tabs[0].panes[0].commands[0].exit == 1 timeout=10s
assert windows[0].tabs[0].panes[0].commands[0].command == "false"
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"].status_line contains "✗ false" timeout=10s
assert windows[0].monitor.cards[?kind=="terminal"].status_line contains "exit 1"
shot   y4-failed
click  'rect(windows[0].tabs[1])'
wait   windows[0].tabs[1].active == true timeout=5s
type   "sleep 8\n"
wait   windows[0].tabs[1].panes[0].running_command == "sleep 8" timeout=10s
assert windows[0].tabs[1].panes[0].commands[0].running == true
assert windows[0].tabs[1].panes[0].commands[0].command == "sleep 8"
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"].status_line contains "● sleep 8" timeout=5s
shot   y4-running
wait   windows[0].monitor.cards[?kind=="terminal"].status_line contains "✓ sleep 8" timeout=15s
assert windows[0].tabs[1].panes[0].commands[0].exit == 0
```

## judge
- `y4-failed`：终端卡片红色「最后一条：✗ false · exit 1 · …」。
- `y4-running`：同一张卡片蓝色「● sleep 8 · N 秒」。
