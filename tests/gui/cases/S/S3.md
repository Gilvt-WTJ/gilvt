# S3 config.toml 没有 language、系统是英文：界面英文
requires: sandbox
checklist: S3
scenarios: []

去掉沙盒配置里固定的 `language`，用 `GILVT_TEST_SYSTEM_LANGUAGE=en-US` 假装 macOS 的首选语言是英文。gilvt 跟随系统，界面为英文，来源是 `system`。

## steps
```gilvt-steps
sh     "sed -i '' '/^language = /d' .config/gilvt/config.toml && ! grep -q '^language' .config/gilvt/config.toml"
restart --env GILVT_TEST_SYSTEM_LANGUAGE=en-US
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
raise
key    cmd+,
wait   settings.key == true && settings.language == "en" timeout=5s
assert settings.language_source == "system"
assert settings.pages[?id=="language"].label == "文A Language"
assert settings.languages[?id=="en"].selected == true
key    cmd+w
restart --set 'language="zh-CN"'
```
