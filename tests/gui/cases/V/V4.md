# V4 内置编辑器：换行显示、中文输入、点击落点、拖选与被拒绝的文件
requires: sandbox
checklist: V4
scenarios: [default]

长行软换行（续行没有行号，当前行底色覆盖它的所有显示行，列表项的续行对齐到文字而不是 `- `）；中文经过文字输入路径插入，光标按字符前进；
点击把光标放到点到的位置，拖动产生选区；含 NUL 字节的文件（二进制）不开编辑 pane，窗口顶部出现红色横幅。

默认字号（13）下只有一个 pane 的终端区约 92 列，所以「编辑」开新文件标签（列数规则，见 V2），编辑区接近整个终端区宽。

**状态断言与截图的分工**：
- 换行只能看截图：`debug state` 有 `wrap_cols` / `rows`，但没有每个逻辑行占几个显示行，也没有行号栏的内容。
- 点击落点：先 `⌘↓` 到文末（最后一行 `the end`，光标第 158 行第 8 列）。编辑区 rect 中心离左边很远，而视口里其余都是 8 个字符的
  短行（`line 001` …），所以点在中心一定落在某个短行的行尾：断言 `cursor.col == 9`（第几行取决于可见行数，不断言；第 9 列
  只可能来自 `line NNN`，所以它证明点击移动了光标）。
- 中文输入：`type` 在后台按字符发送（不经过输入法的组字），断言光标列前进 2。输入法的预编辑（组字中的文字画在光标处、
  `⌘S` 等不生效）需要切换系统输入源，用例不改用户的输入源，所以没有自动化；编辑 pane 也没有 `marked_text` 字段。
- 被拒绝文件的红色横幅不在 `debug state` 里（`error_banner` 是另一条横幅）：断言没有开出编辑 pane、没有新标签，横幅本身看截图。

## judge
- `v4-wrap`：第 3 行（`description: word01 word02 …`）折成多个显示行：只有第一个显示行有行号 `3`，续行的行号栏留空；当前行底色
  覆盖第 3 行的全部显示行（不只是第一行）；不在单词中间断开。第 7 行列表项 `- item01 …` 的续行与 `item01` 的首字母对齐，
  而不是与 `-` 对齐。没有横向滚动条，最右边没有被裁掉的字。
- `v4-cjk`：第 1 行是 `你好---`，两个汉字各占两个半角宽、没有重叠或被裁，光标竖线在「好」之后；头部和标签显示 ●。
- `v4-selection`：从中间某个 `line NNN` 的行尾到下面几行有选区底色，连续、没有缺口。
- `v4-refused`：标签栏下方一条红色横幅「不能编辑 SKILL.md：这是二进制文件，不能编辑」，右侧按钮「预览」「知道了」，**没有**
  「在外部编辑器中打开」；终端区仍是 Agent 终端，没有出现编辑 pane 或新标签（断言已覆盖）。
- 没有自动化：输入法预编辑（见说明）。需要时用中文输入法在编辑 pane 里打一次拼音，确认组字文字画在光标处、上屏后光标前进。
