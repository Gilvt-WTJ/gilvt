Install

  1. Open the downloaded Gilvt-{{VERSION}}.dmg.
  2. Drag Gilvt into Applications and open it from there. If you open it straight from the disk image, gilvt shows a banner and moves itself for you.
  3. Run claude or codex in a pane. The sidebar and inspector pick the session up automatically; there is nothing to configure.

Or with Homebrew, which also puts the gilvt command on your PATH:

brew install --cask gilvt-wtj/gilvt/gilvt

The interface follows your Mac's language (Simplified Chinese on a Chinese Mac, English otherwise); change it in Settings (⌘,) → Language. The first time a session needs you, allow notifications so you hear about it in other apps.

Updates

gilvt keeps itself up to date. It checks in the background, downloads a new version when there is one, and installs it when you quit, so running agents are never cut off. When an update is waiting, the bottom of the sidebar says so; Check for Updates… in the app menu checks right away.

Prefer to decide yourself? Set mode = "check" (ask before downloading) or mode = "off" under [update] in config.toml. Updates are signed and notarized, and the check sends no identifiers.

Build from source

You need Rust and the Xcode Command Line Tools (the full Xcode is not required). Builds from source have no updater.

git clone https://github.com/Gilvt-WTJ/gilvt.git
cd gilvt
scripts/bundle.sh release
open target/release/Gilvt.app
