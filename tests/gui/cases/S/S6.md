# S6 英文界面：工作区与 Agent 状态没有中文
requires: sandbox
checklist: S6
scenarios: [approve-bash]

`language = "en"` 下跑一个等审批的 Claude 会话：左栏、标签、检查器、关闭确认条和审批后的空闲状态里，gilvt 自己的文字都是英文。
每一步断言 `untranslated`（DebugState 列出的英文界面里仍是中文的文字）为空。剧本的提示词是英文，目录是 ASCII，所以剩下的中文只可能来自 gilvt。

## steps
```gilvt-steps
restart --set 'language="en"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/s6 && cd -P ~/work/s6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/s6"
assert untranslated[*] exists count=0
type   "claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?status=="awaiting_approval"].detail contains "rm -rf build" timeout=15s
assert untranslated[*] exists count=0
shot   s6-awaiting
# 关闭确认条：状态文字与按钮
key    cmd+w
wait   windows[0].close_confirm.action == "pane" timeout=3s
assert windows[0].close_confirm.items[*] exists count=1
assert untranslated[*] exists count=0
shot   s6-confirm
key    esc
wait   windows[0].close_confirm == null timeout=3s
# 拒绝这次审批，回到空闲
key    n
wait   windows[0].inspector.card.status == "idle" timeout=10s
assert untranslated[*] exists count=0
shot   s6-idle
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
assert untranslated[*] exists count=0
restart --set 'language="zh-CN"'
```

## judge
- `s6-awaiting`、`s6-confirm`、`s6-idle`：左栏分组与状态、标签、检查器的状态卡与时间线、关闭确认条的状态和按钮都是英文；
  终端里 fake claude 的输出原样显示（不翻译）。
