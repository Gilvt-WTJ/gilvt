# L13 transcript 尾部半行与被截断：已有队列和终端不受影响
requires: sandbox
checklist: L13
scenarios: [hist-claude]

会话 Review 完之后：先往 transcript 末尾追加一段没有换行的半行（Agent 正在写入的样子）——半行被忽略，会话不会重新进队列、也不报错；
再把文件截断（丢掉后面的内容），保存的 Review 位置找不到了——会话以「失败」档重新出现，而不是被悄悄当成已 Review；终端始终可以输入。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
```
