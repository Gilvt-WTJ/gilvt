# I4 ⌘↩ / ⌘⇧↩ 分屏恢复，浮层外 ⌘⇧↩ 仍是放大
requires: sandbox
checklist: I4
scenarios: [hist-claude, hist-codex]

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i4 --age 1h --id c1a0de00-0000-4000-8000-000000000401 --prompt "i4 在右侧恢复"
seed   hist-codex --cwd work/i4 --age 2h --id 01990000-0000-7000-8000-000000000401 --prompt "i4 在下方恢复"
type   "cd -P ~/work/i4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i4"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 && windows[0].overlay.selected == 0 timeout=15s
key    cmd+enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[*] exists count=2 timeout=5s
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].cwd contains "/work/i4" && windows[0].tabs[0].panes[1].foreground == "agent:claude" timeout=15s
shot   i4-right
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
# 第一行现在是正在运行的 Claude 会话（最近活动），Codex 会话在第二行
key    down
wait   windows[0].overlay.selected == 1
key    cmd+shift+enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[*] exists count=3 timeout=5s
wait   windows[0].tabs[0].panes[?focused==true].foreground == "agent:codex" && windows[0].tabs[0].panes[?focused==true].cwd contains "/work/i4" timeout=15s
shot   i4-below
# 浮层外的 ⌘⇧↩：放大当前 pane，再按一次还原
key    cmd+shift+enter
wait   windows[0].tabs[0].panes[?rect==null] exists count=2 timeout=3s
shot   i4-zoomed
key    cmd+shift+enter
wait   windows[0].tabs[0].panes[?rect==null] !exists timeout=3s
```

## judge
- `i4-right`：原 pane 在左，恢复的 Claude 在右侧新 pane。`i4-below`：Codex 在右侧 pane 下方的新 pane 里
  （三个 pane：左、右上、右下）。
- `i4-zoomed`：当前 pane 放大占满 pane 区域（另外两个 rect 为 null，断言）。
- 如果 Claude 会话不在第一行（例如 Codex 的扫描结果更新得更晚），`selected == 1` 仍成立但恢复的是错的会话——
  这时看 `i4-below` 里的前台程序（断言要求是 codex）。
