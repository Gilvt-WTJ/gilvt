# H24 时间线显示每轮的开始时刻
requires: sandbox
checklist: H24
scenarios: [three-turns]

`three-turns` 连续跑三轮：第 1 轮成功、第 2 轮 API 错误、第 3 轮是当前轮。三轮都在今天开始，所以标题带秒，历史轮次只到分钟。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h24 && cd -P ~/work/h24 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h24"
type   "claude @scenario:three-turns\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "测试通过。" timeout=15s
assert windows[0].inspector.rows[0].kind == "title"
assert windows[0].inspector.rows[0].started != null
assert windows[0].inspector.rows[0].label contains "时间线 · 第 3 轮 · "
assert windows[0].inspector.rows[?label contains "第 2 轮"].started != null
assert windows[0].inspector.rows[?label contains "第 1 轮"].started != null
shot   h24
```

## judge
- `h24`：标题为「时间线 · 第 3 轮 · HH:MM:SS」，时刻是灰色、不加粗，和本轮开始的时间一致（与系统时钟相差不超过本用例的运行时长）。
- 两个历史轮次分别为「▸ 第 2 轮 · 第二轮：拉取依赖 · … 步 · HH:MM · <耗时> ✗」和「▸ 第 1 轮 · 第一轮：列出文件 · 1 步 · HH:MM · <耗时> ✓」，
  时刻不早于第 1 轮、不晚于标题的时刻；窄检查器下文字被截断时，截掉的是行尾而不是时刻前面的轮次号。
