# S8 英文界面：监控官与设置窗口没有中文
requires: sandbox
checklist: S8
scenarios: [default]

`language = "en"`、开启监控官（关掉自动总结，不产生 fake 总结的中文内容）：`⌘⇧O` 活动视图、`⌘⇧M` 命令条、`⌘,` 设置窗口的监控官页里，
gilvt 自己的文字都是英文。每一步断言 `untranslated` 为空。点设置页导航要抢前台。

## steps
```gilvt-steps
restart --set 'language="en"' --set 'monitor.enabled=true' --set 'monitor.auto_summary=false'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/s8 && cd -P ~/work/s8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/s8"
type   "claude @scenario:default\n"
key    cmd+shift+o
key    cmd+i
wait   windows[0].inspector.visible == false && windows[0].monitor.chat.collapsed == false timeout=5s
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=30s
assert untranslated[*] exists count=0
shot   s8-monitor
# 底部命令条
key    cmd+shift+m
wait   windows[0].command_bar.expanded == true && windows[0].command_bar.focused == true timeout=5s
assert untranslated[*] exists count=0
shot   s8-command-bar
key    esc
# 设置窗口：监控官页
raise
key    cmd+,
wait   settings.key == true && settings.language == "en" timeout=5s
click  'rect(settings.pages[?id=="monitor"])'
wait   settings.page == "monitor" timeout=5s
assert untranslated[*] exists count=0
shot   --window key s8-settings-monitor
key    cmd+w
restart --set 'language="zh-CN"' --set 'monitor.enabled=false'
```

## judge
- `s8-monitor`：活动视图的分组、卡片（状态、时间、文件数、「took …」）、对话面板的状态和快捷提问按钮都是英文；没有「用时」。
- `s8-command-bar`：命令条的标题和提示是英文。
- `s8-settings-monitor`：监控官页的字段、说明和按钮都是英文。
