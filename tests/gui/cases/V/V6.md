# V6 内置编辑器：对比浮层（磁盘版本 ↔ 我的版本）
requires: sandbox
checklist: V6
scenarios: [default]

有未保存修改时外部改写文件，横条上点「对比」：浮层盖住整个编辑 pane，头部「对比 · SKILL.md　磁盘版本 ↔ 你的版本（未保存）」，
左栏是磁盘版本、右栏是我的版本（pane ≥ 80 列时左右并排），改动行着色，连续的未改动行折成一行。底部三个按钮：
「用磁盘版本」（= 重新载入）、「保留我的，稍后再说」（只关浮层，横条还在）、「仍然覆盖磁盘」（把我的版本写到磁盘）。
`Esc` 关浮层；浮层打开时 `⌘S` 不保存。只有换行符不同时浮层只说「内容相同，只有换行符不同。」。

默认字号（13）下终端区约 92 列，「编辑」开新文件标签（见 V2），编辑 pane 在 `tabs[1]`，宽度 ≥ 80 列，所以 `compare.split == true`。
文件有 20 行 `line NN`：我在第 1 行前输入，磁盘版本在末尾加一行，中间 ≥ 7 行没变，会折叠。外部改写一律是 `cp` 事先写好的文件。

**状态断言与截图的分工**：`debug state` 只导出浮层的行数、是否并排、是否相同和按钮（不导出任何一边的文字），左右哪边是哪个版本、
着色和折叠行看截图 `v6-compare`；按钮的效果用 `dirty` / `bar` 和磁盘文件（`cmp`）断言。「用磁盘版本」之后缓冲区是磁盘版本，
由下一轮「仍然覆盖磁盘」写出的内容（「`mine2 `」+ 第一个磁盘版本）间接证明。

## judge
- `v6-compare`：浮层盖住整个编辑 pane（头部、文本区、状态栏都被盖住）；头部「对比 · SKILL.md　磁盘版本 ↔ 你的版本（未保存）」，
  右侧「Esc 返回编辑」。正文左右两栏：**左栏是磁盘版本**（第 1 行 `---`，末尾多一行 `disk one`），**右栏是我的版本**（第 1 行 `mine ---`，
  没有 `disk one`）；改动的行有删除 / 新增底色（与预览 pane 的 diff 同一套颜色），中间 `line NN` 一段未改动行折成一行「⋯ N 行未改动（点击展开）」，
  首尾各留几行上下文。底部按钮：「用磁盘版本」「保留我的，稍后再说」在左，「仍然覆盖磁盘」单独在右、红色。
- `v6-same`：浮层正文只有一句「内容相同，只有换行符不同。」，没有 diff 行；三个按钮仍在。
- 没有自动化：点折叠行展开（`compare.rows` 会变多）——折叠行没有 rect（`compare` 只导出底部按钮的 rect），需要时手动点一次；
  窄 pane（< 80 列）时的上下合并显示（`split == false`）本用例不覆盖。
