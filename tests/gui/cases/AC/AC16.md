# AC16 devbox-zsh（登录 shell 为 zsh）：安装、cwd、命令块
requires: remote
checklist: AC16
scenarios: []

远端是干净的（run.sh 在每个 remote 用例前执行 `remote.sh reset`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   'ssh devbox-zsh\n'
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "要在 devbox-zsh 上安装远端组件吗" timeout=30s
assert windows[0].tabs[0].panes[0].remote.enhanced == false
shot   ac16-ask
type   'Y\n'
wait   windows[0].tabs[0].panes[0].remote.enhanced == true && hosts[0].bridge == "up" timeout=60s
wait   windows[0].tabs[0].panes[0].remote.cwd == "/home/devz" timeout=15s
assert windows[0].tabs[0].panes[0].cwd == null
assert hosts[0].install == "allowed"
sh     'remote-test exec --user devz "test -x ~/.gilvt-server/bin/gilvt-remote"'
shot   ac16-in
type   'cd /tmp\n'
wait   windows[0].tabs[0].panes[0].remote.cwd == "/tmp" timeout=10s
assert windows[0].tabs[0].panes[0].cwd == null
assert windows[0].tabs[0].title contains "devbox"
type   'false\n'
wait   windows[0].tabs[0].panes[0].commands[?command=="false"].exit == 1 timeout=10s
type   'exit\n'
wait   windows[0].tabs[0].panes[0].remote == null timeout=15s
```

## judge
- `ac16-ask`：pane 里是三行安装询问，末行「[Y] 安装  [n] 这次不用  [N] 这台主机永不安装」。
- `ac16-in`：远端 prompt（`devz@devbox`），上方没有残留的「正在安装远端组件…」。
