# P5 手工破坏 workspace.json：空白启动，原文件另存为 .bad
requires: sandbox
checklist: P5
scenarios: []

`workspace.json` 解析失败时 gilvt 以空白窗口启动（不崩溃），并把原文件改名为 `workspace.json.bad` 供排查；之后正常保存新的布局。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/p5 && cd -P ~/work/p5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/p5"
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 timeout=10s
# ⌘Q 同步写入 workspace.json；退出之后再破坏它（gilvt 还在跑时每秒的定时保存会把它改回去）
key    cmd+q
sleep  2s
sh     'test -s "$HOME/Library/Application Support/gilvt/state/workspace.json"'
sh     'printf "%s" "{ this is not json" > "$HOME/Library/Application Support/gilvt/state/workspace.json"'
restart
wait   windows[*] exists count=1 timeout=20s
# 空白启动：一个窗口、一个标签、一个 pane，不是上次的分屏，也不在 p5
assert windows[0].tabs[*] exists count=1
assert windows[0].tabs[0].panes[*] exists count=1
assert windows[0].layout.tabs[*] exists count=1
assert windows[0].tabs[0].panes[?cwd contains "/work/p5"] !exists
assert pending == []
sh     'test -f "$HOME/Library/Application Support/gilvt/state/workspace.json.bad" && grep -q "this is not json" "$HOME/Library/Application Support/gilvt/state/workspace.json.bad"'
shot   p5-blank
# 之后正常保存：新的布局写回 workspace.json，.bad 还在
sleep  2s
sh     'grep -q "\"version\"" "$HOME/Library/Application Support/gilvt/state/workspace.json" && test -f "$HOME/Library/Application Support/gilvt/state/workspace.json.bad"'
```

## judge
- `p5-blank`：一个空白窗口（一个标签、一个 shell），没有错误横幅或崩溃提示。
- `workspace.json.bad` 的内容就是破坏后的原文件（`{ this is not json`，`sh` 步骤断言）；新的 `workspace.json` 是合法 JSON 且含 `version`。
- gilvt 的 stderr（`gilvt: workspace.json 已忽略（…），原文件保存为 workspace.json.bad`）不在 debug state 里；需要时看 `sandbox.sh` 报告里保存的日志。
