# L10 完整历史：从只看未 Review 切到整个会话，再切回
requires: sandbox
checklist: L10
scenarios: [hist-claude]

一个会话先 Review 完 2 轮（队列清空），Agent 又完成 2 轮后重新进队列。打开 Review 默认只有新的 2 轮；按 `F` 切到完整历史，显示全部 4 轮；再按 `F` 回到只看未 Review。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l10 && cd -P ~/work/l10 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l10"
seed   hist-claude --cwd work/l10 --id c1a0de00-0000-4000-8000-0000000b1001 --prompt "l10 完整历史"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[0] exists timeout=15s
key    space
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
key    cmd+enter
wait   windows[0].overlay.session_review == null && windows[0].overlay.rows[0] !exists timeout=10s
key    esc
wait   windows[0].overlay == null
seed   hist-claude --cwd work/l10 --id c1a0de00-0000-4000-8000-0000000b1001 --append --prompt "l10 又完成两轮"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b1001"].unreviewed_count == 2 timeout=15s
key    space
wait   windows[0].overlay.session_review.mode == "incremental" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.turns[2] !exists
key    f
wait   windows[0].overlay.session_review.mode == "full" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[3] exists timeout=10s
assert windows[0].overlay.session_review.turns[4] !exists && windows[0].overlay.session_review.has_earlier == false
shot   l10-full
key    f
wait   windows[0].overlay.session_review.mode == "incremental" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.turns[2] !exists
key    esc
key    esc
wait   windows[0].overlay == null
```

## judge
- `l10-full`：头部写「完整历史」，按钮是「只看未 Review F」；四轮 turn 都在，包括之前已经确认过的两轮。
