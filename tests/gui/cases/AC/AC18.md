# AC18 在 ssh 会话中关掉 pane，link 结束、bridge 随后关闭
requires: remote
checklist: AC18
scenarios: []

先 ⌘D 再在新 pane（焦点所在）里 ssh，⌘W 关掉的就是 ssh 所在的 pane；窗口因左边的 pane 留下而不关闭。
没有 `focus` / 点击，`key` 不指定 pane：不抢前台。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   'ssh devbox-test\n'
wait   windows[0].tabs[0].panes[1].screen_tail[*] contains "要在 devbox-test 上安装远端组件吗" timeout=30s
type   'Y\n'
wait   windows[0].tabs[0].panes[1].remote.enhanced == true timeout=60s
wait   hosts[0].bridge == "up" timeout=30s
assert hosts[0].links != []
key    cmd+w
wait   windows[0].tabs[0].panes[1] !exists timeout=10s
wait   hosts[0].links == [] timeout=5s
wait   hosts[0].bridge == "none" timeout=60s
```
