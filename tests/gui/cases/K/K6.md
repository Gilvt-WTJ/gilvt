# K6 非 git 目录降级
requires: sandbox
checklist: K6
scenarios: [artifacts-basic]

目录不是 git 仓库（不用共享的 SETUP，它会建仓库）：卡片写明不记录文件改动。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k6 && cd work/k6 && printf '# Demo\n' > README.md"
type   "cd -P ~/work/k6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k6"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[0].state == "degraded" timeout=30s
assert windows[0].inspector.artifacts.cards[0].notices[0] contains "非 git 目录" && windows[0].inspector.artifacts.cards[0].files[*] exists count=0
shot   k6-non-git
```

## judge
- `k6-non-git`：卡片写「非 git 目录，暂不记录文件改动」，没有文件列表。
