# T5 左栏：会话行用 Agent 的标题，手动改名仍然最高
requires: sandbox
checklist: T5
scenarios: [default]

一个正在 gilvt 里运行的会话，左栏行名是它的第一条提示词。Agent 为它写下 `ai-title` 之后（历史索引刷新一次，`⌘⇧R`），左栏行名换成这个标题；
手动改名压过它。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/t5 && cd -P ~/work/t5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/t5"
type   "claude --session-id c1a0de00-0000-4000-8000-0000000c0501 @scenario:default t5 起始提示词\n"
wait   windows[0].sidebar.rows[?section=="project:t5"].name == "t5 起始提示词" && windows[0].inspector.card.status == "idle" timeout=15s
# Agent 给会话起了名字
sh     'F="$(find "$HOME/.claude/projects" -name "*0c0501.jsonl")" && test -n "$F" && echo "{\"type\":\"ai-title\",\"aiTitle\":\"T5 生成的标题\",\"sessionId\":\"x\"}" >> "$F"'
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    esc
wait   windows[0].overlay == null && windows[0].sidebar.rows[?section=="project:t5"].name == "T5 生成的标题" timeout=10s
shot   t5-sidebar
# 手动改名压过它
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+r
key    backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace
type   "我的名字\n"
key    esc
wait   windows[0].overlay == null && windows[0].sidebar.rows[?section=="project:t5"].name == "我的名字" timeout=5s
```

## judge
- `t5-sidebar`：左栏那一行显示「T5 生成的标题」，不是「t5 起始提示词」。
