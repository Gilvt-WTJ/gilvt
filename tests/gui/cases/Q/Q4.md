# Q4 点击终端行把焦点切到它的 pane，终端行不进「需要你」
requires: sandbox
checklist: Q4
scenarios: []

分屏出第二个 shell 后，焦点在右 pane；点第一个终端行（左 pane），焦点回到左 pane。终端行不会出现在「需要你」；没有 agent 时 `⌘⇧↑↓` 不会切到终端。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q4 && cd -P ~/work/q4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q4"
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=2 timeout=10s
assert windows[0].sidebar.terminals == 2
click  'rect(windows[0].sidebar.rows[?kind=="terminal"])'
wait   windows[0].tabs[0].panes[0].focused == true timeout=5s
assert windows[0].tabs[0].panes[1].focused == false
assert windows[0].sidebar.sections[?name=="needs_you"] exists count=0
assert windows[0].sidebar.rows[?section=="needs_you"] exists count=0
key    cmd+shift+down
sleep  500ms
assert windows[0].tabs[0].panes[0].focused == true
assert windows[0].tabs[0].panes[1].focused == false
key    cmd+shift+up
sleep  500ms
assert windows[0].tabs[0].panes[0].focused == true
assert windows[0].tabs[0].panes[1].focused == false
shot   q4
```

## judge
- `q4`：左栏两行终端行，没有「需要你」分区；左 pane 有焦点边框。
