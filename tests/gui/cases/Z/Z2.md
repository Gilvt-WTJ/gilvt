# Z2 固定预览里按 T 移到新标签，Esc 回到原标签，⌘W 关掉后回到原标签
requires: sandbox
checklist: Z2
scenarios: []

键盘做和 Z1 一样的事：在固定预览里按 `T`，pane 移到新标签。新标签里没有终端，`Esc` 回到它来自的标签；再切回去按 `⌘W` 关掉它，也回到原标签。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/z2 && printf 'alpha\nbeta\n' > work/z2/notes.txt"
type   "cd -P ~/work/z2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/z2"
type   "gilvt view --pin notes.txt\n"
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].code exists timeout=10s
click  'rect(windows[0].tabs[0].panes[1].code)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].kind == "preview" && windows[0].tabs[1].panes[0].focused == true timeout=5s
assert windows[0].tabs[0].panes[*] exists count=1
key    escape
wait   windows[0].tabs[0].active == true && windows[0].tabs[0].panes[0].focused == true timeout=5s
assert windows[0].tabs[*] exists count=2
click  'rect(windows[0].tabs[1])'
wait   windows[0].tabs[1].active == true timeout=5s
key    cmd+w
wait   windows[0].tabs[*] exists count=1 && windows[0].tabs[0].active == true && windows[0].tabs[0].panes[0].kind == "terminal" timeout=5s
```
