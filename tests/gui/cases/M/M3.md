# M3 非 git 目录：不显示 git 行，目录名分组不变
requires: sandbox
checklist: M3
scenarios: [default]

会话的目录不在任何 git 仓库里时，`rows[].git` 为 `null`（行上没有 git 行），分组仍按目录名（`project:<目录名>`），与加 git 功能之前一样。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/k3-plain && cd -P ~/work/k3-plain && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k3-plain"
type   "claude @scenario:default k3 没有仓库\n"
wait   windows[0].sidebar.rows[?name=="k3 没有仓库"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
# git 的首次查询在会话出现后约 1–10 秒内完成；等够一轮再断言「没有」
sleep  12s
assert windows[0].sidebar.rows[?name=="k3 没有仓库"].section == "project:k3-plain"
assert windows[0].sidebar.rows[?name=="k3 没有仓库"].git == null
assert windows[0].sidebar.sections[?name=="project:k3-plain"] exists count=1
assert windows[0].sidebar.sections[?name=="project:k3-plain"].count == 1
shot   k3-plain
# 对照：同一个目录变成 git 仓库之后，同一个会话的行才出现 git 行
sh     'cd ~/work/k3-plain && git init -q -b main && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m init'
wait   windows[0].sidebar.rows[?name=="k3 没有仓库"].git.line == "⎇ main" timeout=25s
assert windows[0].sidebar.rows[?name=="k3 没有仓库"].section == "project:k3-plain"
```

## judge
- `k3-plain`：会话行只有名字、状态行和位置，没有 `⎇` 的小字；分区名是「k3-plain」。
- 最后一步（目录变成仓库后出现 `⎇ main`）证明前面的「没有 git 行」不是因为 git 查询根本没有跑。仓库的主目录名正好是 `k3-plain`，所以分区名不变。
