# I17 目录补全与不存在的目录
requires: sandbox
checklist: I17
scenarios: []

从 HOME 开始（目录框为 `~`），`~/wo` + `Tab` 补全为 `~/work/`；多个候选时列在下方；不存在的目录预览变红，三种启动键都不执行。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/i17-alpha work/i17-beta"
type   "cd ~ && clear\n"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.dir == "~" timeout=5s
key    up backspace
type   "~/wo"
key    tab
wait   windows[0].overlay.dir == "~/work/" timeout=3s
type   "i17"
key    tab
wait   windows[0].overlay.dir == "~/work/i17-" timeout=3s
shot   i17-candidates
type   "a"
key    tab
wait   windows[0].overlay.dir == "~/work/i17-alpha/" && windows[0].overlay.preview.missing == false timeout=3s
type   "nope"
wait   windows[0].overlay.preview.missing == true && windows[0].overlay.preview.head == "目录不存在" timeout=3s
shot   i17-missing
key    enter
key    cmd+enter
key    cmd+shift+enter
sleep  1s
assert windows[0].overlay.kind == "new_agent" && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1
key    esc
wait   windows[0].overlay == null
```

## judge
- `i17-candidates`：目录框下方列出 `i17-alpha/`、`i17-beta/` 两个候选。
- `i17-missing`：预览变红，显示「目录不存在」（断言）。三种启动键都没有执行（断言：面板仍开着，没有新 pane / 标签）。
- 如果目录框初始不是 `~`（pane 的 cwd 被上报成了物理路径），先看 `state windows[0].overlay.dir`，把它记进报告；
  这时补全从那个路径开始，需要人工删掉后重做。
