# U3 配置只在显式刷新后重新读取
requires: sandbox
checklist: U3
scenarios: [default]

配置标签打开后改写 `.mcp.json`。普通重绘保持缓存，点击 DebugState 给出的「刷新」坐标后才重新读取。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/u3/.git && printf '%s\n' '{\"mcpServers\":{\"before-refresh\":{\"command\":\"U3-BEFORE-SECRET\"}}}' > work/u3/.mcp.json"
type   "cd -P ~/work/u3 && clear && claude @scenario:default u3 refresh\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" && windows[0].inspector.card.status == "idle" timeout=20s
key    cmd+alt+3
wait   windows[0].inspector.config.loading == false && windows[0].inspector.config.mcp[?name=="before-refresh"] exists timeout=10s
# 运行时的模型 / 权限在 Agent 空闲之后才上报，配置目标随之变化并重读一次磁盘；等它稳定后再改文件，否则这次读取会把新内容带进来。
wait   windows[0].inspector.config.model.source == "runtime" && windows[0].inspector.config.permission.source == "runtime" && windows[0].inspector.config.loading == false timeout=10s
sh     "printf '%s\n' '{\"mcpServers\":{\"after-refresh\":{\"command\":\"U3-AFTER-SECRET\"}}}' > work/u3/.mcp.json"
sleep  1s
assert windows[0].inspector.config.mcp[?name=="before-refresh"] exists && windows[0].inspector.config.mcp[?name=="after-refresh"] !exists
click  'rect(windows[0].inspector.config.refresh_rect)'
wait   windows[0].inspector.config.loading == false && windows[0].inspector.config.mcp[?name=="after-refresh"] exists && windows[0].inspector.config.mcp[?name=="before-refresh"] !exists timeout=10s
assert windows[0].tabs[0].panes[0].foreground == "agent:claude"
sh     "grep -q 'U3-AFTER-SECRET' work/u3/.mcp.json"
shot   u3-refreshed
```

## judge
- `u3-refreshed`：点击刷新后只显示 `after-refresh`，会话仍在原 pane；配置文件仍是测试写入的内容。
- `U3-BEFORE-SECRET` / `U3-AFTER-SECRET` 都不出现在截图或 DebugState。
