# Q5 长标题折成两行，状态行单行带省略号
requires: sandbox
checklist: Q5
scenarios: [long-title]

`long-title` 剧本：很长的第一条提示词，随后一个 40 秒、命令很长的 Bash 调用。左栏 agent 行的标题折成两行，状态行（「● 执行中 · Bash(cargo test …)」）仍是单行、带省略号。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q5 && cd -P ~/work/q5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q5"
type   "claude @scenario:long-title\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists timeout=15s
assert windows[0].sidebar.rows[?kind=="agent"].name contains "Add terminal rows to the sidebar"
assert windows[0].sidebar.rows[?kind=="agent"].line contains "cargo test"
shot   q5
```

## judge
- `q5`：agent 行的标题折成两行（第二行可以以省略号结尾，不是一行被截断）；状态行只有一行，末尾带省略号；时间在行的右上角；行内没有文字溢出到左栏外。
