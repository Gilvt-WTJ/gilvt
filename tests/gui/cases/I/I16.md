# I16 Codex、更多选项与记住的选择
requires: sandbox
checklist: I16
scenarios: [hist-codex]

模型预设来自最近 30 天的 Codex 会话：`seed` 放一个一天前的 fake codex 会话，它的模型是 `gpt-5.6-sol`（fake agent 的
`codex::MODEL`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/i16-other"
seed   hist-codex --cwd work/i16 --age 1d --id 01990000-0000-7000-8000-000000001601 --prompt "i16 模型预设的来源"
type   "mkdir -p ~/work/i16 && cd -P ~/work/i16 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i16"
# 模型预设取自历史索引；gilvt 只在启动和 ⌘⇧R 时重新扫描，seed 在启动之后：先开一次 ⌘⇧R 让索引读到它
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.rows[?session=="codex:01990000-0000-7000-8000-000000001601"] exists timeout=15s
key    esc
wait   windows[0].overlay == null
# 两个标签，才能看出面板里的 ⌘1 / ⌘2 不切换标签
key    cmd+t
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
key    cmd+1
wait   windows[0].tabs[0].active == true
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.agent == "claude" timeout=5s
key    cmd+2
wait   windows[0].overlay.agent == "codex" && windows[0].tabs[0].active == true
key    cmd+1
wait   windows[0].overlay.agent == "claude" && windows[0].tabs[0].active == true
key    cmd+2
wait   windows[0].overlay.agent == "codex"
# 目录：在末尾补上 -other；任务；然后 更多 → 展开，模型 → 第一个预设，权限 → 只读
key    up
type   "-other"
key    down
type   "i16 任务"
key    down right down right down right
wait   windows[0].overlay.dir contains "work/i16-other" && windows[0].overlay.task == "i16 任务" && windows[0].overlay.preview.command contains "codex -m gpt-5.6-sol -s read-only -a on-request" timeout=3s
shot   i16-more
key    cmd+enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].foreground == "agent:codex" && windows[0].tabs[0].panes[1].cwd contains "work/i16-other" timeout=15s
key    cmd+alt+left
wait   windows[0].tabs[0].panes[0].focused == true
key    cmd+shift+n
# 记住了 Agent、模型与权限；目录是新焦点 pane 的（work/i16），任务为空
wait   windows[0].overlay.agent == "codex" && windows[0].overlay.task == "" && windows[0].overlay.preview.command contains "work/i16 && codex -m gpt-5.6-sol -s read-only -a on-request" timeout=5s
shot   i16-remembered
# 只按 Esc 关掉的面板不改变记住的选择
key    cmd+1
wait   windows[0].overlay.agent == "claude"
key    esc
wait   windows[0].overlay == null
key    cmd+shift+n
wait   windows[0].overlay.agent == "codex" && windows[0].overlay.preview.command contains "-m gpt-5.6-sol -s read-only -a on-request" timeout=5s
key    esc
wait   windows[0].overlay == null
```

## judge
- `i16-more`：「更多」展开，模型行选中 `gpt-5.6-sol`（预设），权限行选中「只读」；预览含 `-m gpt-5.6-sol -s read-only -a on-request`（断言）。
- `i16-remembered`：再次打开时仍是 Codex、「更多」展开、模型与权限为上次的选择；目录与任务没有被记住（断言）。
- 如果模型行没有任何预设（`→` 选中了「自定义」，预览没有 `-m`），说明 30 天内的 Codex 会话没有被读到：记 ❌ 并附上
  `seed` 的输出。⌘⇧N 本身不重新扫描历史（只有启动和 ⌘⇧R 会），所以用例先开一次 ⌘⇧R。
