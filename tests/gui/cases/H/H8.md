# H8 TaskCreate / TaskUpdate 累积的 TODO
requires: real-claude
checklist: H8
scenarios: []

TaskCreate / TaskUpdate 的输入与结果格式只有真实 claude 才有（fake agent 不模拟任务 id 的分配），所以用真实 claude。
TODO 随调用累积、更新；被删除的任务从列表消失。

## setup
```sh
tests/gui/sandbox.sh real-up --label h8
```

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
type   "mkdir -p ~/gilvt-lab/h8 && cd -P ~/gilvt-lab/h8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/gilvt-lab/h8"
type   "claude --no-chrome\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=30s
# 在这个目录第一次运行时 Claude 会先问是否信任它：screen_tail 里出现 trust 字样时执行 key enter
type   "只用任务工具，不要写文件：先用 TaskCreate 建三个任务「甲」「乙」「丙」，然后停下来等我。\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=180s
shot   h8-created
type   "用 TaskUpdate 把「甲」标为进行中、把「乙」标为已完成，然后删除「丙」（TaskUpdate 的 status 设为 deleted）。\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=180s
shot   h8-updated
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
```

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/H8
```

## judge
- `h8-created`：TODO 块有「甲」「乙」「丙」三项，都是 ☐，标题「TODO · 0 / 3」。
- `h8-updated`：「◐ 甲」（加粗）、「☑ 乙」（划线）；「丙」已经不在列表里，标题「TODO · 1 / 2」。
- 如果 Claude 没有用 TaskCreate（例如改用 TodoWrite），记为 ⚠️ 并附上时间线截图——这说明当前版本的 claude
  不提供任务工具，需要换提示词或跳过。
