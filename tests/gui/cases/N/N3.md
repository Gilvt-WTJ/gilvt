# N3 ⌘Q：合并列出所有窗口的受影响会话；取消后应用保持运行
requires: sandbox
checklist: N3
scenarios: [long-tool, ask-question]

两个窗口各有一个受影响的会话（窗口 1 在问你，窗口 2 执行中）。`⌘Q` 弹出一条确认条（`action: "quit"`），合并列出两个窗口的会话、每个一次；
取消后两个窗口和会话都还在、应用仍在运行；窗口里没有受影响的会话时 `⌘Q` 直接退出（见 P1）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/l3 && cd -P ~/work/l3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l3"
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"].status == "awaiting_answer" timeout=15s
# 窗口 2：gilvt 在后台时新窗口不会成为 key window，先点一下把 gilvt 带到前台
click  pane(focused)
wait   front == true timeout=5s
key    cmd+n
wait   windows[*] exists count=2 && windows[?key==true].tabs[0].panes[0].foreground == "shell" && windows[?key==true].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   --window key "cd -P ~/work/l3 && claude @scenario:long-tool\n"
wait   windows[?key==true].inspector.card.status == "running_tool" timeout=15s
assert windows[*].close_confirm == null count=2
# ⌘Q：一条确认条，两个会话
key    cmd+q
wait   windows[*].close_confirm.action == "quit" timeout=5s
assert windows[*].close_confirm.action == "quit" count=1
assert windows[*].close_confirm.items[*] exists count=2
assert windows[*].close_confirm.items[?status=="在问你"] exists count=1
assert windows[*].close_confirm.items[?status contains "sleep 30"] exists count=1
shot   l3-quit
# 取消：应用保持运行，两个窗口和两个会话都在
key    enter
wait   windows[*].close_confirm.action !exists timeout=3s
assert windows[*] exists count=2
assert windows[*].sidebar.rows[?status=="awaiting_answer"] exists
assert windows[*].sidebar.rows[?status=="running_tool"] exists
# 再来一次，用 Esc 取消
key    cmd+q
wait   windows[*].close_confirm.action == "quit" timeout=5s
key    esc
wait   windows[*].close_confirm.action !exists timeout=3s
assert windows[*] exists count=2
sleep  1s
assert windows[*] exists count=2
```

## judge
- `l3-quit`：只有一个窗口（出现在最前面的那个）有确认条，写着「退出 …」并列出两个会话（「C · … · 在问你」「C · … · 执行 Bash(sleep 30)」），不是每个窗口各一条。
- 取消后 `debug state` 仍能回答（应用没有退出），两个窗口、两个会话都在。
- `assert windows[*].close_confirm == null count=2`：没弹确认条之前两个窗口的 `close_confirm` 都是 `null`。
