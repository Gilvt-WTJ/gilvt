# O8 「外观」页：点一行立即在所有窗口生效并写回，注释保留
requires: sandbox
checklist: O8
scenarios: []

两个窗口；在设置窗口的「外观」页点 Nord：两个窗口立刻换成 Nord（没有确认或还原步骤），约 300 ms 后 `config.toml` 的 `theme` 改成 `"Nord"`，原有注释都在。
窗口顺序（`windows[]`）不固定，截图用 `--window 0` / `--window 1` 各拍一张。

## steps
```gilvt-steps
sh     "printf '%s\n' '# keep me' >> .config/gilvt/config.toml"
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# gilvt 在后台时新窗口不会成为 key window，先点一下把它带到前台
click  pane(focused)
wait   front == true timeout=5s
key    cmd+n
wait   windows[*] exists count=2 && windows[?key==true].tabs[0].panes[0].foreground == "shell" && windows[?key==true].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="appearance"])'
wait   settings.page == "appearance" timeout=5s
click  'rect(settings.appearance.search_rect)'
type   --window key "nord"
wait   settings.appearance.rows[?name=="Nord"].rect != null timeout=5s
click  'rect(settings.appearance.rows[?name=="Nord"])'
wait   theme.name == "Nord" && settings.appearance.fixed == "Nord" timeout=5s
assert settings.appearance.rows[?name=="Nord"].current == true
assert theme.dark == true
# 选择稳定约 300 ms 后写回，只改 theme 一行
sleep  1s
sh     "grep -qx 'theme = \"Nord\"' .config/gilvt/config.toml && grep -qx '# keep me' .config/gilvt/config.toml && grep -q '^# gilvt GUI test sandbox' .config/gilvt/config.toml"
assert settings.write_error == null
shot   --window key o8-settings
shot   --window 0 o8-window-a
shot   --window 1 o8-window-b
key    cmd+w
wait   settings !exists timeout=5s
sh     "sed -i '' '/^# keep me$/d' .config/gilvt/config.toml"
# 重启回到单窗口并恢复默认配置
restart --set 'theme="light"'
```

## judge
- `o8-window-a`、`o8-window-b`：两个工作区窗口都已是 Nord（深蓝灰终端底、同色调的左栏和检查器），标题栏也是深色。
- `o8-settings`：设置窗口本身也换成 Nord 的深色，Nord 一行高亮且带 ✓。
