# H4 ⌘+点击文件名打开 Quick Look
requires: sandbox
checklist: H4
scenarios: [timeline, timeline-codex]

Read / Edit / Write / apply_patch 行里的文件名 `⌘`+点击后用 Quick Look 打开；Codex 的 apply_patch 用相对路径，按会话 cwd 解析。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/h4/src && printf '# Demo\n\nOld line\n' > work/h4/README.md && printf 'pub fn greet() {}\n' > work/h4/src/lib.rs"
type   "cd -P ~/work/h4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h4"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h4-claude
click  'rect(windows[0].inspector.rows[?label contains "Update README.md"].file)' cmd
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/h4/README.md" timeout=5s
shot   h4-quicklook-readme
key    esc
wait   windows[0].overlay == null
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
type   "clear && codex @scenario:timeline-codex\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" && windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Refactored greet()" timeout=20s
shot   h4-codex
click  'rect(windows[0].inspector.rows[?label contains "apply_patch"].file)' cmd
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/h4/src/lib.rs" timeout=5s
shot   h4-quicklook-lib
key    esc
wait   windows[0].overlay == null
```

## judge
- 两张 Quick Look 截图分别显示 `README.md`（`# Demo` …）与 `src/lib.rs`（`pub fn greet() {}`）的内容；fake agent 不真正改文件，
  所以显示的是 `sh` 步骤写入的原文。
- `apply_patch` 的路径是相对路径 `src/lib.rs`，overlay 的 `path` 断言已确认它按会话 cwd（`~/work/h4`）解析。
- 普通点击（不带 `⌘`）文件名只按 H2 的规则跳转，不打开 Quick Look——本用例不单独验证。
- 如果 `Esc` 没有关掉 Quick Look，报告里注明实际的关闭方式（例如空格），不算失败。
