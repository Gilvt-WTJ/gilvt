# I25 codex_launch 含空格：横幅提示并改用默认值
requires: sandbox
checklist: I25
scenarios: []

`codex_launch = "codex w"` 不是合法的命令名：启动时顶部横幅提示并改用默认值 `codex`，其他配置照常生效。结束时恢复。

## steps
```gilvt-steps
restart --set 'agent.codex_launch="codex w"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
shot   i25-banner
type   "mkdir -p ~/work/i25 && cd -P ~/work/i25 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i25"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" timeout=5s
key    cmd+2
type   "i25x"
# 用的是默认值 codex，不是 "codex w"
wait   windows[0].overlay.agent == "codex" && windows[0].overlay.preview.command contains "&& codex i25x" timeout=3s
key    esc
wait   windows[0].overlay == null
restart --set 'agent.codex_launch="codex"'
```

## judge
- `i25-banner`：窗口顶部的错误横幅指出 `agent.codex_launch = "codex w"` 不是合法的命令名、改用默认值 `codex`。
- 其他配置照常：截图仍是沙盒的浅色主题、Menlo 13 号字（与其他用例的截图一致），提示符 `sandbox$` 正常。
- 最后的 `restart` 恢复 `codex_launch = "codex"`；它失败时先停下来报告。
