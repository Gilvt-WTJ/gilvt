# I22 Dock 角标计数与静音
requires: sandbox
checklist: I22
scenarios: [ask-question]
parallel: serial

角标 = 等你处理、且没有静音的会话数。静音 / 取消静音立即更新；没有会话等待时角标消失。
Dock 上真正显示角标还需要 gilvt 的「允许通知」与「标记应用程序图标」（spec §2）；`dock_badge` 是 gilvt 最后一次设置的文字。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i22 && cd -P ~/work/i22 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i22"
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 timeout=15s
wait   dock_badge == "1"
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "cd -P ~/work/i22 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=2 timeout=15s
wait   dock_badge == "2"
# 静音右边（当前 pane）的会话
rclick 'row(section=="needs_you"&&focused==true)'
click  'menu("静音这个会话的通知")'
wait   dock_badge == "1" && windows[0].sidebar.rows[?muted==true] exists timeout=3s
rclick 'row(section=="needs_you"&&muted==true)'
wait   windows[0].context_menu.items[?label=="静音这个会话的通知"].checked == true timeout=3s
click  'menu("静音这个会话的通知")'
wait   dock_badge == "2" && windows[0].sidebar.rows[?muted==true] !exists timeout=3s
rclick 'row(section=="needs_you"&&focused==true)'
click  'menu("静音这个会话的通知")'
wait   dock_badge == "1" timeout=3s
# 回答左边（没静音的）：只剩静音的在等，角标消失
key    cmd+alt+left
wait   windows[0].tabs[0].panes[0].focused == true
key    enter
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 && dock_badge == null timeout=10s
key    cmd+alt+right
wait   windows[0].tabs[0].panes[1].focused == true
key    enter
wait   windows[0].sidebar.rows[?section=="needs_you"] !exists && dock_badge == null timeout=10s
```

## judge
- 全部是状态断言，没有视觉检查项。右键菜单的两次点击是前台动作；锁屏时它们退出 5，静音部分记为 ⏭。
