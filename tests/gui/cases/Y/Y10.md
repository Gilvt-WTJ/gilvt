# Y10 bash 的命令原文
requires: sandbox
checklist: Y10
scenarios: []

沙盒默认 shell 就是 bash（包装脚本，保持沙盒 HOME / PATH），带空格、分号、引号的命令原文完整出现在 `commands[0].command` 和终端卡片上。zsh / fish 由 `cargo test -p gilvt-shell`（real_shells：`zsh_reports_the_command_line`、装了 fish 时 `fish_reports_the_command_line`）覆盖。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "echo \"a b;c\"\n"
wait   windows[0].tabs[0].panes[0].commands[0].command == "echo \"a b;c\"" && windows[0].tabs[0].panes[0].commands[0].exit == 0 timeout=10s
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"].status_line contains "echo \"a b;c\"" timeout=10s
```
