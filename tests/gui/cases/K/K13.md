# K13 跟进并入同一个任务：一张卡、净改动
requires: sandbox
checklist: K13
scenarios: [artifacts-followups]

一个任务三轮：改 a.txt，「continue」再改 a.txt，「ok」新增 b.txt。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k13 && cd work/k13 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k13 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k13"
type   "claude @scenario:artifacts-followups\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].turns[*] exists count=3 && windows[0].inspector.artifacts.cards[0].computing == false && windows[0].inspector.artifacts.summary.computing == false timeout=60s
assert windows[0].inspector.artifacts.cards[*] exists count=1
assert windows[0].inspector.artifacts.cards[0].sub_line == "第 1–3 轮 · 含 2 次跟进：continue → ok"
assert windows[0].inspector.artifacts.cards[0].computing == false
assert windows[0].inspector.artifacts.cards[0].files[*] exists count=2
assert windows[0].inspector.artifacts.summary.files == 2 && windows[0].inspector.artifacts.summary.added == 3
shot   k13-one-task
```

## judge
- `k13-one-task`：只有一张卡片，标题「时刻 · change a.txt」，下面小字「第 1–3 轮 · 含 2 次跟进：continue → ok」，右侧「2 文件 +3 −1」，两个文件行（a.txt、b.txt）；顶部汇总「▸ 本会话净改动 · 2 文件 +3 −1」。
