# H21 执行中新事件出现在最上面，且在可见区
requires: sandbox
checklist: H21
scenarios: [timeline-live]

`timeline-live` 先快速跑完 40 个 Bash（列表超过一屏），再每 2 秒一个、共 12 个。没有滚动过的检查器里，每个新事件都出现在标题正下方，
不需要滚动就能看到进展。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h21 && cd -P ~/work/h21 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h21"
type   "claude @scenario:timeline-live\n"
wait   windows[0].inspector.rows[?label=="Bash echo step 42"] exists timeout=30s
assert windows[0].inspector.rows[0].kind == "title" && windows[0].inspector.rows[1].rect != null
shot   h21-live
wait   windows[0].inspector.rows[1].label == "Bash echo step 47" timeout=15s
assert windows[0].inspector.rows[1].rect != null && windows[0].inspector.rows[?label=="Bash echo step 41"] exists
wait   windows[0].inspector.card.status == "idle" timeout=30s
assert windows[0].inspector.rows[1].label == "Bash echo step 52" && windows[0].inspector.rows[1].rect != null
shot   h21-done
```

## judge
- `h21-live` / `h21-done`：不动检查器，最新的 `Bash echo step N` 紧贴「时间线 · 第 1 轮」与过滤项下方，是可见的第一行；
  结束时最上面是 `step 52`，往下是 `step 51`、`50`……
