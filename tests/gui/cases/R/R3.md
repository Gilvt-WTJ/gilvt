# R3 总结失败显示原因，重试后恢复
requires: sandbox
checklist: R3
scenarios: [monitor-slow]

假大脑返回认证错误：会话运行中的自动总结失败，头部显示「✦ 总结失败：认证失败…· 重试」；删掉控制文件后点「重试」恢复。

## steps
```gilvt-steps
sh     rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count
sh     printf 'auth\n' > ~/.gilvt-fake-brain
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=true' --set 'monitor.exclude_paths=[]'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r3 && cd -P ~/work/r3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r3"
type   "claude @scenario:monitor-slow\n"
key    cmd+shift+o
wait   windows[0].monitor.cards[?group=="done"].summary.state == "failed" timeout=70s
assert windows[0].monitor.cards[?group=="done"].summary.header contains "认证失败"
assert windows[0].monitor.cards[?group=="done"].summary.header contains "重试"
shot   r3-failed
sh     rm -f ~/.gilvt-fake-brain
click  'rect(windows[0].monitor.cards[?group=="done"].summary)'
wait   windows[0].monitor.cards[?group=="done"].summary.state == "ready" timeout=30s
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=false'
```

## judge
- `r3-failed`：✦ 块左边是红色细条，头部红字「✦ 总结失败：认证失败（请在终端里登录这个 CLI）· 重试」。
