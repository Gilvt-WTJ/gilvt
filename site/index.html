A native macOS terminal for parallel coding agents

Agents work in parallel; your attention doesn’t. gilvt keeps your shell, every Claude Code and Codex session, and the review of their work in one native window, so every switch costs a keystroke instead of your focus.

Download for macOS View on GitHub

Universal (Apple silicon and Intel) · macOS 11 or later · signed and notarized by Apple · Apache-2.0

Three jobs, one window

No more hopping between a terminal, an editor, a diff tool and a dashboard. Each hop is a small context switch; gilvt removes them.

Your everyday terminal

Tabs, splits, GPU rendering, true color, the Kitty keyboard protocol, input methods and 725 themes. Use it for all your work, agents or not.

Every agent in view

One sidebar lists every session; the ones waiting for you rise to the top. ⇧⌘J jumps there across tabs and windows. Notifications, a Dock badge and the Monitor give you the big picture.

Click to review, edit in place

Click a timeline row to return to that moment, open any turn’s diff, preview code, Markdown and Mermaid, and fix it in the built-in editor. Agents can hand you a file with gilvt view.

The whole loop, without leaving the window

  1. RunStart claude or codex in a pane, or six of them.
  2. Get pingedThe session that needs you lights up. ⇧⌘J takes you there.
  3. ReviewOne click shows what this turn changed, file by file.
  4. EditFix it in place, then let the agent carry on.

And the details

Every turn, as a timeline

Commands, edits, TODOs and failures, turn by turn. Click a row and the terminal scrolls back to it.

What each turn changed ⌥⌘2

Per-turn artifacts with a "this turn" diff, so you can review an agent's work without leaving the terminal.

Find and resume sessions ⇧⌘R

Search sessions from days ago, resume them, review finished ones offline, start a new agent in a fresh git worktree.

The Monitor ⇧⌘O

All agents and terminals as cards. Ask "what needs me?" from a command bar in any tab, answered by your own local CLI.

Quick Look and an editor

Code with diffs, rendered Markdown and Mermaid, ⌘P fuzzy file search, and a built-in editor with live preview.

725 themes

A built-in collection plus your own themes, with separate light and dark picks. The window chrome follows the theme.

Built on a few rules

  • Agents stay in their native TUI. No chat UI of its own, no approval buttons.
  • Observe, never answer. gilvt shows state and moves focus; it never types into an agent.
  • Your configuration is untouched. Hooks are injected at launch; your rc files, ~/.claude and ~/.codex stay as they are.
  • No telemetry. The only request gilvt makes on its own is an update check you can turn off. Privacy
