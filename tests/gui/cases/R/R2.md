# R2 关闭自动刷新时只有手动总结
requires: sandbox
checklist: R2
scenarios: [three-turns]

`auto_summary = false`：跑完会话后卡片只有「✦ 生成总结」；点击后才生成。

## steps
```gilvt-steps
sh     rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=false'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r2 && cd -P ~/work/r2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r2"
type   "claude @scenario:three-turns\n"
key    cmd+shift+o
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=20s
sleep  3s
assert windows[0].monitor.cards[?group=="done"].summary.state == "none"
assert windows[0].monitor.cards[?group=="done"].summary.header == "✦ 生成总结"
sh     test ! -e ~/.gilvt-fake-brain.log
shot   r2-none
click  'rect(windows[0].monitor.cards[?group=="done"].summary)'
wait   windows[0].monitor.cards[?group=="done"].summary.state == "ready" timeout=30s
shot   r2-ready
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=false' --set 'monitor.auto_summary=true'
```

## judge
- `r2-none`：卡片标题下只有一个紫色虚线框「✦ 生成总结」。
- `r2-ready`：点击后变成完整的 ✦ 块。
