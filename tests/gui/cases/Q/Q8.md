# Q8 改名期间不弹提示
requires: sandbox
checklist: Q8
scenarios: [long-title]

右键 agent 行「重命名…」进入改名；改名期间鼠标在该行上不出现提示（`tooltip == null`）；Esc 取消改名后再悬停，提示出现。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q8 && cd -P ~/work/q8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q8"
type   "claude @scenario:long-title\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists timeout=15s
rclick 'rect(windows[0].sidebar.rows[?kind=="agent"])'
wait   windows[0].context_menu.items[?label=="重命名…"] exists timeout=5s
click  'menu("重命名…")'
hover  'rect(windows[0].sidebar.rows[?kind=="agent"])'
assert windows[0].sidebar.tooltip == null
key    esc
hover  'pane(focused)'
hover  'rect(windows[0].sidebar.rows[?kind=="agent"])'
wait   windows[0].sidebar.tooltip.text contains "Add terminal rows to the sidebar" timeout=5s
```

## judge
- 无截图判断项；改名期间没有提示、取消后有提示由状态断言覆盖。
