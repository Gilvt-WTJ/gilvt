# H16 等待横幅
requires: sandbox
checklist: H16
scenarios: [ask-question]

另一个会话在问你时，检查器顶部出现等待横幅；点击横幅跳到该会话（等同 `⌘⇧J`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h16 && cd -P ~/work/h16 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h16"
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="project:h16"].status == "awaiting_answer" && windows[0].inspector.card.status == "awaiting_answer" timeout=15s
# 聚焦的就是在等的会话时不显示横幅
assert windows[0].inspector.banner == null
key    cmd+t
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
wait   windows[0].inspector.banner == "claude · h16 在问你" timeout=5s
shot   h16-banner
click  'rect(windows[0].inspector.banner_rect)'
wait   windows[0].tabs[0].active == true && windows[0].tabs[0].panes[0].focused == true && windows[0].inspector.card.status == "awaiting_answer" timeout=5s
```

## judge
- `h16-banner`：横幅标题「claude · h16 在问你」（断言），带问题 `Cats or dogs?` 与等待时长（几秒；超过 1 分钟按分钟显示）。
- 点击后跳回标签 1 的该 pane，并像 `⌘⇧J` 一样闪一次浅蓝（闪烁太快拍不到，不做截图判断）。
