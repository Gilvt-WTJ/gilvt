# U2 Codex 配置摘要：禁用 MCP、Hooks 与记忆
requires: sandbox
checklist: U2
scenarios: [default]

准备用户层和项目层 Codex 配置，检查禁用 MCP、notify / hook、Skills / Prompts 与 AGENTS.md 摘要。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p .codex/skills/user .codex/prompts .agents/skills/shared work/u2/.git work/u2/.codex/skills/project work/u2/.agents/skills/project"
sh     "printf '%s\n' 'model = \"disk-gpt\"' 'approval_policy = \"on-request\"' 'sandbox_mode = \"read-only\"' 'notify = []' '[mcp_servers.user-mcp]' 'command = \"U2-MCP-SECRET\"' '[mcp_servers.off-mcp]' 'command = \"U2-OFF-SECRET\"' 'enabled = false' '[hooks]' 'Stop = []' > .codex/config.toml"
sh     "printf '%s\n' 'sandbox_mode = \"workspace-write\"' '[mcp_servers.project-mcp]' 'url = \"https://U2-URL-SECRET.invalid\"' > work/u2/.codex/config.toml"
sh     "printf 'global codex rules\n' > .codex/AGENTS.md && printf 'project rules\nsecond line\n' > work/u2/AGENTS.md && printf x > .codex/skills/user/SKILL.md && printf x > .codex/prompts/review.md && printf x > .agents/skills/shared/SKILL.md && printf x > work/u2/.codex/skills/project/SKILL.md && printf x > work/u2/.agents/skills/project/SKILL.md"
type   "cd -P ~/work/u2 && clear && codex @scenario:default u2 config\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" && windows[0].inspector.card.status == "idle" timeout=20s
key    cmd+alt+3
wait   windows[0].inspector.tab == "config" && windows[0].inspector.config.loading == false timeout=10s
assert windows[0].inspector.config.agent == "codex" && windows[0].inspector.config.cwd contains "/work/u2"
wait   windows[0].inspector.config.model.text == "gpt-5.6-sol" && windows[0].inspector.config.model.source == "runtime" timeout=10s
wait   windows[0].inspector.config.permission.text == "default" && windows[0].inspector.config.permission.source == "runtime" timeout=10s
assert windows[0].inspector.config.mcp[*] exists count=3 && windows[0].inspector.config.mcp[?name=="off-mcp"].detail == "已禁用" && windows[0].inspector.config.mcp[?name=="project-mcp"].source == "project"
assert windows[0].inspector.config.hooks[*] exists count=2 && windows[0].inspector.config.hooks[?name=="notify"].source == "user" && windows[0].inspector.config.hooks[?name=="Stop"].source == "user"
assert windows[0].inspector.config.skills == 4 && windows[0].inspector.config.commands == 1 && windows[0].inspector.config.subagents == 0
assert windows[0].inspector.config.memory[*] exists count=2 && windows[0].inspector.config.memory[?name contains "/.codex/AGENTS.md"].source == "user" && windows[0].inspector.config.memory[?name contains "/work/u2/AGENTS.md"].source == "project"
assert windows[0].inspector.config.sources[?path contains "/.codex/config.toml"].source == "user" && windows[0].inspector.config.sources[?path contains "/work/u2/.codex/config.toml"].source == "project"
assert windows[0].inspector.config.warnings[*] !exists
shot   u2-codex-config
```

## judge
- `u2-codex-config`：`off-mcp` 带「已禁用」，用户 / 项目来源可区分，Hooks、扩展与两份 AGENTS.md 数量正确。
- 截图和保存的 DebugState 中没有 `U2-MCP-SECRET`、`U2-OFF-SECRET` 或 `U2-URL-SECRET`。
