# L9 置顶：同一优先级里排最前，重启后保持
requires: sandbox
checklist: L9
scenarios: [hist-claude]

两个待 Review 的会话，甲比乙先完成所以排第一。打开乙的 Review 按 `P` 置顶：乙排到第一；再按 `P` 取消。置顶写进 `reviews.json`，`⌘Q` 重开后保持。
