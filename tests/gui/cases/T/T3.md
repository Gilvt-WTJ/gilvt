# T3 没有标题时：第一句话、跳过应答，Codex 用 thread_name
requires: sandbox
checklist: T3
scenarios: [hist-claude, hist-codex]

没有 Agent 标题的会话取提示词的第一句（句号前），太长的截断；Codex 的标题来自 `~/.codex/session_index.jsonl` 的 `thread_name`。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions" "$HOME/.codex/session_index.jsonl"'
type   "mkdir -p ~/work/t3 && cd -P ~/work/t3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/t3"
seed   hist-claude --cwd work/t3 --id c1a0de00-0000-4000-8000-0000000c0301 --prompt "整理 README 的结构。然后补上测试用例和文档说明，最后更新变更记录"
seed   hist-codex --cwd work/t3 --id 01990000-0000-7000-8000-0000000c0301 --prompt "t3 Codex 会话" --ai-title "调研验证可行性"
seed   hist-codex --cwd work/t3 --id 01990000-0000-7000-8000-0000000c0302 --prompt "t3 另一个 Codex 会话"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
assert windows[0].overlay.rows[?session contains "c1a0de00"].title == "整理 README 的结构" && windows[0].overlay.rows[?session contains "c1a0de00"].title_source == "prompt"
assert windows[0].overlay.rows[?session contains "0c0301"].title == "调研验证可行性" && windows[0].overlay.rows[?session contains "0c0301"].title_source == "ai"
assert windows[0].overlay.rows[?session contains "0c0302"].title == "t3 另一个 Codex 会话" && windows[0].overlay.rows[?session contains "0c0302"].title_source == "prompt"
shot   t3-titles
key    esc
wait   windows[0].overlay == null
```

## judge
- `t3-titles`：Claude 的会话只显示第一句「整理 README 的结构」，没有后面的长尾；Codex 的第一个会话显示「调研验证可行性」，另一个没有 `thread_name` 的显示它的提示词。
