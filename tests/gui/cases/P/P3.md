# P3 cwd 目录被删之后重开：该 pane 回到主目录并提示
requires: sandbox
checklist: P3
scenarios: []

分屏的两个 pane 分别在 `keep` 和 `gone`。退出后删掉 `gone` 目录再重开：`gone` 那个 pane 在 `$HOME` 启动，窗口顶部出现「目录 … 已不存在，该 pane 改在主目录启动」，
`keep` 那个 pane 不受影响。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/p3/keep ~/work/p3/gone && cd -P ~/work/p3/keep && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/p3/keep"
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "cd -P ~/work/p3/gone && clear\n"
wait   windows[0].tabs[0].panes[1].cwd contains "/work/p3/gone"
assert windows[0].error_banner == null
key    cmd+q
sleep  2s
# gilvt 已经退出：删掉其中一个 pane 的目录
sh     'rm -rf "$HOME/work/p3/gone" && test ! -e "$HOME/work/p3/gone"'
restart
wait   windows[0].tabs[0].panes[*] exists count=2 timeout=20s
wait   windows[0].error_banner contains "已不存在" && windows[0].error_banner contains "/work/p3/gone" timeout=10s
# keep 的 pane 保持原目录；gone 的 pane 不再在 gone（回到沙盒的 $HOME，不在 /work/ 下）
wait   windows[0].tabs[0].panes[?cwd contains "/work/p3/keep"] exists count=1 timeout=15s
assert windows[0].tabs[0].panes[?cwd contains "/work/p3/gone"] !exists
assert windows[0].tabs[0].panes[?cwd contains "/work/"] exists count=1
state  windows[0].tabs[0].panes[*].cwd
state  windows[0].layout
shot   p3-notice
```

## judge
- `p3-notice`：窗口顶部的红色横幅写着「目录 …/work/p3/gone 已不存在，该 pane 改在主目录启动」，点击可关闭。
- `state windows[0].tabs[0].panes[*].cwd` 的输出里一个是 `…/work/p3/keep`，另一个是沙盒的 `$HOME`（`…/gilvt-gui-…/home`），没有 `…/work/p3/gone`。
- 横幅只说一次；两个 pane 的分屏结构仍在（左右两个 pane）。
