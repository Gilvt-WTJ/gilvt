# L3 Claude 与 Codex 的新 turn 入队，只读 Review 显示最终回复
requires: sandbox
checklist: L3
scenarios: [hist-claude, hist-codex]

一个 Claude 会话和一个 Codex 会话各有两轮已完成的 turn，都在 baseline 之后才出现，所以都进待 Review。`Space` 打开只读 Review：
每个 turn 的 prompt、Agent 最终回复（Claude 和 Codex 都要有）、结果都显示出来；只是打开、查看、返回，不会把任何 turn 标记为已 Review。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l3 && cd -P ~/work/l3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l3"
seed   hist-claude --cwd work/l3 --id c1a0de00-0000-4000-8000-0000000b0301 --prompt "l3 Claude 的 Review"
seed   hist-codex --cwd work/l3 --id 01990000-0000-7000-8000-0000000b0301 --prompt "l3 Codex 的 Review"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
assert windows[0].overlay.rows[0].session_key contains "c1a0de00" && windows[0].overlay.rows[0].unreviewed_count == 2 && windows[0].overlay.session_review == null
key    space
wait   windows[0].overlay.session_review.session_key contains "c1a0de00" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.mode == "incremental" && windows[0].overlay.session_review.turns[2] !exists && windows[0].overlay.session_review.snapshot_through != null
assert windows[0].overlay.session_review.turns[0].outcome == "done" && windows[0].overlay.session_review.turns[0].has_reply == true && windows[0].overlay.session_review.turns[1].has_reply == true
assert windows[0].overlay.session_review.actions.review_next.enabled == true && windows[0].overlay.session_review.error == null
shot   l3-claude
key    esc
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.session_review == null
key    down
key    space
wait   windows[0].overlay.session_review.session_key contains "01990000" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
assert windows[0].overlay.session_review.turns[2] !exists && windows[0].overlay.session_review.turns[0].has_reply == true && windows[0].overlay.session_review.turns[1].has_reply == true
shot   l3-codex
key    esc
wait   windows[0].overlay.session_review == null
assert windows[0].overlay.tabs[?name=="review"].count == 2 && windows[0].overlay.rows[0].unreviewed_count == 2 && windows[0].overlay.rows[1].unreviewed_count == 2
key    esc
wait   windows[0].overlay == null
```

## judge
- `l3-claude` / `l3-codex`：每个 turn 卡片依次是「你」的 prompt、「Agent 最终回复」（Claude：「README 已整理。」「已补充用法。」；Codex 对应的回复）、结果（已完成）与 tokens、可折叠的「过程」；底部有 跳过 / 稍后提醒 / 置顶 / 已 Review，下一个。
- 窗口够宽时队列在左、Review 在右（`session_review.layout == "wide"`）。
- 打开、返回之后两个会话仍然各有 2 轮待 Review（断言已确认）。
