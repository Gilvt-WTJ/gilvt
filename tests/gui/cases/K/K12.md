# K12 右键复制路径:行号
requires: sandbox
checklist: K12
scenarios: [artifacts-basic]

右键点文件行：剪贴板得到 `路径:行号`（会覆盖用户的剪贴板；`run.sh` 事先保存、事后还原）。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k12 && cd work/k12 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k12 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k12"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=30s
rclick 'rect(windows[0].inspector.artifacts.cards[0].files[?path=="hello.txt"])'
wait   windows[0].inspector.toast == "已复制" timeout=5s
clipboard contains "hello.txt:1"
```

## judge
- 无视觉判断；剪贴板内容由 `clipboard contains` 断言（行号是该文件第一处改动，hello.txt 是新文件，所以是 1）。
