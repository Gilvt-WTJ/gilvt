# I9 单击、双击与右键菜单的恢复
requires: sandbox
checklist: I9
scenarios: [hist-claude]

单击只移动光标；双击按 `↩` 的规则恢复；右键菜单「恢复」「在右侧恢复」分别等同 `↩` / `⌘↩`。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i9 --age 1h --id c1a0de00-0000-4000-8000-000000000901 --prompt "i9 第一个"
seed   hist-claude --cwd work/i9 --age 2h --id c1a0de00-0000-4000-8000-000000000902 --prompt "i9 第二个"
seed   hist-claude --cwd work/i9 --age 3h --id c1a0de00-0000-4000-8000-000000000903 --prompt "i9 第三个"
type   "cd -P ~/work/i9 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i9"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 && windows[0].overlay.selected == 0 timeout=15s
shot   i9-list
click  'rect(windows[0].overlay.rows[?title contains "i9 第二个"])'
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.selected == 1
dclick 'rect(windows[0].overlay.rows[?title contains "i9 第二个"])'
# 焦点 pane 是空闲 shell：就地恢复
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].screen_tail[*] contains "claude --resume c1a0de00-0000-4000-8000-000000000902" timeout=5s
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=10s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
shot   i9-menu-1
rclick 'rect(windows[0].overlay.rows[?title contains "i9 第一个"])'
wait   windows[0].context_menu.items[*].label == "恢复" timeout=3s
click  'menu("恢复")'
# 焦点 pane 在运行 Agent：「恢复」= ↩ = 开新标签
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].panes[0].screen_tail[*] contains "claude --resume c1a0de00-0000-4000-8000-000000000901" timeout=15s
wait   windows[0].tabs[1].panes[0].foreground == "agent:claude" timeout=10s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
shot   i9-menu-2
rclick 'rect(windows[0].overlay.rows[?title contains "i9 第三个"])'
wait   windows[0].context_menu.items[*].label == "在右侧恢复" timeout=3s
click  'menu("在右侧恢复")'
wait   windows[0].tabs[1].panes[*] exists count=2 && windows[0].tabs[1].panes[1].focused == true timeout=5s
wait   windows[0].tabs[1].panes[1].foreground == "agent:claude" && windows[0].tabs[1].panes[1].screen_tail[*] contains "claude --resume c1a0de00-0000-4000-8000-000000000903" timeout=15s
```

## judge
- 单击后浮层仍开着、光标在第二行（断言）；`i9-list` 里每行的位置用于换算点击坐标。
- 右键菜单里「恢复」「在右侧恢复」两项都在；分别按 `↩`（新标签，因为焦点 pane 在运行 Agent）与 `⌘↩`（右侧分屏）执行（断言）。
