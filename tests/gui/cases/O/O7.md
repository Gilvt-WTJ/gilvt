# O7 设置窗口「外观」页：打开、搜索、深浅过滤
requires: sandbox
checklist: O7
scenarios: []

`⌘,` 打开设置窗口，点左栏「◐ 外观」；搜索框输入 `nord`，点分段控件「深色」。选中的分段项用强调色填充（浅色主题下也比未选中的醒目）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="appearance"])'
wait   settings.page == "appearance" && settings.pages[?id=="appearance"].selected == true timeout=5s
assert settings.appearance.mode == "fixed"
assert settings.appearance.fixed == "gilvt Light"
assert settings.appearance.chips[?id=="mode-fixed"].on == true
click  'rect(settings.appearance.search_rect)'
type   --window key "nord"
wait   settings.appearance.query == "nord" timeout=5s
assert settings.appearance.rows[0].name contains "Nord"
click  'rect(settings.appearance.chips[?id=="filter-dark"])'
wait   settings.appearance.filter == "dark" && settings.appearance.chips[?id=="filter-dark"].on == true timeout=5s
assert settings.appearance.rows[?name=="Nord"] exists
# 搜索和过滤只改列表，不换主题
assert theme.name == "gilvt Light"
shot   --window key o7
key    cmd+w
wait   settings !exists timeout=5s
```

## judge
- `o7`：「设置」窗口，左栏「◐ 外观」是紫底的当前页、下面是「◎ 监控官」；搜索框里是「nord」，「深色」与「固定」两个分段项是紫色填充白字，比未选中的项醒目；左侧列表只有深色的 Nord 系主题（每行一个色点），右侧是高亮主题的 16 色、示例输出和四种状态标记；整页配色与「◎ 监控官」页一致（同一套底色、边框和控件）。
