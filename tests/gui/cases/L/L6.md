# L6 Review 打开期间新完成的 turn 不会被这次确认吞掉
requires: sandbox
checklist: L6
scenarios: [hist-claude]

打开一个会话的 Review（快照里有 2 轮），这时 Agent 又完成了 2 轮（`seed --append`：旧记录原样保留，所以 Review 位置仍然有效）。
`⌘↩` 只推进到打开页面时已完成的那一轮；关闭再重新打开 Session Center 后，新完成的 2 轮仍在待 Review 里。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l6 && cd -P ~/work/l6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l6"
seed   hist-claude --cwd work/l6 --id c1a0de00-0000-4000-8000-0000000b0601 --prompt "l6 先完成两轮"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b0601"].unreviewed_count == 2 timeout=15s
key    space
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists && windows[0].overlay.session_review.snapshot_through != null timeout=10s
assert windows[0].overlay.session_review.turns[2] !exists
# Review 还开着的时候，Agent 又完成了两轮
seed   hist-claude --cwd work/l6 --id c1a0de00-0000-4000-8000-0000000b0601 --append --prompt "l6 打开期间追加"
key    cmd+enter
wait   windows[0].overlay.session_review == null && windows[0].overlay.rows[?session_key contains "0b0601"] !exists timeout=10s
assert windows[0].overlay.store_last_error == null
key    esc
wait   windows[0].overlay == null
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b0601"].unreviewed_count == 2 timeout=15s
assert windows[0].overlay.tabs[?name=="review"].count == 1
shot   l6-requeued
key    esc
wait   windows[0].overlay == null
```

## judge
- `l6-requeued`：这个会话重新出现在「待 Review」里，写着 2 轮待 Review（只有打开期间新完成的那两轮，之前确认过的两轮没有再出现）。
