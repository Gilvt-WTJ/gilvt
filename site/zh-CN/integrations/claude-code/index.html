让终端知道 Claude Code 什么时候需要你

Claude Code 保留原生 TUI。gilvt 观察本机 session 生命周期，在周围增加左栏、通知、逐轮 review 和持久会话导航。

更新于 2026-10-08 · gilvt {{VERSION}}

设置：安装 gilvt，打开 pane 并运行 claude。对于在 gilvt 内启动的会话，状态集成会在启动时注入，不会重写你的 Claude 设置或 shell rc 文件。

gilvt 能识别什么

gilvt 组合 Claude Code hooks、本机会话记录和进程身份，把执行轮次、权限请求、问题、失败、完成和子 Agent 活动统一成一个会话模型。

  • 左栏把等待审批或回答的会话移入「需要你」。
  • pane 描边和标签圆点显示执行、注意、错误和完成未读状态。
  • 系统通知把你带回正确 pane。
  • 检查器把命令、工具调用、编辑和 TODO 连接成逐轮时间线。

Review 与恢复

产物标签按轮次组织文件，并打开「本轮」diff。Session Center 可以查找旧 Claude 会话、离线 review 已完成工作，并为原项目生成受支持的恢复命令。

配置仍然属于你

从 gilvt 启动 Claude 使用临时集成设置，而不是永久编辑现有 Claude 配置。检查器的「配置」标签读取模型、权限、MCP、hooks、skills 和记忆文件的有效脱敏摘要。

如果希望 gilvt 发现其他终端应用里启动的 Claude，会话可以显式、可逆地运行 gilvt integrate install 安装全局 hooks；普通 gilvt 内会话不需要这一步。

失败时的行为

hook 缺失或记录格式变化不会阻塞终端输入。gilvt 会退回推断或精简状态；只有具备精确身份依据的会话才允许精确进程控制。
