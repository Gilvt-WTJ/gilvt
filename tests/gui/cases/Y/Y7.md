# Y7 终端卡片补课，点一条回到那条命令
requires: sandbox
checklist: Y7
scenarios: []

终端里执行两条命令后，补课列出它们（最新在前）；点较早的那条，跳到该 pane，视图滚回那条命令。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "echo first-marker\n"
wait   windows[0].tabs[0].panes[0].commands[0].command == "echo first-marker" && windows[0].tabs[0].panes[0].commands[0].running == false timeout=10s
type   "seq 1 200\n"
wait   windows[0].tabs[0].panes[0].commands[0].command == "seq 1 200" && windows[0].tabs[0].panes[0].commands[0].running == false timeout=10s
key    cmd+shift+o
wait   windows[0].monitor.cards[?kind=="terminal"] exists count=1 timeout=10s
click  'rect(windows[0].monitor.cards[?kind=="terminal"].catchup)'
wait   windows[0].monitor.cards[?kind=="terminal"].expanded == true timeout=5s
assert windows[0].monitor.cards[?kind=="terminal"].rows[0].text contains "seq 1 200"
assert windows[0].monitor.cards[?kind=="terminal"].rows[1].text contains "echo first-marker"
# 点之前终端停在底部：seq 的最后一行 200 在可见区里（first-marker 早已滚出）
assert windows[0].tabs[1].panes[0].screen_tail[*] == "200"
click  'rect(windows[0].monitor.cards[?kind=="terminal"].rows[1])'
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].focused == true timeout=5s
wait   windows[0].tabs[1].panes[0].screen_tail[*] contains "first-marker" timeout=5s
shot   y7
```

## judge
- `y7`：终端视图滚回到 `echo first-marker` 附近（不在最底部，`seq` 的 200 行输出大部分在视图下方），那几行短暂高亮。
