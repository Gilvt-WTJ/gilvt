# W3 编辑器实时预览：Mermaid 图表与 SVG 图片
requires: sandbox
checklist: W3
scenarios: []

`.mmd` 的实时预览是 `diagram`，`.svg` 的是 `image`；在编辑器里改动后预览重建（`refreshes` 增加），不出现横幅。
先 `restart --set font_size=9`（理由同 W1），结束时改回 13。字号 9 时编辑 pane 是终端标签里的分屏，所以不能关标签；每个文件改完先 `⌘S` 保存（缓冲区干净），再 `⌘W` 只关编辑 pane（预览跟着关，标签回到只剩终端），
磁盘文件应是「改动 + 原内容」。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/w3 && printf 'graph TD\n  A-->B\n' > work/w3/flow.mmd && printf '<svg xmlns=\"http://www.w3.org/2000/svg\" width=\"10\" height=\"20\"/>' > work/w3/logo.svg && cp work/w3/logo.svg work/w3/logo.orig"
type   "cd -P ~/work/w3 && clear && gilvt view flow.mmd\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w3/flow.mmd" timeout=10s
key    e
wait   windows[0].editors[0].path contains "/work/w3/flow.mmd" timeout=5s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "diagram" && windows[0].editors[0].preview.refreshes == 1 timeout=10s
assert windows[0].editors[0].preview.banner == null
shot   w3-diagram
click  'rect(windows[0].editors[0].rect)'
key    cmd+down
type   "  B-->C"
wait   windows[0].editors[0].dirty == true timeout=5s
wait   windows[0].editors[0].preview.refreshes != 1 timeout=5s
assert windows[0].editors[0].preview.banner == null
key    cmd+s
wait   windows[0].editors[0].dirty == false timeout=5s
key    cmd+w
wait   windows[0].editors[*] !exists && windows[0].tabs[0].panes[*] exists count=1 timeout=5s
sh     "printf 'graph TD\n  A-->B\n  B-->C' | cmp - work/w3/flow.mmd"
wait   windows[0].tabs[0].panes[0].focused == true timeout=5s
type   "clear && gilvt view logo.svg\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w3/logo.svg" timeout=10s
key    e
wait   windows[0].editors[0].path contains "/work/w3/logo.svg" timeout=5s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "image" && windows[0].editors[0].preview.refreshes == 1 timeout=10s
assert windows[0].editors[0].preview.banner == null
shot   w3-image
click  'rect(windows[0].editors[0].rect)'
key    cmd+up
type   " "
wait   windows[0].editors[0].dirty == true timeout=5s
wait   windows[0].editors[0].preview.refreshes != 1 timeout=5s
assert windows[0].editors[0].preview.banner == null
key    cmd+s
wait   windows[0].editors[0].dirty == false timeout=5s
key    cmd+w
wait   windows[0].editors[*] !exists && windows[0].tabs[0].panes[*] exists count=1 timeout=5s
sh     "printf ' ' | cat - work/w3/logo.orig | cmp - work/w3/logo.svg"
restart --set font_size=13
```

## judge
- `w3-diagram`：预览 pane 里是 A → B 的流程图，没有错误横幅。
- `w3-image`：预览 pane 里是一个 10×20 的矩形图（SVG 空图可能只是一块空白，不显示错误即可）。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
