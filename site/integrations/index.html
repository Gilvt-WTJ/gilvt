Agents keep their native TUI

gilvt observes Claude Code and Codex through their supported local signals, then adds status, navigation, review and session management around them.

Automatic local detection

Start an Agent in a pane. gilvt associates its process, hooks and durable session record with that pane.

No proprietary chat layer

Prompts, approvals and questions stay inside Claude Code or Codex. gilvt never answers for you.

Graceful fallback

If a signal is unavailable or its format changes, the pane remains a working terminal and the integration degrades.
