# U4 配置标签：行内展开、扩展弹窗与打开 Markdown
requires: sandbox
checklist: U4
scenarios: [default]

MCP / Hooks / 记忆的行可以就地展开看脱敏后的详情；Skills / 命令 / 子 Agent 在弹窗里列出名称、描述和文件，点一项在 Quick Look 里打开它的 Markdown。

## judge
- `u4-rows-expanded`：「remote」展开后只有类型一行；PreToolUse 展开后只有 `Bash · audit (+2 参数)`；展开区比行缩进一级，▸ 变 ▾。
- `u4-skills-dialog`：弹窗标题「Skills · 2」，每项有名称、层级标签「项目」、描述、路径和「打开」；顶部说明「只读」；弹窗在窗口内，不遮住终端之外的东西。
- `u4-skill-opened`：Quick Look 渲染出 `code-review` 的 Markdown，弹窗已经关闭。
- 截图和保存的 DebugState 中没有 `U4-ENV-SECRET`、`U4-ARG-SECRET`、`U4-URL-SECRET`、`U4-HEADER-SECRET`。
