安装

  1. 打开下载好的 Gilvt-{{VERSION}}.dmg。
  2. 把 Gilvt 拖进「应用程序」，再从那里打开。如果直接在磁盘映像里打开，gilvt 会显示一条横幅，帮你把自己移过去。
  3. 在 pane 里运行 claude 或 codex，左栏和检查器会自动识别这个会话，不需要任何配置。

界面默认简体中文，可以在设置（⌘,）→「语言」里切换成 English。第一次有会话需要你时，请允许通知，这样你在别的应用里也能收到提醒。

更新

gilvt 会自动保持最新：在后台检查，有新版本就下载，并在你退出 gilvt 时安装，正在跑的 Agent 不会被打断。有更新在等待时，左栏底部会提示；也可以在应用菜单里点「检查更新…」立即检查。

想自己决定？在 config.toml 的 [update] 下设 mode = "check"（下载前先问你）或 mode = "off"。更新都经过签名和公证，检查时不发送任何标识。

从源码构建

需要 Rust 和 Xcode Command Line Tools（不需要完整的 Xcode）。从源码构建的版本没有自动更新。

git clone https://github.com/Gilvt-WTJ/gilvt.git
cd gilvt
scripts/bundle.sh release
open target/release/Gilvt.app
