# H2 点击有锚点的事件跳到终端位置
requires: sandbox
checklist: H2
scenarios: [timeline]

`timeline` 剧本最后有一段 100 行的回复，把 `echo early` 顶出屏幕；点击它在时间线里的行，终端滚回该位置，并高亮 3 行 1 秒。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h2 && cd -P ~/work/h2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h2"
type   "claude @scenario:timeline\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
# 前提：echo early 已经不在可见区域
assert windows[0].tabs[0].panes[0].screen_tail[*] != "⏺ Bash(echo early)"
shot   h2-before
# 行的中心落在文字上（▸ 在行首，另有自己的 toggle rect）
click  'rect(windows[0].inspector.rows[?label contains "echo early"])'
wait   windows[0].tabs[0].panes[0].screen_tail[*] == "⏺ Bash(echo early)" timeout=3s
shot   h2-highlight
sleep  1500ms
shot   h2-after
```

## judge
- `h2-highlight`：终端滚回 `⏺ Bash(echo early)` 附近，从该行起 3 行有高亮底色；`h2-after`（1.5 秒后）高亮已经消失，
  终端停在同一位置。`shot` 自身要花几百毫秒，高亮没拍到时记为 ⚠️（需要人工看一次），不算失败。
- 两张图里 fake claude 的 `❯` 提示符后面都没有多出字符：点击没有往 pane 写入任何按键。
- 点击是前台动作（gilvt 会来到前台）；锁屏时 `click` 退出 5，这个用例记为 ⏭。
