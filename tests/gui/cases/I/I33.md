# I33 清理向导的按钮：归档让计数下降，移到废纸篓先出确认条
requires: sandbox
checklist: I33
scenarios: [hist-claude, think-long]

「已 Review 且 30 天未动」里点［归档 N 个］：横幅「已归档 N 个会话」，预设重新计算，这些会话离开该预设（以及「空会话」之类只看
未归档会话的预设）。「空会话」里点［移到废纸篓 N 个（… + 附属 …）］只出确认条（同会话面板的文案，带「+ 附属」），按钮在确认条打开时
不可用；`Esc` 取消，什么也没移动。按钮只能点击（前台动作）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/i33 && cd -P ~/work/i33 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i33"
seed   hist-claude --cwd work/i33 --age 40d --id c1a0de00-0000-4000-8000-000000003301 --prompt "i33 旧甲"
seed   hist-claude --cwd work/i33 --age 45d --id c1a0de00-0000-4000-8000-000000003302 --prompt "i33 旧乙"
seed   think-long --cwd work/i33 --id c1a0de00-0000-4000-8000-000000003303 --prompt "i33 空" --session-data
key    cmd+shift+k
wait   windows[0].overlay.kind == "cleanup" && windows[0].overlay.computing == false && windows[0].overlay.presets[2].count == 3 timeout=15s
assert windows[0].overlay.presets[0].count == 1 && windows[0].overlay.presets[1].count == 2 && windows[0].overlay.presets[3].count == 0
# 已 Review 且 30 天未动 → 归档 2 个
key    down
wait   windows[0].overlay.preset == 1 && windows[0].overlay.buttons[?action=="archive"].label == "归档 2 个" && windows[0].overlay.buttons[?action=="archive"].enabled == true timeout=3s
click  'rect(windows[0].overlay.buttons[?action=="archive"])'
wait   windows[0].overlay.banner == "已归档 2 个会话" && windows[0].overlay.computing == false && windows[0].overlay.presets[1].count == 0 timeout=10s
assert windows[0].overlay.presets[0].count == 1 && windows[0].overlay.presets[2].count == 3 && windows[0].overlay.presets[3].count == 0
assert windows[0].overlay.rows[0] !exists && windows[0].overlay.buttons[?action=="archive"].enabled == false
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i33-archived
sh     'python3 -c "import json,sys; s=json.load(open(sys.argv[1]))[\"sessions\"]; sys.exit(0 if all(s[\"claude:c1a0de00-0000-4000-8000-00000000330\" + n].get(\"archived_turns\") == 2 for n in \"12\") else 1)" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
# 空会话 → 移到废纸篓：只出确认条，Esc 取消
key    up
wait   windows[0].overlay.preset == 0 && windows[0].overlay.rows[0].title contains "i33 空" timeout=3s
assert windows[0].overlay.buttons[?action=="trash"].label contains " + 附属 " && windows[0].overlay.buttons[?action=="trash"].enabled == true
click  'rect(windows[0].overlay.buttons[?action=="trash"])'
wait   windows[0].overlay.confirm.text contains "1 个会话 · " && windows[0].overlay.confirm.text contains " + 附属 " && windows[0].overlay.confirm.text contains "将移到废纸篓" timeout=3s
assert windows[0].overlay.buttons[?action=="trash"].enabled == false && windows[0].overlay.buttons[?action=="archive"].enabled == false
sleep  1s
shot   i33-confirm
key    esc
wait   windows[0].overlay.kind == "cleanup" && windows[0].overlay.confirm == null timeout=3s
assert windows[0].overlay.presets[0].count == 1 && windows[0].overlay.buttons[?action=="trash"].enabled == true
sh     "find .claude -name 'c1a0de00-0000-4000-8000-000000003303.jsonl' | grep -q . && test -f .claude/file-history/c1a0de00-0000-4000-8000-000000003303/x"
key    esc
wait   windows[0].overlay.kind == "sessions" timeout=3s
key    esc
wait   windows[0].overlay == null
```

## judge
- `i33-archived`：顶部横幅「已归档 2 个会话」；「已 Review 且 30 天未动」变成「0 个 · 0 MB」，右边没有行，［归档 0 个］是灰的。
- `i33-confirm`：底部的摘要与按钮换成确认条「1 个会话 · X MB + 附属 Y MB 将移到废纸篓（可从废纸篓还原）」与［取消］［移到废纸篓］。
- 最后的 `sh` 确认 `Esc` 之后会话记录和附属数据都还在原处。
