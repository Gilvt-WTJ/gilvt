# Z4 把分屏里的编辑器 pane 拖到标签栏：移到新标签
requires: sandbox
checklist: Z4
scenarios: []

Quick Look 里按 `⌥E`：沙盒窗口在 13 号字下默认会给编辑器开新标签，`⌥` 翻转成分屏，编辑器 pane 出现在终端右边。
把编辑器的标题栏拖到标签栏，编辑器移到新标签；未保存的修改（●）跟着走。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/z4 && printf 'hello\n' > work/z4/notes.txt"
type   "cd -P ~/work/z4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/z4"
type   "gilvt view notes.txt\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.code exists timeout=10s
key    alt+e
wait   windows[0].editors[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].kind == "editor" && windows[0].tabs[0].panes[1].header exists timeout=10s
click  'rect(windows[0].editors[0].rect)'
type   "x"
wait   windows[0].editors[0].dirty == true timeout=5s
drag   'rect(windows[0].tabs[0].panes[1].header)' 'rect(windows[0].tab_bar)'
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].kind == "editor" timeout=5s
assert windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].kind == "terminal"
assert windows[0].editors[0].tab == 1 && windows[0].editors[0].dirty == true
shot   z4-moved
```

## judge
- `z4-moved`：第二个标签是编辑器（标题带 ●），占满 pane 区域；第一个标签只剩终端。
- 如果 `⌥E` 在这台机器上没有分屏（窗口更宽、列数够分屏时默认就是分屏，`⌥` 反而开新标签），改用 `E` 重跑。
