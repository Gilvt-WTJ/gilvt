# S7 英文界面：浮层、预览与编辑器没有中文
requires: sandbox
checklist: S7
scenarios: []

`language = "en"` 下依次打开 `⌘P` 文件面板（有结果、无匹配）、Quick Look 预览、编辑 pane、`⌘⇧R` 会话面板和 `⌘⇧N` 新建 Agent：
每一步断言 `untranslated` 为空。`work/s7` 里只有 ASCII 文件名和内容。

## steps
```gilvt-steps
restart --set 'language="en"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/s7/.git && printf '# Notes\n\nhello from s7\n' > work/s7/notes.md && printf 'fn main() {}\n' > work/s7/main.rs"
type   "cd -P ~/work/s7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/s7" timeout=10s
# 文件面板：无匹配
key    cmd+p
wait   windows[0].overlay.kind == "finder" timeout=5s
assert untranslated[*] exists count=0
type   "zzzz-no-such-file"
wait   windows[0].overlay.query == "zzzz-no-such-file" && windows[0].overlay.items == 0 timeout=10s
assert untranslated[*] exists count=0
shot   s7-finder-empty
key    esc
wait   windows[0].overlay == null timeout=5s
# 文件面板 → Quick Look 预览
key    cmd+p
wait   windows[0].overlay.kind == "finder" timeout=5s
type   "notes"
wait   windows[0].overlay.query == "notes" && windows[0].overlay.items != 0 timeout=10s
key    enter
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/s7/notes.md" && windows[0].overlay.base != null timeout=10s
assert untranslated[*] exists count=0
shot   s7-preview
# 预览 → 编辑 pane
key    e
wait   windows[0].overlay == null && windows[0].editors[0].path contains "/work/s7/notes.md" timeout=10s
assert untranslated[*] exists count=0
shot   s7-editor
key    cmd+shift+w
wait   windows[0].editors[*] !exists && windows[0].tabs[*] exists count=1 timeout=5s
# 会话面板
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=5s
assert untranslated[*] exists count=0
shot   s7-sessions
key    esc
wait   windows[0].overlay == null timeout=5s
# 新建 Agent
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" timeout=5s
assert untranslated[*] exists count=0
shot   s7-new-agent
key    esc
wait   windows[0].overlay == null timeout=5s
restart --set 'language="zh-CN"'
```

## judge
- `s7-finder-empty`：面板标题、提示和「No matches」是英文。
- `s7-preview`：预览标题、diff 基准、底部按键提示是英文。
- `s7-editor`：编辑器标题栏与状态栏是英文（编码名如 `UTF-8` 原样）。
- `s7-sessions`、`s7-new-agent`：筛选项、按键提示、按钮都是英文；新建 Agent 的「⌘1 / ⌘2」提示只出现一次。
