# W5 编辑器实时预览：超大文件只在保存后更新
requires: sandbox
checklist: W5
scenarios: []

超过 50 000 行的 `.md`：开预览后顶部横幅含「文件太大」，输入不触发刷新（`refreshes` 不变）；`⌘S` 之后预览更新，`refreshes` 增加。打开预览只构建一次（`refreshes == 1`），横幅不会被这次构建清掉。
先 `restart --set font_size=9`（理由同 W1），结束时改回 13。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/w5 && seq 1 60000 | sed 's/^/line /' > work/w5/big.md"
type   "cd -P ~/work/w5 && clear && gilvt view big.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w5/big.md" timeout=20s
key    e
wait   windows[0].editors[0].path contains "/work/w5/big.md" timeout=20s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.banner contains "文件太大" && windows[0].editors[0].preview.refreshes == 1 timeout=20s
shot   w5-banner
click  'rect(windows[0].editors[0].rect)'
key    cmd+up
type   "x"
wait   windows[0].editors[0].dirty == true timeout=5s
sleep  1s
assert windows[0].editors[0].preview.refreshes == 1 && windows[0].editors[0].preview.banner contains "文件太大"
key    cmd+s
wait   windows[0].editors[0].dirty == false timeout=20s
wait   windows[0].editors[0].preview.refreshes != 1 timeout=20s
restart --set font_size=13
```

## judge
- `w5-banner`：预览 pane 顶部有「文件太大，未实时预览 · 保存后更新」横幅。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
