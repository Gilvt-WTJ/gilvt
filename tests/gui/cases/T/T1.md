# T1 会话名：Agent 自己的标题 > 兜底的提示词，手动改名永远最高
requires: sandbox
checklist: T1
scenarios: [hist-claude]

三个 Claude 历史会话：A 只有 `ai-title`；B 有 `ai-title` 和 `custom-title`（用户在 Claude 里改的，要压过生成的）；C 没有任何标题、第一条提示词是「继续」
（应答，不是主题）。「会话」浮层里 A 显示生成的标题，B 显示 custom 标题，C 显示第一个有信息量的提示词；`title_source` 说明名字从哪来。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions" "$HOME/.codex/session_index.jsonl"'
type   "mkdir -p ~/work/t1 && cd -P ~/work/t1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/t1"
seed   hist-claude --cwd work/t1 --id c1a0de00-0000-4000-8000-0000000c0101 --prompt "继续 t1a" --ai-title "Calc 重构方案"
seed   hist-claude --cwd work/t1 --id c1a0de00-0000-4000-8000-0000000c0102 --prompt "继续 t1b" --ai-title "生成的标题" --custom-title "我改的标题"
seed   hist-claude --cwd work/t1 --id c1a0de00-0000-4000-8000-0000000c0103 --prompt "继续"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3 timeout=15s
assert windows[0].overlay.rows[?session contains "0c0101"].title == "Calc 重构方案" && windows[0].overlay.rows[?session contains "0c0101"].title_source == "ai"
assert windows[0].overlay.rows[?session contains "0c0102"].title == "我改的标题" && windows[0].overlay.rows[?session contains "0c0102"].title_source == "custom"
assert windows[0].overlay.rows[?session contains "0c0103"].title == "历史会话：再补一段用法" && windows[0].overlay.rows[?session contains "0c0103"].title_source == "prompt"
shot   t1-titles
key    esc
wait   windows[0].overlay == null
```

## judge
- `t1-titles`：三行分别是「Calc 重构方案」「我改的标题」「历史会话：再补一段用法」，没有一行显示「继续 …」；认得出每个会话是干什么的。
