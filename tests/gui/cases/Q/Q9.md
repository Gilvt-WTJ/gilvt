# Q9 terminal tab 的长任务名称保持单行
requires: sandbox
checklist: Q9
scenarios: [long-title]

`long-title` 剧本会生成超过 terminal tab 最大宽度的任务名称。数据层保留完整标题，tab 视觉上只显示一行并在末尾用省略号截断。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "claude @scenario:long-title\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists timeout=15s
assert windows[0].tabs[0].title contains "Add terminal rows to the sidebar"
assert windows[0].tabs[0].rect != null
shot   q9
```

## judge
- `q9`：顶部 terminal tab 的长任务名称只有一行，末尾显示省略号；文字没有在 tab 内换到第二行或被上下裁切；左侧状态点和右侧关闭按钮完整可见。
