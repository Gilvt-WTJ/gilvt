# R11 「其他…」模型试跑失败时配置不变
requires: sandbox
checklist: R11
scenarios: []

切到 Codex：两个模型重置，下拉里出现假 `codex app-server` 分两页返回的模型；测试连接通过；「其他…」填一个不存在的模型（假大脑对 `missing-` 开头的名字按真实 CLI 报错），试跑失败、提示「模型不存在或无权使用」、config.toml 一个字节都没变；换一个存在的名字才写入，并标出「⚠ 不在列表中」。结束时恢复原来的 config.toml。

## steps
```gilvt-steps
sh     'cp ~/.config/gilvt/config.toml ~/r11-orig.toml && rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count'
restart --set 'monitor.enabled=true' --set 'monitor.model="haiku"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert settings !exists
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="monitor"])'
wait   settings.page == "monitor" timeout=5s
assert settings.fields[?id=="model"].value == "haiku"
# 切到 Codex：两个模型重置
click  'rect(settings.fields[?id=="provider"].options[?label=="Codex"])'
wait   settings.fields[?id=="provider"].value == "codex" timeout=3s
assert settings.fields[?id=="model"].label == "CLI 默认"
assert settings.fields[?id=="summary_model"].label == "同对话模型"
sh     'grep -qx "provider = \"codex\"" ~/.config/gilvt/config.toml'
sh     'grep -qx "model = \"\"" ~/.config/gilvt/config.toml'
# 假 app-server 分两页返回的模型都在下拉里
wait   settings.fields[?id=="model"].options[?label=="fake-codex-small"] exists timeout=15s
assert settings.fields[?id=="model"].options[?label=="fake-codex-large"] exists
click  'rect(settings.fields[?id=="test"])'
wait   settings.test.state == "ok" timeout=60s
assert settings.test.text contains "认证正常"
assert settings.test.text contains "对话"
sh     'cp ~/.config/gilvt/config.toml ~/r11-before.toml'
# 其他… 填不存在的模型：试跑失败，配置一个字节都没变
click  'rect(settings.fields[?id=="summary_model"])'
wait   settings.fields[?id=="summary_model"].open == true timeout=3s
click  'rect(settings.fields[?id=="summary_model"].options[?label=="其他…"])'
wait   settings.other.field == "summary_model" timeout=3s
type   --window key "missing-model"
key    enter
wait   settings.notice contains "模型不存在或无权使用" timeout=30s
assert settings.notice_error == true
assert settings.fields[?id=="summary_model"].value == ""
sh     'cmp ~/r11-before.toml ~/.config/gilvt/config.toml'
sh     'grep -q -- "-m missing-model" ~/.gilvt-fake-brain.log'
shot   r11-rejected
key    esc
wait   settings.other == null timeout=3s
# 换一个存在的名字：试跑成功才写入
click  'rect(settings.fields[?id=="summary_model"])'
wait   settings.fields[?id=="summary_model"].open == true timeout=3s
click  'rect(settings.fields[?id=="summary_model"].options[?label=="其他…"])'
wait   settings.other.field == "summary_model" timeout=3s
type   --window key "fake-codex-xl"
key    enter
wait   settings.fields[?id=="summary_model"].value == "fake-codex-xl" timeout=30s
assert settings.fields[?id=="summary_model"].label contains "⚠ 不在列表中"
sh     'grep -qx "summary_model = \"fake-codex-xl\"" ~/.config/gilvt/config.toml'
shot   r11-written
key    cmd+w
wait   settings !exists timeout=5s
# restart 的沙盒检查只看聚焦的 pane：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
sh     'cp ~/r11-orig.toml ~/.config/gilvt/config.toml && rm -f ~/r11-orig.toml ~/r11-before.toml ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count'
restart
```

## judge
- `r11-rejected`：「总结模型」位置是一个输入框，里面是 missing-model；下面一条红色提示「模型不存在或无权使用（…）」；测试连接的绿色行「✓ codex <版本> · 认证正常 · 总结 …s」；「对话模型」旁有「↻ 刷新」。
- `r11-written`：「总结模型」下拉显示「fake-codex-xl ⚠ 不在列表中」，红色提示已消失。
