# W1 编辑器实时预览：Markdown 渲染随输入刷新
requires: sandbox
checklist: W1
scenarios: []

在编辑器里打开一个 `.md`，`⌘⇧V` 在右侧开出预览；输入几个字，预览在约 0.2 秒后重建（`refreshes` 增加），磁盘上的文件不变；再按 `⌘⇧V` 关闭。
沙盒窗口较窄，先 `restart --set font_size=9` 让编辑 pane 与预览都有足够列数，结束时改回 13。
本用例不启动 Agent，用 `gilvt view` 打开 Quick Look 再按 `e` 进入编辑 pane；此时标签里是终端、编辑 pane，开预览后是 3 个 pane。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/w1 && printf '# Title\n\nbody\n' > work/w1/a.md && cp work/w1/a.md work/w1/a.orig"
type   "cd -P ~/work/w1 && clear && gilvt view a.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w1/a.md" timeout=10s
key    e
wait   windows[0].editors[0].path contains "/work/w1/a.md" timeout=5s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
assert windows[0].editors[0].preview == null
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "rendered" && windows[0].editors[0].preview.refreshes == 1 timeout=10s
assert windows[0].tabs[0].panes[*] exists count=3
shot   w1-open
click  'rect(windows[0].editors[0].rect)'
type   "hello "
wait   windows[0].editors[0].dirty == true timeout=5s
wait   windows[0].editors[0].preview.refreshes != 1 timeout=5s
sh     "cmp work/w1/a.orig work/w1/a.md"
key    cmd+shift+v
wait   windows[0].editors[0].preview == null && windows[0].tabs[0].panes[*] exists count=2 timeout=5s
restart --set font_size=13
```

## judge
- `w1-open`：编辑 pane 右边（或旁边）有一个只读预览 pane，渲染出标题 `Title` 和正文 `body`；头部有「预览：渲染」按钮。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
