# L16 Review 位置失效后的两种恢复：从当前开始、Review 全部可见历史
requires: sandbox
checklist: L16
scenarios: [hist-claude]

两个会话 Review 完之后，transcript 都被截断（保存的位置找不到了）。它们以「失败」档重新出现；打开后显示最新的几轮和一条说明，
「已 Review，下一个」不可用，直到选择：`B`「从当前开始」（现有的 turn 都算看过，会话离开队列）或 `A`「Review 全部可见历史」（现有的 turn 全部待 Review）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l16 && cd -P ~/work/l16 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l16"
seed   hist-claude --cwd work/l16 --id c1a0de00-0000-4000-8000-0000000b1601 --prompt "l16 甲"
seed   hist-claude --cwd work/l16 --id c1a0de00-0000-4000-8000-0000000b1602 --prompt "l16 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s

wait   windows[0].overlay.session_review.session_key contains "0b1601" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s

wait   windows[0].overlay.session_review.session_key contains "0b1602" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s

key    esc

sh     'for F in $(find "$HOME/.claude/projects" -name "*0b160[12].jsonl"); do python3 -c "import os,sys; n=os.path.getsize(sys.argv[1]); os.truncate(sys.argv[1], n*3//4)" "$F" || exit 1; done'
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
assert windows[0].overlay.rows[0].priority == "failed" && windows[0].overlay.rows[1].priority == "failed"

wait   windows[0].overlay == null
```
