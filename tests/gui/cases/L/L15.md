# L15 鼠标：左栏入口与 Review 的按钮
requires: sandbox
checklist: L15
scenarios: [hist-claude]

用鼠标走一遍：点左栏标题下的「待 Review N」打开 Session Center 的「待 Review」；打开一个会话的 Review 后依次点 跳过、置顶、稍后提醒 → 1 小时后、已 Review，下一个。
点击会把 gilvt 带到前台，只在得到用户同意后运行（`run.sh --foreground`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l15 && cd -P ~/work/l15 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l15"
seed   hist-claude --cwd work/l15 --id c1a0de00-0000-4000-8000-0000000b1501 --prompt "l15 甲"
seed   hist-claude --cwd work/l15 --id c1a0de00-0000-4000-8000-0000000b1502 --prompt "l15 乙"
seed   hist-claude --cwd work/l15 --id c1a0de00-0000-4000-8000-0000000b1503 --prompt "l15 丙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    esc
wait   windows[0].overlay == null
wait   windows[0].sidebar.visible == true && windows[0].sidebar.review_entry.count == 3 timeout=10s
click  'rect(windows[0].sidebar.review_entry)'
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[2] exists && windows[0].overlay.rows[3] !exists timeout=10s
click  'rect(windows[0].overlay.rows[0])'
key    space
wait   windows[0].overlay.session_review.session_key contains "0b1501" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
click  'rect(windows[0].overlay.session_review.actions.skip)'
wait   windows[0].overlay.session_review.session_key contains "0b1502" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
click  'rect(windows[0].overlay.session_review.actions.pin)'
wait   windows[0].overlay.session_review.pinned == true && windows[0].overlay.rows[0].session_key contains "0b1502" timeout=10s
click  'rect(windows[0].overlay.session_review.actions.snooze)'
wait   windows[0].overlay.session_review.snooze_menu == true
click  'rect(windows[0].overlay.session_review.actions.snooze_hour)'
wait   windows[0].overlay.rows[?session_key contains "0b1502"] !exists && windows[0].overlay.tabs[?name=="review"].count == 2 timeout=10s
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
shot   l15-buttons
click  'rect(windows[0].overlay.session_review.actions.review_next)'
wait   windows[0].overlay.tabs[?name=="review"].count == 1 timeout=10s
assert windows[0].overlay.store_last_error == null
key    esc
key    esc
wait   windows[0].overlay == null
wait   windows[0].sidebar.review_entry.count == 1 timeout=10s
```

## judge
- `l15-buttons`：Review 底部有 跳过 S / 稍后提醒 Z / 置顶 P / 已 Review，下一个 ⌘↩，按钮文字清晰、悬停有反馈。
- 左栏「待 Review」的数字随队列变化（3 → 1）。
