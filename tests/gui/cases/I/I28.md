# I28 `⌘E` 归档：离开默认列表，运行中的会话不能归档
requires: sandbox
checklist: I28
scenarios: [hist-claude, default]

会话浮层里 `⌘E` 归档光标所在的会话：它离开默认列表（「已归档」筛选里才看得到，见 I30），文件不动；归档写进 `reviews.json`
的 `archived_at` 与 `archived_turns`（归档时的轮数，之后轮数变多就自动取消归档，见 I29）。运行中的会话 `⌘E` 只出横幅
「运行中的会话不能归档」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i28 --age 2d --id c1a0de00-0000-4000-8000-000000002801 --prompt "i28 要归档的会话"
seed   hist-claude --cwd work/i28 --age 3d --id c1a0de00-0000-4000-8000-000000002802 --prompt "i28 留着的会话"
type   "mkdir -p ~/work/i28 && cd -P ~/work/i28 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i28"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
# 较新的在上面，光标在第一行
assert windows[0].overlay.rows[0].title contains "i28 要归档" && windows[0].overlay.rows[0].selected == true
key    cmd+e
wait   windows[0].overlay.banner == "已归档 1 个会话" && windows[0].overlay.items == 1 timeout=3s
assert windows[0].overlay.rows[?title contains "i28 要归档"] !exists && windows[0].overlay.rows[0].title contains "i28 留着"
assert windows[0].overlay.filter.archived == false && windows[0].overlay.chips[?label=="已归档"].active == false
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i28-archived
# 文件不动；归档状态（时间 + 当时的轮数）在 reviews.json 里
sh     "find .claude -name 'c1a0de00-0000-4000-8000-000000002801.jsonl' | grep -q ."
sh     'python3 -c "import json,sys; s=json.load(open(sys.argv[1]))[\"sessions\"][\"claude:c1a0de00-0000-4000-8000-000000002801\"]; sys.exit(0 if s[\"archived_turns\"] == 2 and s[\"archived_at\"][\"secs_since_epoch\"] > 0 else 1)" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
# 关掉再打开，仍然不在默认列表里；搜索也不命中
key    esc
wait   windows[0].overlay == null
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
type   "i28 要归档"
sleep  500ms
assert windows[0].overlay.rows[?title contains "i28 要归档"] !exists
key    esc
wait   windows[0].overlay == null
# 运行中的会话：⌘E 只出横幅
type   "claude @scenario:default i28 运行中\n"
wait   windows[0].sidebar.rows[?name=="i28 运行中"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.rows[?live==true] exists timeout=15s
assert windows[0].overlay.rows[0].live == true && windows[0].overlay.rows[0].selected == true
key    cmd+e
wait   windows[0].overlay.banner == "运行中的会话不能归档" timeout=3s
assert windows[0].overlay.rows[?live==true] exists && windows[0].overlay.items == 2
sleep  1s
shot   i28-running
key    esc
wait   windows[0].overlay == null
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
```

## judge
- `i28-archived`：顶部横幅「已归档 1 个会话」，列表只剩「i28 留着的会话」；筛选条最后一项是「已归档」（未选中）。
- `i28-running`：横幅「运行中的会话不能归档」，运行中的会话仍在列表最上面（「● 运行中 · 标签 1」）。
