# I31 直接删除归档的会话，附属数据一起移到废纸篓
requires: sandbox
checklist: I31
scenarios: [hist-claude]

归档不影响直接删除：「已归档」筛选下 `⌘⌫` 照常出确认条，并且分开写出附属数据的大小（「1 个会话 · X MB + 附属 Y MB 将移到废纸篓」）。
确认（`↩`）后会话记录和按会话 id 存的附属数据（`~/.claude/file-history/<id>/`、`~/.claude/tasks/<id>/`，由 `seed --session-data` 写下）
都离开原处，**另一个会话**的附属数据不动。测试会话由 `seed` 生成，只在沙盒里；文件进了真实用户的废纸篓。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i31 --age 2d --id c1a0de00-0000-4000-8000-000000003101 --prompt "i31 归档后删除" --session-data
seed   hist-claude --cwd work/i31 --age 3d --id c1a0de00-0000-4000-8000-000000003102 --prompt "i31 留着" --session-data
type   "mkdir -p ~/work/i31 && cd -P ~/work/i31 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i31"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
assert windows[0].overlay.rows[0].title contains "i31 归档后删除"
key    cmd+e
wait   windows[0].overlay.banner == "已归档 1 个会话" && windows[0].overlay.items == 1 timeout=3s
click  'rect(windows[0].overlay.chips[?label=="已归档"])'
wait   windows[0].overlay.filter.archived == true && windows[0].overlay.items == 1 timeout=3s
key    cmd+backspace
# 确认条先写「+ 附属 计算中…」（附属大小在后台算），算完换成「+ 附属 Y MB」：等到 「B 将移到废纸篓」 才是最终文案
wait   windows[0].overlay.confirm.text contains "1 个会话 · " && windows[0].overlay.confirm.text contains " + 附属 " && windows[0].overlay.confirm.text contains "B 将移到废纸篓" timeout=5s
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i31-confirm
key    enter
wait   windows[0].overlay.confirm == null && windows[0].overlay.items == 0 timeout=10s
note-trashed c1a0de00-0000-4000-8000-000000003101
sh     "! find .claude -name 'c1a0de00-0000-4000-8000-000000003101*' | grep -q ."
sh     '! test -e .claude/file-history/c1a0de00-0000-4000-8000-000000003101 && ! test -e .claude/tasks/c1a0de00-0000-4000-8000-000000003101'
sh     'test -f .claude/file-history/c1a0de00-0000-4000-8000-000000003102/x && test -f .claude/tasks/c1a0de00-0000-4000-8000-000000003102/1.json'
sh     "find .claude -name 'c1a0de00-0000-4000-8000-000000003102.jsonl' | grep -q ."
click  'rect(windows[0].overlay.chips[?label=="已归档"])'
wait   windows[0].overlay.filter.archived == false && windows[0].overlay.items == 1 && windows[0].overlay.rows[0].title contains "i31 留着" timeout=3s
key    esc
wait   windows[0].overlay == null
```

## judge
- `i31-confirm`：确认条「1 个会话 · X MB + 附属 Y MB 将移到废纸篓（可从废纸篓还原）」（断言），附属约 0.03 MB（`--session-data` 写了 32 KB）。
- 确认后：`note-trashed` 核对真实 `~/.Trash` 里有名字含 `c1a0de00-…3101` 的条目（transcript 与两个附属目录，访达给同名目录加后缀）；
  `sh` 确认沙盒里它的 transcript、`file-history/<id>`、`tasks/<id>` 都不在了，另一个会话的都还在。条目记进 `trashed.txt`，由
  `sandbox.sh down` 列给用户处理——**不要清空废纸篓**。`note-trashed` 退出 5（这个终端读不了 `~/.Trash`）时在访达里只读核对，记 ⚠️。
