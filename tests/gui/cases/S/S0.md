# S0 沙盒自检
requires: sandbox                 # sandbox | real-claude | real-codex | manual
checklist: —
scenarios: [ask-question]

沙盒本身的冒烟测试（spec §10）：启动、state 可读、fake agent 被识别为 claude、`down` 清理干净。
每次验收的第一个用例；它失败时不要继续执行其他用例。

## setup
```sh
tests/gui/sandbox.sh up --label s0
```
`up` 自己已经做了安全检查：在 pane 里执行 `type -P claude` / `type -P codex` / `$HOME`，三者都必须指向
沙盒（`<sandbox>/bin`、`<sandbox>/home`），否则 `up` 会立即 `down` 并以退出码 2 结束。

## steps
```gilvt-steps
assert version == 1
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "claude @scenario:ask-question\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" && windows[0].sidebar.rows[?status=="awaiting_answer"] exists timeout=15s
assert windows[0].sidebar.rows[?status=="awaiting_answer"].detail == "Cats or dogs?"
assert windows[0].tabs[0].panes[0].screen_tail[*] contains "❯ 1. Cats"
key    enter
wait   windows[0].sidebar.rows[?kind=="agent"].status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "You picked Cats." timeout=10s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
shot   s0
```

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/S0
# 检查没有残留：
ls -d "$TMPDIR"/gilvt-gui-2* 2>/dev/null          # 应为空（或只剩其他仍在运行的沙盒）
pgrep -x gilvt-app                                 # 不应有 up 记录的那个 pid
```
在 `down` 之前记下 `session.env` 里的 `PID` 和 `SANDBOX_DIR`，`down` 之后确认：
- `kill -0 <PID>` 失败（进程已结束）；
- `<SANDBOX_DIR>` 与 `$TMPDIR/gilvt-gui-current` 都不存在；
- 用户自己的 gilvt（如果开着）仍在运行。

## judge
看 `shots/s0.png`：
- 能看到沙盒提示符 `sandbox$`，以及 fake agent 留下的界面：欢迎行 `✻ Welcome to Claude Code v… (gilvt-fake-agent)`、
  问题 `Cats or dogs?` 与选项、回复 `⏺ You picked Cats.`；
- 本用例不涉及中文输入，不检查中文；
- 左栏里应有这个会话的一行（空闲或已结束），pane 边框没有状态色。

注意：
- `shot s0` 退出 5（`SCREEN LOCKED`）表示屏幕锁定、截图被跳过：视觉检查记为「跳过（锁屏）」，不算失败；
  其余状态断言照常判定；
- 只截 gilvt 自己的窗口（`shot` 会先查询一次 state，让被遮挡的窗口也画出最新的一帧）；
- `type` / `key` 是后台输入，gilvt 不会被带到前台；这个用例没有前台动作。
