# I35 全局 hook 安装可逆且保留用户配置
requires: manual
checklist: I35
scenarios: []

## steps
```gilvt-steps
# 手动：在隔离 HOME 中准备带自定义 hooks、普通配置和注释的 ~/.claude/settings.json 与 ~/.codex/config.toml
# 手动：依次运行 gilvt integrate install、status、再次 install 和 uninstall，并检查每一步的文件内容与备份
# 手动：分别准备无效 JSON/TOML，确认 install 拒绝覆盖且原字节不变
```

## judge
- status 对 Claude/Codex 都报告完整安装，重复安装后 gilvt hook 数量不变。
- 用户 hooks、Codex 普通配置及注释保留，改写前生成备份。
- uninstall 只删除 gilvt 管理的条目。
- 文件为无效 JSON/TOML 时命令失败且原字节不变。
