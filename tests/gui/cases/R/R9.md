# R9 终端标签里 ⌘⇧M 呼出命令条：对话与监控官标签一致，Esc 收起后焦点回到终端
requires: sandbox
checklist: R9
scenarios: []

没有 Agent 会话，只有一个 zsh（它自己就是 `@` 候选里的终端卡片）。`chat-slow` 让假大脑的两半回答之间停 1.5 秒，好看到收起时的「回答中…」。聊天文字只打 ASCII（输入法会改写中文）。

沙盒窗口默认较窄，监控官标签约 720px（< 760px）：本用例不收起检查器，正是要验证「在监控官中查看 ↗」新建的标签里对话面板以浮层打开（`monitor.chat.open == true`，右边缘是 26px 竖条），键盘在面板输入框里。

## steps

sh     "rm -f ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-chat.log && printf 'chat-slow\n' > ~/.gilvt-fake-brain"

## judge
- `r9-line`：窗口底部、左栏与检查器之间一条约 20px 的细线，左边「◎ 监控官」，右边灰色「⌘⇧M 提问」；终端在它上方。
- `r9-answering`：细线显示「◎ 监控官 · 回答中…」；没有浮层。
- `r9-popup`：pane 区域底部叠着一块浮层（紫色上边框）：灰色小字「你：which sessions need me」、灰色「✓ 已列出 N 个会话」、回答「现在有 N 个会话（完）」、按钮「在监控官中查看 ↗」，下面是紫色边框的输入框（占位「问监控官…（@ 选会话 · ⏎ 发送 · Esc 收起）」）；细线右边是「Esc 收起」。浮层上方能看到的终端文字与 `r9-answering` 里同一行的位置相同（展开不改变终端大小）。
- `r9-monitor`：最左边新出现「◎ 监控官」标签并处于激活，右边缘是 26px 竖条，对话面板以浮层盖在卡片墙上（不是只剩竖条），里面是同一轮问答，输入框里是「r9」；底部细线照常在（收起状态）。
- 手动补充（输入法，不能自动化：驱动的 `type` 绕过输入法）：系统切到拼音输入法，在 zsh 里按 `⌘⇧M`，输入 `nihao` 让候选窗出现，再按 `⌘⇧M`：命令条收起、候选窗消失，终端里没有落下任何字符；再按 `⌘⇧M` 输入框里没有残留的拼音。
