# I1 ⌘⇧R 会话浮层的默认视图
requires: sandbox
checklist: I1
scenarios: [hist-claude, hist-codex]

`seed` 在当前项目 `~/work/i1` 里放一个 Claude、一个 Codex 的两轮历史会话，另在 `~/work/i1-old` 放一个 8 天前的旧会话。
默认只列当前项目，最近的在最上面。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i1 --age 2h --id c1a0de00-0000-4000-8000-000000000101 --prompt "i1 两小时前的 Claude 会话"
seed   hist-codex --cwd work/i1 --age 1h --id 01990000-0000-7000-8000-000000000101 --prompt "i1 一小时前的 Codex 会话"
seed   hist-claude --cwd work/i1-old --age 8d --id c1a0de00-0000-4000-8000-000000000102 --prompt "i1 八天前的旧会话"
type   "cd -P ~/work/i1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i1"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.filter.scope == "current" && windows[0].overlay.filter.stale == false timeout=5s
shot   i1-opening
wait   windows[0].overlay.items == 2 && windows[0].overlay.selected == 0 && windows[0].overlay.query == "" timeout=15s
shot   i1
key    esc
wait   windows[0].overlay == null
```

## judge
- `i1`：筛选条默认选中「i1」（当前项目），分组标题「i1 · 当前项目」；两行依次是
  「X i1 一小时前的 Codex 会话 · 2 轮 · 1 小时前」「C i1 两小时前的 Claude 会话 · 2 轮 · 2 小时前」（图标、名称、轮数、
  最后活动时间）；八天前的旧会话不在当前项目里，不列出。
- `i1-opening`：刚打开时可能显示「正在读取会话…」（本次运行第一次打开）或已有结果；扫描期间标「刷新中…」——拍到哪种都行，
  但界面不能是空白或卡住。
- 光标在第一行。
