# T4 ⌘R：改名压过 Agent 的标题；清空回到 Agent 的标题；原样 ⏎ 不冻结成改名
requires: sandbox
checklist: T4
scenarios: [hist-claude]

改名框预填的是当前显示的标题（Agent 的标题）。在它后面改成手动名 → `title_source` 变 `saved`；清空保存 → 回到 Agent 的标题；
改名框里什么都不改直接 `⏎`，不会把 Agent 的标题冻结成手动名（`title_source` 仍然是 `ai`）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions" "$HOME/.codex/session_index.jsonl"'
type   "mkdir -p ~/work/t4 && cd -P ~/work/t4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/t4"
seed   hist-claude --cwd work/t4 --id c1a0de00-0000-4000-8000-0000000c0401 --prompt "继续 t4" --ai-title "Calc 重构方案"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 && windows[0].overlay.rows[0].title == "Calc 重构方案" timeout=15s
# 什么都不改，⏎：仍然是 Agent 的标题
key    cmd+r
key    enter
sleep  500ms
assert windows[0].overlay.rows[0].title == "Calc 重构方案" && windows[0].overlay.rows[0].title_source == "ai"
# 预填的是「Calc 重构方案」（9 个字符），全部删掉后输入手动名
key    cmd+r
key    backspace backspace backspace backspace backspace backspace backspace backspace backspace
type   "手动名\n"
wait   windows[0].overlay.rows[0].title == "手动名" && windows[0].overlay.rows[0].title_source == "saved" timeout=5s
shot   t4-renamed
# 清空保存：回到 Agent 的标题
key    cmd+r
key    backspace backspace backspace
key    enter
wait   windows[0].overlay.rows[0].title == "Calc 重构方案" && windows[0].overlay.rows[0].title_source == "ai" timeout=5s
key    esc
wait   windows[0].overlay == null
```

## judge
- `t4-renamed`：这一行显示「手动名」。
