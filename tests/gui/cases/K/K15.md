# K15 无改动的任务折叠成一行，点开逐条查看
requires: sandbox
checklist: K15
scenarios: [artifacts-turns]

三轮里第 2 轮只解释：它折成「▸ 1 轮无文件改动 · …」，点开后才画出那张卡片。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k15 && cd work/k15 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k15 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k15"
type   "claude @scenario:artifacts-turns\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.quiet_groups[*] exists count=1 && windows[0].inspector.artifacts.cards[0].state == "done" timeout=40s
assert windows[0].inspector.artifacts.quiet_groups[0].open == false
click  'rect(windows[0].inspector.artifacts.quiet_groups[0].rect)'
wait   windows[0].inspector.artifacts.quiet_groups[0].open == true timeout=5s
assert windows[0].inspector.artifacts.cards[1].rect != null
shot   k15-quiet-open
```

## judge
- `k15-quiet-open`：折叠行已展开，中间多出一张卡片，标题 `explain what you did`，右侧「无文件改动 · 耗时」。
