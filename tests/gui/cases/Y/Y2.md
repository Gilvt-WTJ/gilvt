# Y2 三种状态的会话分进各自分组
requires: sandbox
checklist: Y2
scenarios: [approve-bash, long-tool, three-turns]

三个标签分别跑 `approve-bash`（停在审批）、`long-tool`（执行中）、`three-turns`（跑完），监控官里各占一组，标签标题带「· 1 需要你」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/y2 && cd -P ~/work/y2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/y2"
type   "claude @scenario:approve-bash\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 timeout=15s
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/y2 && claude @scenario:long-tool\n"
wait   windows[0].sidebar.rows[?status=="running_tool"] exists count=1 timeout=15s
key    cmd+t
wait   windows[0].tabs[*] exists count=3 && windows[0].tabs[2].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/y2 && claude @scenario:three-turns\n"
key    cmd+shift+o
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=20s
assert windows[0].monitor.cards[?group=="needs_you"] exists count=1
assert windows[0].monitor.cards[?group=="running"] exists count=1
assert windows[0].monitor.cards[?group=="needs_you"].status_line contains "等待审批"
assert windows[0].monitor.groups[?name=="needs_you"].count == 1
assert windows[0].monitor.groups[?name=="running"].count == 1
assert windows[0].monitor.groups[?name=="done"].count == 1
assert windows[0].monitor.needs_you == 1
assert windows[0].tabs[0].title contains "1 需要你"
shot   y2
```

## judge
- `y2`：三组从上到下「需要你 · 1」「运行中 · 1」「完成未看 · 1」；运行中卡片显示执行中的 Bash；完成未看卡片有「测试通过。」引语；标签标题「◎ 监控官 · 1 需要你」。
