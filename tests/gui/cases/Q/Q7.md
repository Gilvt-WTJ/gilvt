# Q7 悬停终端行的提示：名字、位置、目录，没有状态行
requires: sandbox
checklist: Q7
scenarios: []

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/q7 && cd -P ~/work/q7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/q7"
# 分屏后第一个终端行是左 pane：位置词确定为「左」（单个 pane 时位置词为空）
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
wait   windows[0].sidebar.rows[?kind=="terminal"] exists count=2 timeout=10s
hover  'rect(windows[0].sidebar.rows[?kind=="terminal"])'
wait   windows[0].sidebar.tooltip.text contains "/work/q7" timeout=5s
assert windows[0].sidebar.tooltip.text contains " · 左"
shot   q7
hover  'pane(focused)'
wait   windows[0].sidebar.tooltip == null timeout=5s
```

## judge
- `q7`：提示里有终端的名字、位置行（标签标题 · 左）和目录 `…/work/q7`；没有状态行（没有「● …」「✓ …」之类的一行）。
