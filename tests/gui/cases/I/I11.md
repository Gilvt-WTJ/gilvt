# I11 从废纸篓放回后重新出现
requires: manual
checklist: I11
scenarios: [hist-claude]

「放回原处」只能在访达里由用户本人操作（测试不操作系统界面）。本用例自己准备并移走一个会话，然后请用户放回，再核对。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i11 --age 8d --id c1a0de00-0000-4000-8000-000000001101 --prompt "i11 放回之后还在"
type   "cd -P ~/work/i11 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i11"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    cmd+r
key    backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace backspace
type   "i11 改过的名字\n"
key    cmd+backspace
shot   i11-confirm
wait   windows[0].overlay.confirm.text contains "1 个会话" timeout=3s
click  'rect(windows[0].overlay.confirm.buttons[?label=="移到废纸篓"])'
wait   windows[0].overlay.items == 0 timeout=10s
note-trashed c1a0de00-0000-4000-8000-000000001101
key    esc
wait   windows[0].overlay == null
# 手动：请用户在访达里打开废纸篓，选中 c1a0de00-0000-4000-8000-000000001101.jsonl，右键「放回原处」；完成后继续
sh     "find .claude -name 'c1a0de00-0000-4000-8000-000000001101.jsonl' | grep -q ."
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
shot   i11-back
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].screen_tail[*] contains "claude --resume c1a0de00-0000-4000-8000-000000001101" timeout=5s
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=10s
type   "放回之后继续\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: 放回之后继续" timeout=10s
```

## judge
- 「需要你」清单：在访达里对 `c1a0de00-…1101.jsonl` 执行「放回原处」（报告里写明文件名与原位置
  `<沙盒>/home/.claude/projects/…-work-i11/`）。放回之前沙盒已经 `down` 的话，放回会失败——这一步必须在本用例运行期间做。
- `i11-back`：会话重新出现在列表里，名字仍是「i11 改过的名字」。
- `↩` 之后可以再次恢复并接着对话（断言）。
