# T2 搜索：能按标题找到，也能按当初的原话找到
requires: sandbox
checklist: T2
scenarios: [hist-claude]

会话的标题和它第一条提示词里的词是两套词。「全部会话」和 Session Center 的待 Review 都同时匹配两者（以及 Agent 的 custom 标题）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions" "$HOME/.codex/session_index.jsonl"'
type   "mkdir -p ~/work/t2 && cd -P ~/work/t2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/t2"
seed   hist-claude --cwd work/t2 --id c1a0de00-0000-4000-8000-0000000c0201 --prompt "继续 原话关键字alpha" --ai-title "Calc 重构方案"
seed   hist-claude --cwd work/t2 --id c1a0de00-0000-4000-8000-0000000c0202 --prompt "另一个会话 beta" --ai-title "无关的标题" --custom-title "我的专属名"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
# 全部会话：标题里的词
type   "重构"
wait   windows[0].overlay.items == 1 && windows[0].overlay.rows[0].session contains "0c0201" timeout=5s
key    backspace backspace
# 原话里的词
type   "alpha"
wait   windows[0].overlay.items == 1 && windows[0].overlay.rows[0].session contains "0c0201" timeout=5s
key    backspace backspace backspace backspace backspace
# Agent 的 custom 标题
type   "专属"
wait   windows[0].overlay.items == 1 && windows[0].overlay.rows[0].session contains "0c0202" timeout=5s
key    backspace backspace
wait   windows[0].overlay.items == 2 timeout=5s
# 待 Review：同样的搜索
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
type   "重构"
wait   windows[0].overlay.rows[0].session_key contains "0c0201" && windows[0].overlay.rows[1] !exists timeout=5s
key    backspace backspace
type   "alpha"
wait   windows[0].overlay.rows[0].session_key contains "0c0201" && windows[0].overlay.rows[1] !exists timeout=5s
shot   t2-search
key    esc
key    esc
wait   windows[0].overlay == null
```

## judge
- `t2-search`：搜索框里是「alpha」，列表只有一行；这一行显示的名字是「Calc 重构方案」（不是「继续 原话关键字alpha」）。
