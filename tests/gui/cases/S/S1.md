# S1 英文界面与热重载
requires: sandbox
checklist: S1
scenarios: []

## steps
```gilvt-steps
restart --set 'language="en"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
raise
key    cmd+,
wait   settings.key == true && settings.language == "en" timeout=5s
assert settings.pages[?id=="appearance"].label == "◐ Appearance"
assert settings.pages[?id=="language"].label == "文A Language"
assert settings.pages[?id=="monitor"].label == "◎ Monitor"
assert settings.languages[?id=="en"].selected == true
shot   --window key s1-english
key    cmd+w
restart --set 'language="zh-CN"'
```

## judge
- `s1-english`：设置窗口导航为 Appearance / Language / Monitor；外观页的搜索、筛选、模式和状态示例均为英文。
- 工作区的会话侧栏与检查器标签使用英文；终端里的 `sandbox$` 等程序输出保持原样。
