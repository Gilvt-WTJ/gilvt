# R7 站会简报以 B 版式出现，会话链接能跳过去
requires: sandbox
checklist: R7
scenarios: [approve-bash]

一个会话停在审批上。点「✦ 生成站会简报」：对话进程这时才启动，假大脑通过真实的 `gilvt mcp` 调用 `list_sessions`，按 B 版式回答；点「要你处理」里的链接，回到那个会话所在的标签。

环境风险（与 Y8 / Q1 相同）：沙盒看得到本机真实的 claude 进程。`needs_you` 恰好为 1、链接落在 `tabs[1]`（沙盒里只有一个 claude 标签）都假定本机没有别的 claude 在等审批；有时先停掉它们再跑。

## steps
```gilvt-steps
sh     rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-chat.log
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=false'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r7 && cd -P ~/work/r7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r7"
type   "claude @scenario:approve-bash\n"
key    cmd+shift+o
# 沙盒里监控官标签约 720px（< 760px 会收成竖条）：收起检查器让面板完整出现
key    cmd+i
wait   windows[0].inspector.visible == false && windows[0].monitor.chat.collapsed == false timeout=5s
wait   windows[0].monitor.cards[?group=="needs_you"] exists count=1 timeout=20s
assert windows[0].monitor.needs_you == 1
assert windows[0].monitor.chat.status == "idle"
assert chat_process.running == false && chat_process.starts == 0
shot   r7-before
click  'rect(windows[0].monitor.chat.quick[?label=="✦ 生成站会简报"])'
wait   windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="list_sessions"].done == true timeout=30s
wait   windows[0].monitor.chat.status == "idle" timeout=30s
assert windows[0].monitor.chat.messages[?role=="user"].text == "生成站会简报"
assert windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="list_sessions"].label contains "✓ 已列出"
assert windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="list_sessions"].ok == true
assert windows[0].monitor.chat.messages[?role=="assistant"].text contains "### 要你处理"
assert windows[0].monitor.chat.messages[?role=="assistant"].text contains "### 整体"
assert windows[0].monitor.chat.messages[?role=="assistant"].links[*].key contains "agent:claude:"
assert windows[0].monitor.chat.messages[?role=="assistant"].links[0].rect != null
assert chat_process.running == true && chat_process.provider == "claude" && chat_process.starts == 1 && chat_process.turns == 1
sh     "grep -q 'user: 生成站会简报' ~/.gilvt-fake-brain-chat.log"
sh     "grep -q 'tool list_sessions: {' ~/.gilvt-fake-brain-chat.log"
shot   r7-briefing
click  'rect(windows[0].monitor.chat.messages[?role=="assistant"].links[0])'
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].focused == true timeout=5s
# restart 的沙盒检查只看聚焦的 pane：聚焦的是 claude（审批中），先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
# 把检查器放回来（ui.json 里的 inspector_hidden 不留给后面的用例）
key    cmd+i
wait   windows[0].inspector.visible == true timeout=5s
sleep  2s
restart --set 'monitor.enabled=false'
```

## judge
- `r7-before`：卡片墙右侧是 360px 宽的「◎ 监控官」面板：头部「◎ 监控官」「Claude · CLI 默认 ▾」「新对话」「⇥」，底部三个快捷问题和输入框（占位「继续问…（@ 选会话 · ⏎ 发送 · ⇧⏎ 换行）」）；审批中的卡片按钮行有「◎ 问它」。
- `r7-briefing`：右对齐的用户气泡「生成站会简报」；回答上方一行灰色小字「✓ 已列出 N 个会话」；正文先是粗体小标题「要你处理」和一行带紫色下划线链接的会话，然后「整体」和一段话（与 `s2-briefing-options.html` 的 B 版式一致）；答案按正文宽度折行成段落（不是一行一截的代码样式），链接文字完整落在气泡内。
- 手动补充（DebugState 看不到）：鼠标悬停在链接上时光标变成手形。
