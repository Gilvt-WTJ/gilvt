集成

Agent 保留自己的原生 TUI

gilvt 通过 Claude Code 与 Codex 支持的本机信号观察它们，再在周围增加状态、导航、review 和会话管理。

自动本地识别

在 pane 里启动 Agent，gilvt 会把进程、hooks 和持久 session 记录关联起来。

没有私有聊天层

prompt、审批和问题仍留在 Claude Code 或 Codex 中，gilvt 从不替你回答。

安全降级

某个信号不可用或格式变化时，pane 仍是可用终端，集成能力只会降低。
