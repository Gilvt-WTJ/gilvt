# K7 没有快照的历史轮
requires: sandbox
checklist: K7
scenarios: [hist-claude]

恢复一个 gilvt 没记录过的旧会话（`seed` 出来的两轮）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/k7 --age 2d --id c1a0de00-0000-4000-8000-000000004007 --prompt "k7 旧会话"
type   "cd -P ~/work/k7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k7"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[*] exists count=2 timeout=15s
assert windows[0].inspector.artifacts.cards[0].state == "degraded" && windows[0].inspector.artifacts.cards[0].notices[0] contains "无快照"
assert windows[0].inspector.artifacts.cards[1].notices[0] contains "无快照"
shot   k7-no-snapshot
```

## judge
- `k7-no-snapshot`：两张卡片都写「无快照：这一轮发生时 gilvt 没在记录」。
