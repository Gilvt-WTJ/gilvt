# K2 测试失败显示 ✗ 和退出码
requires: sandbox
checklist: K2
scenarios: [artifacts-turns]

fake agent 启动后自己把剧本里的三轮连着演完；第 1 轮（最下面一张卡片）的 `cargo test` 以退出码 101 失败。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k2 && cd work/k2 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k2"
type   "claude @scenario:artifacts-turns\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[*] exists count=3 && windows[0].inspector.artifacts.cards[0].state == "done" timeout=40s
assert windows[0].inspector.artifacts.cards[2].test.ok == false && windows[0].inspector.artifacts.cards[2].test.exit == 101
assert windows[0].inspector.artifacts.cards[2].title contains "change a.txt"
shot   k2-failed-test
```

## judge
- `k2-failed-test` 里第 1 轮卡片有红色的 `✗ cargo test 失败（退出码 101）`。
