# J6 渲染后的代码块选区保留换行
requires: sandbox
checklist: J6
scenarios: []

在渲染视图里从代码块第一行拖到第二行，选区文字保留行间换行，`⌘C` 复制。会覆盖用户的剪贴板。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j6 && cd work/j6 && git init -q && printf '# Title here\n\nFirst paragraph of text.\n\nSecond paragraph of text.\n\n- item one\n- item two\n\n~~~\ncode line 1\ncode line 2\n~~~\n' > note.md"
type   "cd -P ~/work/j6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j6"
type   "gilvt view note.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.mode == "rendered" && windows[0].overlay.code exists timeout=10s
# rect(…) 是矩形的中心，偏移加在中心上。文档区 (265,107,670,524)，中心 (600,369)；标题在 y≈151，段落 y≈186 / 216，列表项 y≈247 / 271，代码块两行 y≈315 / 335；正文从 x≈305 开始
drag   'rect(windows[0].overlay.code)+(-285,-54)' 'rect(windows[0].overlay.code)+(-40,-34)'
wait   windows[0].overlay.selection == "code line 1\ncode line 2" timeout=5s
shot   j6-selected
key    cmd+c
clipboard contains "code line 1"
clipboard contains "code line 2"
```

## judge
- `j6-selected`：代码块的两行文字有选区高亮，段落和列表没有。
- 会覆盖用户的剪贴板（报告里注明）。
