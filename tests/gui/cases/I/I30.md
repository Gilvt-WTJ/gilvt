# I30 「已归档」筛选：查看、取消归档
requires: sandbox
checklist: I30
scenarios: [hist-claude]

筛选条最后一项「已归档」只列归档了的会话（行上标「已归档」）；在这里 `⌘E` 是取消归档，会话回到默认列表。
筛选只能点击（前台动作）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i30 --age 2d --id c1a0de00-0000-4000-8000-000000003001 --prompt "i30 归档又取消"
seed   hist-claude --cwd work/i30 --age 3d --id c1a0de00-0000-4000-8000-000000003002 --prompt "i30 一直没归档"
type   "mkdir -p ~/work/i30 && cd -P ~/work/i30 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i30"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 2 timeout=15s
assert windows[0].overlay.rows[0].title contains "i30 归档又取消"
key    cmd+e
wait   windows[0].overlay.banner == "已归档 1 个会话" && windows[0].overlay.items == 1 timeout=3s
click  'rect(windows[0].overlay.chips[?label=="已归档"])'
wait   windows[0].overlay.filter.archived == true && windows[0].overlay.chips[?label=="已归档"].active == true && windows[0].overlay.items == 1 timeout=3s
assert windows[0].overlay.rows[0].title contains "i30 归档又取消" && windows[0].overlay.rows[0].dir == "~/work/i30"
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i30-archived-filter
# 右键菜单里这一项是「取消归档」
rclick 'rect(windows[0].overlay.rows[0])'
wait   windows[0].context_menu.items[?label=="取消归档"] exists timeout=3s
key    esc
wait   windows[0].context_menu == null
key    cmd+e
wait   windows[0].overlay.banner == "已取消归档 1 个会话" && windows[0].overlay.items == 0 timeout=3s
click  'rect(windows[0].overlay.chips[?label=="已归档"])'
wait   windows[0].overlay.filter.archived == false && windows[0].overlay.items == 2 timeout=3s
assert windows[0].overlay.rows[?title contains "i30 归档又取消"] exists
sh     'python3 -c "import json,sys; s=json.load(open(sys.argv[1]))[\"sessions\"][\"claude:c1a0de00-0000-4000-8000-000000003001\"]; sys.exit(0 if \"archived_at\" not in s else 1)" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
sleep  1s
shot   i30-unarchived
key    esc
wait   windows[0].overlay == null
```

## judge
- `i30-archived-filter`：「已归档」高亮，列表只有「i30 归档又取消」，行上有灰色「已归档」标记。
- `i30-unarchived`：回到默认筛选，两个会话都在，没有「已归档」标记。
