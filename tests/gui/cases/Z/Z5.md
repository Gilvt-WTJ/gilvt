# Z5 ⌘⇧T 把分屏里的终端 pane 移到新标签
requires: sandbox
checklist: Z5
scenarios: []

终端 pane 没有标题栏可拖，用 `⌘⇧T` 移。移的是同一个 pane：屏幕内容还在，shell 还是原来那个，新标签成为当前标签、焦点在它上面；原标签只剩左边的终端。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" && windows[0].tabs[0].panes[1].screen_tail[*] contains "sandbox$" timeout=10s
type   "clear && echo Z5-MARK\n"
wait   windows[0].tabs[0].panes[1].screen_tail[*] contains "Z5-MARK"
key    cmd+shift+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true timeout=5s
assert windows[0].tabs[1].panes[*] exists count=1
assert windows[0].tabs[1].panes[0].kind == "terminal" && windows[0].tabs[1].panes[0].focused == true
assert windows[0].tabs[1].panes[0].screen_tail[*] contains "Z5-MARK"
assert windows[0].tabs[0].panes[*] exists count=1
# 还是同一个 shell：能接着输入
type   "echo Z5-AFTER\n"
wait   windows[0].tabs[1].panes[0].screen_tail[*] contains "Z5-AFTER"
```
