# W4 编辑器实时预览：预览与编辑 pane 的生命周期
requires: sandbox
checklist: W4
scenarios: []

只关预览 pane（`⌘W` 聚焦在预览上）：编辑器的 `preview` 回到 `null`，编辑 pane 还在；再开预览后关闭编辑 pane（点头部「✕」）：
预览一起关闭，标签里只剩终端，没有悬空 pane。
先 `restart --set font_size=9`（理由同 W1），结束时改回 13。

**简化**：「聚焦到预览」用点预览 pane 的方式做：预览 pane 的 rect 取 `tabs[0].panes[2].rect`（编辑 pane 是 `panes[1]`，预览在它后面）。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/w4 && printf '# Title\n\nbody\n' > work/w4/a.md"
type   "cd -P ~/work/w4 && clear && gilvt view a.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w4/a.md" timeout=10s
key    e
wait   windows[0].editors[0].path contains "/work/w4/a.md" timeout=5s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "rendered" && windows[0].tabs[0].panes[*] exists count=3 timeout=10s
# 只关预览
click  'rect(windows[0].tabs[0].panes[2].rect)'
wait   windows[0].tabs[0].panes[2].focused == true timeout=5s
key    cmd+w
wait   windows[0].editors[0].preview == null && windows[0].tabs[0].panes[*] exists count=2 timeout=5s
assert windows[0].editors[*] exists count=1 && windows[0].tabs[0].panes[1].kind == "editor"
# 再开，然后关编辑 pane
click  'rect(windows[0].editors[0].rect)'
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "rendered" && windows[0].tabs[0].panes[*] exists count=3 timeout=10s
click  'rect(windows[0].editors[0].close_rect)'
wait   windows[0].editors[*] !exists && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[*] exists count=1 timeout=5s
assert windows[0].tabs[0].panes[0].foreground == "shell"
restart --set font_size=13
```

## judge
- 没有残留的预览 pane：最后标签里只有终端一个 pane。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
