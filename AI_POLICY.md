# AI Usage Policy

gilvt is built for people who work with coding agents, and its maintainers use them too. AI-assisted
contributions are welcome under these rules:

- **Disclose it.** Say which tools you used (for example Claude Code, Codex, Cursor) and how much of the
  change they produced. The pull request template asks for this.
- **Understand every line.** You must be able to explain what your change does and how it interacts
  with the rest of gilvt without help from an AI tool. If you can't, don't submit it.
- **Verify it yourself.** Run the tests, and for UI changes run the affected GUI acceptance cases (see
  [CONTRIBUTING.md](CONTRIBUTING.md)). Don't submit output you haven't checked.
- **Keep issues and reviews human.** You may use AI to draft an issue or a comment, but a person must
  review and edit it before posting. Cut the noise; describe what you actually observed.
- **No AI-generated media** (images, icons, screenshots edited by AI, video, audio).

Pull requests and issues that look like unreviewed AI output may be closed without a detailed review.

These rules apply to outside contributions. Maintainers use AI tools at their own discretion and are
responsible for what they merge.
