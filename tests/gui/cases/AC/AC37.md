# AC37 检查器时间线里 ⌘+点击远端会话的文件名
requires: remote
checklist: AC37
scenarios: [timeline]

远端会话的文件名指向远端主机上的文件：⌘+点击从远端读取，用 Quick Look 打开，绝不打开 Mac 上的同名文件。远端的 README.md 是 12 字节（`remote-ac37`），与 H4 在 Mac 上写的不同，用 `size` 区分。点击会抢前台。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   'ssh devbox-test\n'
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "要在 devbox-test 上安装远端组件吗" timeout=30s
type   'Y\n'
wait   windows[0].tabs[0].panes[0].remote.enhanced == true && hosts[0].bridge == "up" timeout=60s
type   'mkdir -p ~/ac37 && echo remote-ac37 > ~/ac37/README.md && cd ~/ac37 && clear\n'
wait   windows[0].tabs[0].panes[0].remote.cwd == "/home/dev/ac37" timeout=10s
type   'claude @scenario:timeline\n'
wait   windows[0].inspector.source == "remote" && windows[0].inspector.card.status == "idle" timeout=30s
wait   windows[0].inspector.rows[?label contains "Update README.md"] exists timeout=15s
click  'rect(windows[0].inspector.rows[?label contains "Update README.md"].file)' cmd
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.size == 12 timeout=10s
assert windows[0].overlay.path == "/home/dev/ac37/README.md" && windows[0].overlay.host == "dev@127.0.0.1:2202"
assert windows[0].inspector.toast == null
shot   ac37-quicklook
key    esc
wait   windows[0].overlay == null
```

## judge
- `ac37-quicklook`：Quick Look 显示 `README.md`，内容是一行 `remote-ac37`（远端文件），标题处是远端主机；没有「这项功能暂不支持远端」提示。
