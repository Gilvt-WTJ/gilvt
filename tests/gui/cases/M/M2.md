# M2 主目录与 worktree 的会话归同一个项目
requires: sandbox
checklist: M2
scenarios: [default]

同一个仓库的主目录和它的 linked worktree 里各跑一个会话：左栏按主仓库名分组（同一个 `project:<仓库名>` 分区），不是两个项目；
worktree 里的那一行在 git 行前面带上 worktree 的目录名，以便和主目录区分。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'git init -q -b main ~/work/k2 && cd ~/work/k2 && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m init && git worktree add -q ../k2-wt -b k2-wt-branch'
type   "cd -P ~/work/k2 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k2"
type   "claude @scenario:default k2 主目录\n"
wait   windows[0].sidebar.rows[?name=="k2 主目录"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/k2-wt && claude @scenario:default k2 工作树\n"
wait   windows[0].sidebar.rows[?name=="k2 工作树"].status == "idle" && windows[0].tabs[1].panes[0].foreground == "agent:claude" timeout=20s
# 两个会话都归「k2」这个项目，没有出现按目录名 k2-wt 单独分的组
wait   windows[0].sidebar.rows[?section=="project:k2"] exists count=2 timeout=20s
assert windows[0].sidebar.sections[?name=="project:k2"] exists count=1
assert windows[0].sidebar.sections[?name=="project:k2-wt"] !exists
assert windows[0].sidebar.rows[?section=="project:k2"].git.repo == "k2" count=2
assert windows[0].sidebar.rows[?section=="project:k2"].git.linked_worktree == true count=1
assert windows[0].sidebar.rows[?section=="project:k2"].git.linked_worktree == false count=1
assert windows[0].sidebar.rows[?section=="project:k2"].git.line contains "k2-wt · ⎇ k2-wt-branch"
assert windows[0].sidebar.rows[?name=="k2 主目录"].git.line == "⎇ main"
assert windows[0].sidebar.rows[?name=="k2 工作树"].git.branch == "k2-wt-branch"
shot   k2-grouped
# 会话面板里两个会话同属当前项目（项目名是主仓库名，不是目录名）
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
assert windows[0].overlay.rows[?agent=="claude"] exists count=2
key    esc
wait   windows[0].overlay == null
```

## judge
- `k2-grouped`：左栏只有一个「k2」分区，里面两行：主目录那行的 git 行是 `⎇ main`，工作树那行是 `k2-wt · ⎇ k2-wt-branch`（前缀是 worktree 的目录名）。
- 没有名为「k2-wt」的分区。
- `⌘⇧R` 的两行都是 k2 项目的会话（`overlay.rows`），不是各自一个项目。
