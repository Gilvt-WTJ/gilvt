# K5 超过 8 个文件：前 8 个加「按目录分组查看全部」
requires: sandbox
checklist: K5
scenarios: [artifacts-many]

一轮写出 10 个文件；只列前 8 个，点链接后列出全部。会点击（抢前台）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k5 && cd work/k5 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k5 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k5"
type   "claude @scenario:artifacts-many\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].hidden_files == 2 timeout=30s
assert windows[0].inspector.artifacts.cards[0].files[*] exists count=8
click  'rect(windows[0].inspector.artifacts.cards[0].more_rect)'
wait   windows[0].inspector.artifacts.cards[0].hidden_files == 0 && windows[0].inspector.artifacts.cards[0].files[*] exists count=10 timeout=5s
shot   k5-all-files
```

## judge
- `k5-all-files`：卡片列出 10 个文件（按目录分组）。
