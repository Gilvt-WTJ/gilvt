# R8 「◎ 问它」带上范围 chip；回答流式出现，带工具调用行；停止、回答中再发、⇥ 收起
requires: sandbox
checklist: R8
scenarios: [three-turns]

`chat-slow` 让假大脑每段之间停 1.5 秒，好看到流式中间态。回答完成后接着验：回答中点「停止」、回答中直接再发一条（先中断当前轮）、点 `⇥` 收起后字母键 a 仍作用于卡片墙、点竖条展开。聊天文字只打 ASCII（输入法会改写中文），回车单独用 `key enter`（监控官标签里 `type` 没有 pane 回显可核对）。

## steps
```gilvt-steps
sh     "rm -f ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-chat.log && printf 'chat-slow\n' > ~/.gilvt-fake-brain"
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=false'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/r8 && cd -P ~/work/r8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/r8"
type   "claude @scenario:three-turns\n"
key    cmd+shift+o
# 沙盒里监控官标签约 720px（< 760px 会收成竖条）：收起检查器让面板完整出现
key    cmd+i
wait   windows[0].inspector.visible == false && windows[0].monitor.chat.collapsed == false timeout=5s
wait   windows[0].monitor.cards[?group=="done"] exists count=1 timeout=20s
click  'rect(windows[0].monitor.cards[?group=="done"].ask)'
wait   windows[0].monitor.chat.input.chips[*].key contains "agent:claude:" timeout=5s
assert windows[0].monitor.chat.scope[*] contains "agent:claude:"
shot   r8-chip
type   "why did test one fail"
key    enter
wait   windows[0].monitor.chat.messages[?role=="user"].chips[*] contains "agent:claude:" timeout=5s
assert windows[0].monitor.chat.messages[?role=="user"].text == "why did test one fail"
wait   windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="get_timeline"].done == true timeout=30s
assert windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="get_session"].label contains "✓ 已读取"
assert windows[0].monitor.chat.messages[?role=="assistant"].tools[?name=="get_timeline"].label contains "时间线"
wait   windows[0].monitor.chat.messages[?role=="assistant"].text contains "（第 1 段）" timeout=20s
assert windows[0].monitor.chat.status == "answering"
assert windows[0].monitor.chat.stop != null
shot   r8-streaming
wait   windows[0].monitor.chat.status == "idle" timeout=30s
assert windows[0].monitor.chat.messages[?role=="assistant"].text contains "（完）"
assert windows[0].monitor.chat.messages[?role=="assistant"].links[*].key contains "agent:claude:"
assert windows[0].monitor.chat.messages[?role=="assistant"].links[0].rect != null
assert windows[0].monitor.chat.input.chips[*].key contains "agent:claude:"
assert chat_process.running == true && chat_process.starts == 1 && chat_process.turns == 1
sh     "grep -qF 'user: <scope keys=\"agent:claude:' ~/.gilvt-fake-brain-chat.log"
shot   r8-done
# 回答中点「停止」：只中断这一轮，进程不重启
type   "and the second one"
key    enter
wait   windows[0].monitor.chat.status == "answering" && windows[0].monitor.chat.stop != null timeout=15s
click  'rect(windows[0].monitor.chat.stop)'
wait   windows[0].monitor.chat.status == "idle" timeout=15s
assert windows[0].monitor.chat.messages[?role=="notice"].text contains "（这一轮已中断）"
assert chat_process.running == true && chat_process.starts == 1
shot   r8-stopped
# 回答中直接再发一条：先中断当前轮，再回答新的一条
click  'rect(windows[0].monitor.chat.input)'
type   "third question"
key    enter
wait   windows[0].monitor.chat.status == "answering" timeout=15s
type   "fourth question"
key    enter
wait   windows[0].monitor.chat.messages[?role=="user"].text contains "fourth question" timeout=10s
wait   windows[0].monitor.chat.status == "idle" timeout=40s
assert windows[0].monitor.chat.messages[?role=="notice"] exists count=2
assert windows[0].monitor.chat.messages[?role=="assistant"].text contains "（完）"
assert chat_process.running == true && chat_process.starts == 1
# ⇥ 收起：竖条出现；字母键 a 作用于卡片墙（面板展开、输入框仍是空的，说明键没进输入框）；再收起，点竖条展开
click  'rect(windows[0].monitor.chat.collapse)'
wait   windows[0].monitor.chat.collapsed == true && windows[0].monitor.chat.rail != null timeout=5s
key    a
wait   windows[0].monitor.chat.collapsed == false && windows[0].monitor.chat.input.text == "" timeout=5s
click  'rect(windows[0].monitor.chat.collapse)'
wait   windows[0].monitor.chat.collapsed == true && windows[0].monitor.chat.rail != null timeout=5s
click  'rect(windows[0].monitor.chat.rail)'
wait   windows[0].monitor.chat.collapsed == false && windows[0].monitor.chat.rect != null timeout=5s
shot   r8-reopened
sh     rm -f ~/.gilvt-fake-brain
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
# 把检查器放回来（ui.json 里的 inspector_hidden 不留给后面的用例）
key    cmd+i
wait   windows[0].inspector.visible == true timeout=5s
sleep  2s
restart --set 'monitor.enabled=false'
```

## judge
- `r8-chip`：输入框里有紫色 chip「@<会话名> ×」，输入框边框是紫色（有焦点）；卡片墙上这张卡片是选中的。
- `r8-streaming`：头部有「回答中」pill 和「停止」；回答还没出齐三段、没有「（完）」；上方两行灰色小字「✓ 已读取 … 的概况」「✓ 已读取 … 第 a–b 轮时间线（N 个工具调用）」。
- `r8-done`：回答三段齐全，最后一段的会话名是可点的链接（紫色下划线）；「停止」消失；输入框里的 chip 仍在（可以追问）。
- `r8-stopped`：被中断的回答保留已出现的部分，下面一行灰色「（这一轮已中断）」；「回答中」pill 已消失。
- `r8-reopened`：面板回到 360px 宽，历史完整，没有竖条。
- 不在这里断言：「正在读取」的瞬时状态（工具行 started 到 done 之间很短）；排队消息（对话进程还在启动时发出的第二条）在启动成功后发出，这一条没有稳定的窗口，见报告「手动」。
