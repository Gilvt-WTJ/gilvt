# N1 ⌘W：Agent 在思考 / 执行 / 等授权 / 在问你时先确认（默认取消），其余状态直接关
requires: sandbox
checklist: N1
scenarios: [default, think-long, long-tool, approve-bash, ask-question, api-error]

在分屏的右 pane 里跑 agent，对它按 `⌘W`。思考中、执行中、等待授权、在问你：弹出关闭确认条（`close_confirm`，`action: "pane"`，`items` 列出会话和状态），
`↩` / `Esc` 都是取消（默认），pane 还在；`⌘↩` 才是「仍然关闭」。空闲、已结束、出错的 agent 和普通 shell：直接关，不弹确认。

## judge
- `l1-asking`、`l1-approval`：窗口里有确认条，写着受影响的会话（「C · <会话名> · 在问你」「… · 等待授权」），默认的按钮是「取消」；pane 还在。
- 思考中这一步依赖 `default` 剧本的 2 秒思考窗口：`wait … == "thinking"` 之后马上按 `⌘W`；如果这一轮恰好先结束，`close_confirm` 不出现，重跑一次（不是 bug）。
- 空闲、出错、已结束、普通 shell 四种：按 `⌘W` 后 pane 立即关闭，没有确认条（断言 `close_confirm == null`，pane 数减一）。
- 取消（`↩` / `Esc`）之后 agent 状态没有变化（还在等回答 / 授权）。
