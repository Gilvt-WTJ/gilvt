# I38 external exact 生命周期控制
requires: manual
checklist: I38
scenarios: []

## steps
```gilvt-steps
# 手动：安装全局 hooks，在外部终端运行专用测试 Agent 并至少完成一轮，再从 Session Center 打开它的 Review
# 手动：复制诊断，核对字段和隐私边界；点击中断，确认当前 turn 收到 SIGINT
# 手动：验证终止的同会话二次确认、切换会话取消确认，以及第二次点击发送 SIGTERM
# 手动：构造身份变化或不安全 PGID，确认信号被拒绝；核对 inferred/unresolved 的控制按钮禁用
```

## judge
- 「复制诊断」包含 agent、session ID、PID、进程启动时间、PGID、TTY、终端和 `binding=exact`，不含 prompt、环境变量或完整 argv。
- 「中断」发送 SIGINT，Agent 当前 turn 被中断。
- 「终止…」第一次只变成「确认终止」；切换会话会取消确认；同一会话连续第二次点击才发送 SIGTERM。
- PID 被复用、进程类型改变、PGID 不安全时拒绝发送信号并显示原因。
- `inferred` / `unresolved` runtime 的中断与终止按钮存在但禁用。
