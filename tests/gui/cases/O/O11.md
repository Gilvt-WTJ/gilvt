# O11 手改 config.toml 的 theme / [colors] 立即生效
requires: sandbox
checklist: O11
scenarios: []

不重启：用 `sh` 改 `config.toml` 的 `theme`，所有窗口和设置窗口的「外观」页跟着变；改成不存在的名字时窗口顶部出现错误横幅并回退；加上 `[colors]` 覆盖后立即叠加。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert theme.name == "gilvt Light"
key    cmd+,
wait   settings.key == true timeout=5s
click  'rect(settings.pages[?id=="appearance"])'
wait   settings.page == "appearance" && settings.appearance.fixed == "gilvt Light" timeout=5s
sh     "cp .config/gilvt/config.toml o11-orig.toml"
sh     "sed -i '' 's/^theme = .*/theme = \"Nord\"/' .config/gilvt/config.toml"
wait   theme.name == "Nord" timeout=5s
wait   settings.appearance.fixed == "Nord" timeout=5s
# 写错的名字：横幅提示，回退到 gilvt 的默认主题
sh     "sed -i '' 's/^theme = .*/theme = \"Nrod\"/' .config/gilvt/config.toml"
wait   theme.source == "fallback" timeout=5s
assert theme.error contains "Nrod"
wait   windows[0].error_banner contains "Nrod" timeout=5s
shot   o11-banner
# [colors] 覆盖立即叠加
sh     "sed -i '' 's/^theme = .*/theme = \"dark\"/' .config/gilvt/config.toml && printf '%s\n' '[colors]' 'background = \"#202040\"' >> .config/gilvt/config.toml"
wait   theme.name == "gilvt Dark" && theme.colors_overrides == 1 timeout=5s
assert settings.appearance.colors_overrides == 1
shot   --window key o11-colors
key    cmd+w
wait   settings !exists timeout=5s
sh     "cp o11-orig.toml .config/gilvt/config.toml && rm -f o11-orig.toml"
wait   theme.name == "gilvt Light" && theme.colors_overrides == 0 timeout=5s
```

## judge
- `o11-banner`：窗口顶部红色横幅：「主题 "Nrod" 不存在，已改用 gilvt …；你是不是想用 "Nord"？」之类的提示；界面是 gilvt 的默认主题。
- `o11-colors`：设置窗口深色，「外观」页底部有一行「配置中有 1 项 [colors] 颜色覆盖，已叠加在所选主题上」。
