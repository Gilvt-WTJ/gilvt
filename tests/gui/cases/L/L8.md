# L8 稍后提醒：从队列隐藏，重启后仍然隐藏
requires: sandbox
checklist: L8
scenarios: [hist-claude]

在 Review 里按 `Z` 打开提醒菜单（`Esc` 取消），再按 `1`（1 小时后）：这个会话离开队列、打开下一个；稍后提醒写进 `reviews.json`，
不改变 Review 位置；`⌘Q` 重开后它仍然不在队列里。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l8 && cd -P ~/work/l8 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l8"
seed   hist-claude --cwd work/l8 --id c1a0de00-0000-4000-8000-0000000b0801 --prompt "l8 甲"
seed   hist-claude --cwd work/l8 --id c1a0de00-0000-4000-8000-0000000b0802 --prompt "l8 乙"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[1] exists && windows[0].overlay.rows[2] !exists timeout=15s
key    space
wait   windows[0].overlay.session_review.session_key contains "0b0801" && windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=10s
key    z
wait   windows[0].overlay.session_review.snooze_menu == true
assert windows[0].overlay.session_review.actions.snooze_hour.enabled == true && windows[0].overlay.session_review.actions.snooze_tomorrow.enabled == true
shot   l8-menu
key    esc
wait   windows[0].overlay.session_review.snooze_menu == false && windows[0].overlay.session_review.session_key contains "0b0801"
assert windows[0].overlay.rows[1] exists
key    z
wait   windows[0].overlay.session_review.snooze_menu == true
key    1
wait   windows[0].overlay.rows[?session_key contains "0b0801"] !exists && windows[0].overlay.session_review.session_key contains "0b0802" timeout=10s
assert windows[0].overlay.tabs[?name=="review"].count == 1 && windows[0].overlay.store_last_error == null && windows[0].overlay.session_review.snooze_menu == false
sh     'awk "/0b0801/{f=1} f&&/snoozed_until/{ok=1} f&&/reviewed_through/{bad=1} f&&/^    }/{f=0} END{exit !ok || bad}" "$HOME/Library/Application Support/gilvt/state/reviews.json"'
key    esc
key    esc
wait   windows[0].overlay == null
key    cmd+q
sleep  2s
restart
wait   windows[*] exists count=1 timeout=20s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=15s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.rows[?session_key contains "0b0802"] exists timeout=15s
assert windows[0].overlay.rows[?session_key contains "0b0801"] !exists && windows[0].overlay.tabs[?name=="review"].count == 1
key    esc
wait   windows[0].overlay == null
```

## judge
- `l8-menu`：Review 底部出现「稍后提醒：1 小时后 / 今天晚些时候 / 明天 / 取消」一行。
- 重开后第一个会话仍不在队列里（1 小时没到），第二个还在。
