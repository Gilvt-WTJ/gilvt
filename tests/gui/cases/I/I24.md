# I24 dock_bounce = false：角标照常、图标不跳
requires: sandbox
checklist: I24
scenarios: [ask-question]
parallel: serial

## steps
```gilvt-steps
restart --set notify.dock_bounce=false
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
assert dock_bounces == 0 && front == false
type   "mkdir -p ~/work/i24 && cd -P ~/work/i24 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=1 && dock_badge == "1" timeout=15s
sleep  3s
assert dock_bounces == 0
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "cd -P ~/work/i24 && claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="needs_you"] exists count=2 && dock_badge == "2" timeout=15s
sleep  3s
assert dock_bounces == 0
restart --set notify.dock_bounce=true
```

## judge
- 全部是状态断言。最后的 `restart` 恢复默认配置；它失败时先停下来报告。
