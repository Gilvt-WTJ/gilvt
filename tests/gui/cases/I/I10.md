# I10 清理筛选下多选移到废纸篓
requires: sandbox
checklist: I10
scenarios: [hist-claude, hist-codex]

「≥ 7 天未活动」下 `⇧`+点击选一段、`⌘`+点击增减，`⌘⌫` 出确认条；`Esc` 先关确认条再关浮层；确认后会话从列表消失，
文件进了**真实用户**的废纸篓（访达的废纸篓不随 HOME 改变）。测试会话由 `seed` 生成，只在沙盒里。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i10 --age 8d --id c1a0de00-0000-4000-8000-000000001001 --prompt "i10 旧会话 甲" --companion
seed   hist-claude --cwd work/i10 --age 9d --id c1a0de00-0000-4000-8000-000000001002 --prompt "i10 旧会话 乙" --companion
seed   hist-codex --cwd work/i10 --age 10d --id 01990000-0000-7000-8000-000000001003 --prompt "i10 旧会话 丙" --companion
seed   hist-claude --cwd work/i10 --age 1h --id c1a0de00-0000-4000-8000-000000001004 --prompt "i10 新会话"
type   "cd -P ~/work/i10 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i10"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 4 timeout=15s
shot   i10-list
click  'rect(windows[0].overlay.chips[?label=="≥ 7 天未活动"])'
wait   windows[0].overlay.filter.stale == true && windows[0].overlay.items == 3
shot   i10-stale
# 顺序：甲（8 天）、乙（9 天）、丙（10 天）。点甲，⇧ 点丙选中三个，⌘ 点乙去掉它
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 甲"])'
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 丙"])' shift
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 乙"])' cmd
wait   windows[0].overlay.rows[?marked==true] exists count=2 && windows[0].overlay.rows[?title contains "i10 旧会话 乙"].marked == false timeout=3s
shot   i10-selected
key    cmd+backspace
wait   windows[0].overlay.confirm.text contains "2 个会话" timeout=3s
shot   i10-confirm
key    esc
assert windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3
shot   i10-confirm-closed
key    esc
wait   windows[0].overlay == null
# 再来一次，这次确认
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 4 timeout=15s
click  'rect(windows[0].overlay.chips[?label=="≥ 7 天未活动"])'
wait   windows[0].overlay.filter.stale == true && windows[0].overlay.items == 3
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 甲"])'
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 丙"])' shift
click  'rect(windows[0].overlay.rows[?title contains "i10 旧会话 乙"])' cmd
wait   windows[0].overlay.rows[?marked==true] exists count=2 timeout=3s
key    cmd+backspace
# 确认条打开时 ⌘↩ / ⇧↩ 都不会误确认
key    cmd+enter
key    shift+enter
assert windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 3
shot   i10-still-confirming
assert windows[0].overlay.confirm.text contains "2 个会话"
click  'rect(windows[0].overlay.confirm.buttons[?label=="移到废纸篓"])'
wait   windows[0].overlay.items == 1 timeout=10s
note-trashed c1a0de00-0000-4000-8000-000000001001 01990000-0000-7000-8000-000000001003
sh     "! find .claude .codex -name '*00000000100[13]*' | grep -q ."
sh     "find .claude -name 'c1a0de00-0000-4000-8000-000000001002.jsonl' | grep -q ."
shot   i10-done
key    esc
```

## judge
- `i10-stale`：只剩三个旧会话，右侧有大小（每个约 0.1 MB：`--companion` 各加了 64 KB），出现勾选框与「⇧ / ⌘ 点击多选」。
- `i10-selected`：勾选了甲、丙（乙被 `⌘` 点掉），上方「已选 2 个 · 共 X MB」。
- `i10-confirm`：确认条「2 个会话 · X MB 将移到废纸篓（可从废纸篓还原）」；`i10-confirm-closed`：`Esc` 只关掉了确认条（断言浮层仍在）。
- `i10-still-confirming`：`⌘↩` / `⇧↩` 之后确认条仍在，列表没变（断言）。
- 确认后：`note-trashed` 核对真实 `~/.Trash` 里有 `c1a0de00-…1001.jsonl`、`c1a0de00-…1001/`、
  `rollout-…-01990000-…1003.jsonl` 与它的 `.langsmith`；`sh` 确认沙盒里甲、丙的文件都不在了、乙还在。
  这些条目记进 `trashed.txt`，由 `sandbox.sh down` 列给用户处理——**不要清空废纸篓**。
  `note-trashed` 退出 5 表示这个终端读不了 `~/.Trash`（没有完全磁盘访问权限）：改为在访达里只读核对，记 ⚠️。
- 「确认条打开时按住 `↩` 不会误确认」：`keys` 工具发不出按键重复（autorepeat），这一项不在本用例里，见报告。
