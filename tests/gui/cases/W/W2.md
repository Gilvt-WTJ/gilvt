# W2 编辑器实时预览：切换预览类型并记住
requires: sandbox
checklist: W2
scenarios: []

预览打开时点头部的「预览：渲染」按钮，在 `rendered` 与 `changes` 之间切换；选择按文件类型（`md`）写进 `ui.json` 的 `live_preview`，
关掉预览再开同类型文件时沿用最后一次的选择。

**简化**：`ui.json` 里的记录用 `sh` + `grep` 断言（路径同 H14：沙盒 HOME 下的 `Library/Application Support/gilvt/state/ui.json`）；
「下次打开用它」靠关掉预览后重新 `⌘⇧V` 检查 `provider`（同一个沙盒进程内，由内存里的偏好决定）。
先 `restart --set font_size=9`（理由同 W1），结束时改回 13，并删掉 `ui.json` 以免影响别的用例。

## steps
```gilvt-steps
restart --set font_size=9
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/w2 && printf '# Title\n\nbody\n' > work/w2/a.md"
type   "cd -P ~/work/w2 && clear && gilvt view a.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.path contains "/work/w2/a.md" timeout=10s
key    e
wait   windows[0].editors[0].path contains "/work/w2/a.md" timeout=5s
# 从 Quick Look 按 e 打开的编辑 pane 不抢键盘（键盘留在终端）：先点进编辑区，快捷键才会到编辑器
click  'rect(windows[0].editors[0].rect)'
wait   windows[0].tabs[0].panes[1].focused == true timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "rendered" timeout=10s
assert windows[0].editors[0].preview_rect != null
click  'rect(windows[0].editors[0].preview_rect)'
wait   windows[0].editors[0].preview.provider == "changes" timeout=5s
shot   w2-changes
sh     "grep -c '\"md\": \"changes\"' 'Library/Application Support/gilvt/state/ui.json'"
click  'rect(windows[0].editors[0].preview_rect)'
wait   windows[0].editors[0].preview.provider == "rendered" timeout=5s
sh     "grep -c '\"md\": \"rendered\"' 'Library/Application Support/gilvt/state/ui.json'"
click  'rect(windows[0].editors[0].preview_rect)'
wait   windows[0].editors[0].preview.provider == "changes" timeout=5s
# 关掉预览再开：沿用最后一次的选择
key    cmd+shift+v
wait   windows[0].editors[0].preview == null timeout=5s
key    cmd+shift+v
wait   windows[0].editors[0].preview.provider == "changes" timeout=10s
sh     "rm -f 'Library/Application Support/gilvt/state/ui.json'"
restart --set font_size=13
```

## judge
- `w2-changes`：预览 pane 显示「改动」视图（缓冲区与磁盘一致，所以是「无改动」之类的空状态或整份文件，不是渲染后的排版）。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
