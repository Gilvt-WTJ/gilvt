# L14 300+ 个会话：队列可交互、列表虚拟化、终端不被阻塞
requires: sandbox
checklist: L14
scenarios: [hist-claude]

在 gilvt 之外写入 320 个新完成的会话，打开 Session Center：窗口立即出现（扫描在后台），扫描完成后「待 Review」有 320 个；
关掉再开（缓存命中）队列在 2 秒内就可交互；列表是虚拟化的，只有可见行有 rect。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'rm -rf "$HOME/.claude/projects" "$HOME/.codex/sessions"'
type   "mkdir -p ~/work/l14 && cd -P ~/work/l14 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/l14"
sh     'mkdir -p "$HOME/work/l14" && cd "$HOME/work/l14" && i=1 && while [ $i -le 320 ]; do claude --headless --session-id "$(printf c1a0de00-0000-4000-8000-%012d $i)" "@scenario:hist-claude l14 会话 $i" >/dev/null || exit 1; i=$((i + 1)); done'
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=2s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.refreshing == false && windows[0].overlay.tabs[?name=="review"].count == 320 timeout=120s
assert windows[0].overlay.rows[319] exists && windows[0].overlay.rows[320] !exists && windows[0].overlay.rows[0].rect != null && windows[0].overlay.rows[200].rect == null
shot   l14-first
key    esc
wait   windows[0].overlay == null
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=2s
key    cmd+2
wait   windows[0].overlay.kind == "session_center" && windows[0].overlay.tab == "review" && windows[0].overlay.tabs[?name=="review"].count == 320 && windows[0].overlay.rows[0].rect != null timeout=2s
key    space
wait   windows[0].overlay.session_review.loading == false && windows[0].overlay.session_review.turns[1] exists timeout=3s
key    esc
key    esc
wait   windows[0].overlay == null
type   "echo l14-done\n"
wait   windows[0].tabs[0].panes[0].screen_tail[*] contains "l14-done" timeout=5s
```

## judge
- 「待 Review」tab 的数字是 320；滚动列表流畅，没有明显卡顿。
- 第二次打开时队列几乎立刻出现（缓存命中），打开 Review 也在几百毫秒内显示。
- 这些时间上限（2 秒 / 3 秒）只是防止明显的阻塞；精确的耗时目标（缓存命中 200 ms 内可交互、首屏 300 ms）看 `l14-first` 之外的体感，必要时用 Instruments 复核。
