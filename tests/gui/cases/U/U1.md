# U1 Claude 配置摘要：分层、扩展与脱敏
requires: sandbox
checklist: U1
scenarios: [default]

用户层和项目层都准备 Claude 配置。配置标签应显示最终摘要和来源，但不能把 MCP 命令、URL、token 或环境变量值带进 DebugState。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p .claude/skills/user-skill .claude/commands .claude/agents work/u1/.git work/u1/.claude/skills/project-skill work/u1/.claude/commands work/u1/.claude/agents"
sh     "printf '%s\n' '{\"model\":\"disk-sonnet\",\"hooks\":{\"Stop\":[]}}' > .claude/settings.json && printf 'user memory\n' > .claude/CLAUDE.md && printf x > .claude/skills/user-skill/SKILL.md && printf x > .claude/commands/user.md && printf x > .claude/agents/user.md"
sh     "printf '%s\n' '{\"permissions\":{\"defaultMode\":\"plan\"},\"hooks\":{\"PreToolUse\":[]}}' > work/u1/.claude/settings.json && printf '%s\n' '{\"model\":\"local-opus\"}' > work/u1/.claude/settings.local.json"
sh     "printf '%s\n' '{\"mcpServers\":{\"project-mcp\":{\"command\":\"U1-MCP-SECRET\",\"env\":{\"TOKEN\":\"U1-TOKEN-SECRET\"}}}}' > work/u1/.mcp.json && printf '%s\n' '{\"mcpServers\":{\"user-mcp\":{\"url\":\"https://U1-URL-SECRET.invalid\"}}}' > .claude.json"
sh     "printf 'project memory\nsecond line\n' > work/u1/CLAUDE.md && printf x > work/u1/.claude/skills/project-skill/SKILL.md && printf x > work/u1/.claude/commands/project.md && printf x > work/u1/.claude/agents/project.md"

wait   windows[0].inspector.tab == "config" && windows[0].inspector.config.loading == false timeout=10s
assert windows[0].inspector.config.agent == "claude" && windows[0].inspector.config.cwd contains "/work/u1"
wait   windows[0].inspector.config.model.text == "claude-sonnet-4-5-20250929" && windows[0].inspector.config.model.source == "runtime" timeout=10s
wait   windows[0].inspector.config.permission.text == "default" && windows[0].inspector.config.permission.source == "runtime" timeout=10s
assert windows[0].inspector.config.mcp[*] exists count=2 && windows[0].inspector.config.mcp[?name=="user-mcp"].source == "user" && windows[0].inspector.config.mcp[?name=="project-mcp"].source == "project"

assert windows[0].inspector.config.skills == 2 && windows[0].inspector.config.commands == 2 && windows[0].inspector.config.subagents == 2

shot   u1-claude-config
```

## judge
- `u1-claude-config`：模型、权限、MCP、Hooks、扩展数量、两份记忆和来源文件分组清楚；顶部明确写「只读」。
- 截图和保存的 DebugState 中没有 `U1-MCP-SECRET`、`U1-TOKEN-SECRET` 或 `U1-URL-SECRET`。
