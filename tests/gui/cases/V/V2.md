# V2 内置编辑器：打开路由（新标签 / 分屏 / ⌥ 翻转 / 聚焦已有）
requires: sandbox
checklist: V2
scenarios: [default]

「编辑」的默认去处：当前标签已有 ≥ 3 个 pane，或在来源 pane 右边分屏后任一半 < 60 列时**新开文件标签**（插在当前标签右边，键盘进入
编辑 pane），否则分屏；`⌥`+点「编辑」翻转（强制分屏时即使变窄也照做）；文件已经在某个编辑 pane 里时只聚焦它。关掉文件标签回到来源标签。

和 V1 一样先 `restart --set font_size=9`，终端区约 132 列，这样两条「新标签」规则可以分开验证：
左右分屏（`⌘D`）后 Agent 终端约 66 列，再分会 < 60 列 → 新标签（只有 2 个 pane，所以是列数规则）；
关掉右边的 shell、上下分屏两次（`⌘⇧D`）后 Agent 终端仍是整宽约 132 列，但标签里有 3 个 pane → 新标签（pane 数规则）。
「回到来源标签」：文件标签总是插在来源标签右边，关掉后「回到来源」与「回到左邻」在这里是同一个标签，用例只断言回到了它。

## judge
- `v2-file-tab`：标签栏多了一个标题为 `SKILL.md` 的标签，紧挨在 Agent 标签右边且是当前标签；编辑 pane 占满整个终端区；
  来源标签里的三个上下排列的 pane 不变（断言已覆盖结构）。
- `v2-flipped-split`：最上面一行是 Agent 终端和它右边的编辑 pane，各占一半，两个 shell 在下面整宽排列；编辑 pane 正常显示文本
  （没有「窗口太窄」）；焦点边框在 Agent 终端上。
- 最后的 `restart` 把 `font_size` 改回 13；它失败时后面的用例都不可信，先停下来报告。
