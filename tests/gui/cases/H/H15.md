# H15 检查器跟随焦点 pane
requires: sandbox
checklist: H15
scenarios: [ask-question, default]

在 pane / 标签之间切换焦点（`⌘⌥` 方向键、`⌘1`、点击标签、`⌘⇧↑` / `⌘⇧↓`），检查器立即换成当前 pane 的会话；普通 shell 时为空状态。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h15 && cd -P ~/work/h15 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h15"
type   "claude @scenario:ask-question\n"
wait   windows[0].sidebar.rows[?section=="project:h15"].status == "awaiting_answer" && windows[0].inspector.card.status == "awaiting_answer" timeout=15s
key    cmd+d
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
wait   windows[0].inspector.card == null
key    cmd+alt+left
wait   windows[0].tabs[0].panes[0].focused == true && windows[0].inspector.card.status == "awaiting_answer"
key    cmd+alt+right
wait   windows[0].tabs[0].panes[1].focused == true && windows[0].inspector.card == null
key    cmd+t
wait   windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/h15 && claude @scenario:default h15 第二个会话\n"
wait   windows[0].tabs[1].panes[0].foreground == "agent:claude" && windows[0].inspector.card.status == "idle" timeout=15s
key    cmd+1
wait   windows[0].tabs[0].active == true && windows[0].inspector.card == null
shot   h15-tabs
click  'rect(windows[0].tabs[1])'
wait   windows[0].tabs[1].active == true && windows[0].inspector.card.status == "idle"
key    cmd+1
wait   windows[0].tabs[0].active == true && windows[0].inspector.card == null
# 从普通 shell pane 按 ⌘⇧↓ 到「全部会话」的第一行，再按一次到下一行
key    cmd+shift+down
wait   windows[0].tabs[*].panes[?focused==true].foreground == "agent:claude" && windows[0].inspector.card.status != "ended"
shot   h15-next-1
key    cmd+shift+down
wait   windows[0].tabs[*].panes[?focused==true].foreground == "agent:claude" && windows[0].inspector.card.status != "ended"
shot   h15-next-2
key    cmd+shift+up
wait   windows[0].tabs[*].panes[?focused==true].foreground == "agent:claude"
```

## judge
- 状态断言已经覆盖「立即切换」：每次焦点变化后 `inspector.card` 跟着变，shell pane 时为 `null`（空状态）。
- `h15-next-1` / `h15-next-2`：两次 `⌘⇧↓` 分别停在两个会话上（一个「在问你」、一个空闲），检查器的状态卡与左栏
  高亮行一致。
- 点击标签是本用例唯一的前台动作；锁屏时这一步退出 5，其余步骤照常。
