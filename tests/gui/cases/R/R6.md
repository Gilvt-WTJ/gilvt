# R6 排除目录下的会话不送给模型
requires: sandbox
checklist: R6
scenarios: [monitor-slow]

`exclude_paths` 含 `~/work/r6`：另开一个标签在不排除的 `~/work/r6ok` 里跑同一个剧本做对照。对照会话得到 ✦ 总结之后，排除目录里的卡片仍没有 ✦ 块、左栏没有 ✦ 行，假大脑的日志里没有它的目录（只断言日志内容：重启时的 pane 检查命令本身也会被总结一次）。目录在重启前用 `sh` 建好，fake agent 用一条命令启动。

## steps
```gilvt-steps
sh     mkdir -p ~/work/r6/sub ~/work/r6ok && rm -f ~/.gilvt-fake-brain ~/.gilvt-fake-brain.log ~/.gilvt-fake-brain-count
restart --set 'monitor.enabled=true' --set 'monitor.auto_summary=true' --set 'monitor.exclude_paths=["~/work/r6"]'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "cd -P ~/work/r6/sub && claude @scenario:monitor-slow\n"
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].panes[0].foreground == "shell" && windows[0].tabs[1].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "cd -P ~/work/r6ok && claude @scenario:monitor-slow\n"
key    cmd+shift+o
wait   windows[0].monitor.cards[?group=="done"] exists count=2 timeout=40s
# 对照会话已经被总结：总结在运转
wait   windows[0].sidebar.rows[?cwd contains "/work/r6ok"].summary contains "fake 总结" timeout=30s
sleep  3s
assert windows[0].monitor.cards[?group=="done"].summary == null count=1
assert windows[0].sidebar.rows[?cwd contains "/work/r6/sub"] exists count=1
assert windows[0].sidebar.rows[?cwd contains "/work/r6/sub"].summary == null
sh     "! grep -q 'r6/sub' ~/.gilvt-fake-brain.log"
sh     "grep -q '会话：' ~/.gilvt-fake-brain.log"
shot   r6
# restart 的沙盒检查只看聚焦的 pane（监控官标签是活动标签、或聚焦的是 claude 时都通不过）：先开一个新标签停在提示符，等布局保存
key    cmd+t
wait   windows[0].tabs[*].panes[?focused==true].foreground == "shell" && windows[0].tabs[*].panes[?focused==true].screen_tail[*] contains "sandbox$" timeout=15s
sleep  2s
restart --set 'monitor.enabled=false' --set 'monitor.exclude_paths=[]'
```

## judge
- `r6`：两张完成未看卡片：`r6ok` 那张有紫色 ✦ 块；排除目录里那张与 S1 完全一样（没有紫色块、没有「✦ 重新总结」）。
