# Z3 Quick Look 里按 T：直接在新标签打开
requires: sandbox
checklist: Z3
scenarios: []

`gilvt view` 打开 Quick Look 浮层；按 `T`（而不是 ⏎ 固定成分屏）预览直接成为一个新标签，原标签不分屏。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/z3 && printf 'one\ntwo\n' > work/z3/notes.txt"
type   "cd -P ~/work/z3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/z3"
type   "gilvt view notes.txt\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.code exists timeout=10s
key    t
wait   windows[0].overlay == null && windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true timeout=5s
assert windows[0].tabs[1].panes[*] exists count=1 && windows[0].tabs[1].panes[0].kind == "preview" && windows[0].tabs[1].panes[0].focused == true
assert windows[0].tabs[0].panes[*] exists count=1 && windows[0].tabs[0].panes[0].kind == "terminal"
shot   z3-tab
```

## judge
- `z3-tab`：第二个标签「👁 notes.txt」是当前标签，预览占满 pane 区域，标题栏提示含「T 新标签 · Esc 回到终端」。
