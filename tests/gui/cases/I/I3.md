# I3 Agent pane 里恢复 Codex 会话：开新标签
requires: real-codex
checklist: I3
scenarios: []

真实 `codex-w resume <id>`：历史轮次、能否接着对话都是真实 CLI 的行为（spec §6.2）。焦点 pane 正在运行 Agent 时，`↩` 开新标签，
shell 出现提示符后才输入 `cd <cwd> && codex-w resume <id>`。
前提（清单 I 节）：`~/.config/gilvt/config.toml` 的 `[agent]` 里已有用户本人确认过的 `codex_launch = "codex-w"`；测试不修改它。

## setup
```sh
tests/gui/sandbox.sh real-up --label i3
```

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
type   "mkdir -p ~/gilvt-lab/i3 && cd -P ~/gilvt-lab/i3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/gilvt-lab/i3"
type   "codex-w\n"
# Codex 的更新提示选 Skip；在这个目录第一次运行时的信任提示按 ↩
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" timeout=30s
type   "只回复这几个字：i3 第一轮\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=120s
type   "只回复这几个字：i3 第二轮\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=120s
type   "/quit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
type   "clear && claude --no-chrome\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=30s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.filter.scope == "current" timeout=15s
shot   i3-palette
# 第一行应当是刚才的 Codex 会话（没有提示词的新 claude 会话不列出）；不是的话用 ↓ 移过去
key    enter
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].screen_tail[*] contains "codex-w resume " timeout=15s
wait   windows[0].tabs[1].panes[0].foreground == "agent:codex" && windows[0].inspector.timeline_rows != 0 timeout=30s
shot   i3-resumed
type   "我们刚才的两轮你分别回复了什么？一句话回答\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=120s
shot   i3-continued
type   "/quit\n"
key    cmd+1
type   "/exit\n"
```

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/I3
```

## judge
- 原标签里的 claude 没有被打断（它仍是标签 1 的前台程序）；恢复发生在新的标签 2 里，命令在提示符出现之后才输入。
- `i3-resumed`：Codex 显示之前的对话；检查器时间线补出「i3 第一轮」「i3 第二轮」两轮。
- `i3-continued`：Codex 的回答提到 i3 第一轮 / 第二轮（能接着原来的上下文）。
- 这是真实 codex 用例：会产生费用；报告里记下 `codex-w --version`。
