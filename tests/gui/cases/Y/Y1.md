# Y1 ⌘⇧O 打开监控官，再按只聚焦
requires: sandbox
checklist: Y1
scenarios: []

按 `⌘⇧O` 在最左新开「◎ 监控官」标签；切到别的标签后再按一次，只是回到它，标签数不变。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
key    cmd+shift+o
wait   windows[0].tabs[0].panes[0].kind == "monitor" && windows[0].tabs[0].active == true timeout=10s
assert windows[0].tabs[0].title contains "监控官"
assert windows[0].tabs[*] exists count=2
assert windows[0].monitor.groups[?name=="terminals"].count == 1
shot   y1
click  'rect(windows[0].tabs[1])'
wait   windows[0].tabs[1].active == true && windows[0].tabs[0].active == false timeout=5s
key    cmd+shift+o
wait   windows[0].tabs[0].active == true && windows[0].tabs[0].panes[0].kind == "monitor" timeout=5s
assert windows[0].tabs[*] exists count=2
assert windows[0].tabs[?title contains "监控官"] exists count=1
```

## judge
- `y1`：最左标签「◎ 监控官」；内容区有筛选条「全部 1 · 终端 1」，一张终端卡片。
