# I19 左栏「已结束」里恢复会话
requires: sandbox
checklist: I19
scenarios: [default]

先 `restart`，让「已结束」只有本用例的会话并处于默认的折叠状态。

## steps
```gilvt-steps
restart
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i19 && cd -P ~/work/i19 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i19"
type   "claude @scenario:default i19 甲\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: i19 甲" timeout=15s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
type   "clear && claude @scenario:default i19 乙\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: i19 乙" timeout=15s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
type   "clear && claude @scenario:default i19 运行中\n"
wait   windows[0].sidebar.rows[?name=="i19 运行中"].status == "idle" timeout=15s
wait   windows[0].sidebar.sections[?name=="ended"].collapsed == true && windows[0].sidebar.sections[?name=="ended"].count == 2 timeout=10s
shot   i19-collapsed
click  'rect(windows[0].sidebar.sections[?name=="ended"])'
wait   windows[0].sidebar.sections[?name=="ended"].collapsed == false && windows[0].sidebar.rows[?name=="i19 甲"].rect != null
shot   i19-expanded
# 双击：焦点 pane 在运行 Agent，按 ↩ 的规则开新标签
dclick 'row(name=="i19 甲")'
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].panes[0].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?name=="i19 甲"].section == "project:i19" timeout=10s
rclick 'row(name=="i19 乙")'
wait   windows[0].context_menu.items[*] exists count=6 && windows[0].context_menu.items[0].label == "恢复" && windows[0].context_menu.items[1].label == "在右侧恢复" timeout=3s
click  'menu("在右侧恢复")'
wait   windows[0].tabs[1].panes[*] exists count=2 && windows[0].tabs[1].panes[1].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?name=="i19 乙"].section == "project:i19" timeout=10s
# 「i19」分组的会话都空闲，分组是折叠的（折叠分区里的行不能点）：先点分组标题展开
wait   windows[0].sidebar.sections[?name=="project:i19"].collapsed == true timeout=5s
click  'rect(windows[0].sidebar.sections[?name=="project:i19"])'
wait   windows[0].sidebar.rows[?name=="i19 运行中"].visible == true && windows[0].sidebar.rows[?name=="i19 运行中"].rect != null timeout=3s
rclick 'row(name=="i19 运行中")'
wait   windows[0].context_menu.items[*] exists count=3 timeout=3s
assert windows[0].context_menu.items[0].label == "重命名…" && windows[0].context_menu.items[1].label == "静音这个会话的通知" && windows[0].context_menu.items[2].label == "复制会话 ID"
shot   i19-live-menu
key    esc
wait   windows[0].context_menu == null
```

## judge
- `i19-expanded`：「已结束」下两行变淡；`i19 甲` / `i19 乙` 恢复后回到「i19」项目分组（断言）。
- 已结束会话的菜单是「恢复 / 在右侧恢复 / 重命名… / 静音这个会话的通知 / 复制会话 ID / 移到废纸篓…」（断言六项、前两项）；
  运行中会话的菜单只有三项（断言）。
- `key esc` 没有关掉菜单时，点一下菜单外的空白处（前台），报告里注明。
