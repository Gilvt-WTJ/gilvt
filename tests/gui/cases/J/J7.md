# J7 渲染视图的选区：单击与切换源码视图都会清除
requires: sandbox
checklist: J7
scenarios: []

渲染视图里单击不留选区；拖出选区后按 `S` 切到源码 diff 视图，选区清除。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j7 && cd work/j7 && git init -q && printf '# Title here\n\nFirst paragraph of text.\n\nSecond paragraph of text.\n\n- item one\n- item two\n\n~~~\ncode line 1\ncode line 2\n~~~\n' > note.md"
type   "cd -P ~/work/j7 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j7"
type   "gilvt view note.md\n"
wait   windows[0].overlay.kind == "quicklook" && windows[0].overlay.mode == "rendered" && windows[0].overlay.code exists timeout=10s
# rect(…) 是矩形的中心，偏移加在中心上。文档区 (265,107,670,524)，中心 (600,369)；标题在 y≈151，段落 y≈186 / 216，列表项 y≈247 / 271，代码块两行 y≈315 / 335；正文从 x≈305 开始
click  'rect(windows[0].overlay.code)+(-250,-183)'
assert windows[0].overlay.selection == null
drag   'rect(windows[0].overlay.code)+(-300,-218)' 'rect(windows[0].overlay.code)+(-40,-98)'
wait   windows[0].overlay.selection != null timeout=5s
click  'rect(windows[0].overlay.code)+(-250,-183)'
wait   windows[0].overlay.selection == null timeout=5s
drag   'rect(windows[0].overlay.code)+(-300,-218)' 'rect(windows[0].overlay.code)+(-40,-98)'
wait   windows[0].overlay.selection != null timeout=5s
key    s
wait   windows[0].overlay.mode != "rendered" && windows[0].overlay.selection == null timeout=5s
```
