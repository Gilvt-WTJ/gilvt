# V5 内置编辑器：外部修改（静默更新、横幅、重新载入、覆盖、删除）
requires: sandbox
checklist: V5
scenarios: [default]

编辑 pane 监听文件所在目录（防抖约 150 ms）：没有未保存修改时，外部改写文件 → 缓冲区**静默更新**，状态栏左侧闪「已更新」约 2 秒；
有未保存修改时 → 不用等 `⌘S`，头部下面立即出现黄色横条「文件已在磁盘上被修改…」（重新载入 / 对比 / 仍然覆盖）。
「重新载入」把磁盘内容作为**一次可撤销的编辑**换进来并算作已保存，`⌘Z` 回到我的版本（又是未保存）；「仍然覆盖」把我的版本写到磁盘；
`Esc` 收起横条，但之后 `⌘S` 仍被拦下、横条重新出现；文件被删除 → 横条「文件已被删除或移走。」（保存（重新创建）/ 关闭 / 知道了），
「保存（重新创建）」把缓冲区写回原路径。「对比」见 V6。

默认字号（13）下终端区约 92 列，「编辑」开新文件标签（见 V2），编辑 pane 在 `tabs[1]`。外部改写一律是 `cp` 一份事先写好的文件
（`work/v5/ext-*`），这样磁盘内容可以用 `cmp` 精确比较。

**状态断言与截图的分工**：
- `debug state` 不导出缓冲区文字（`docs/debug-state.md`「安全与隐私」），缓冲区内容用**保存后的磁盘文件**间接证明：
  静默更新后在文首输入 `a1 ` 再 `⌘S`，磁盘必须正好是「`a1 ` + 外部版本」（证明缓冲区换成了外部版本，且保存没有被误判为冲突）；
  「重新载入 → `⌘Z`」之后「仍然覆盖」写出的必须正好是「`b2 a1 ` + 第一个外部版本」（证明 `⌘Z` 回到的是我的版本）。
- 「重新载入」之后缓冲区是磁盘版本这一点，除了 `dirty == false`、横条消失，还看截图 `v5-reloaded`。
- 横条按钮用 `bar_buttons[?label=="…"].rect` 点；文字、颜色、默认按钮样式看截图。

## judge
- `v5-banner`：编辑 pane 头部下面一条黄色横条「⚠ 文件已在磁盘上被修改，而你有未保存的改动。」，按钮从左到右
  「重新载入」「对比」「仍然覆盖」，「对比」是默认（强调）样式；头部和标签显示 ●；文本区仍是我的版本（第 1 行以 `b2 a1 ---` 开头），
  不是外部版本。
- `v5-reloaded`：横条消失，● 消失；文本区是外部版本（`# external two`、`changed by someone else`），第 1 行是 `---`；
  状态栏左侧是「已更新」（约 2 秒，截图时可能已恢复成「第 N 行，第 M 列」，那也算通过）。
- `v5-deleted`：横条「⚠ 文件已被删除或移走。」，按钮「保存（重新创建）」「关闭」「知道了」，「保存（重新创建）」是默认样式；头部显示 ●；
  文本区仍是缓冲区内容（第 1 行以 `e5 ---` 开头）。
- 没有自动化：横条的「关闭」「知道了」（删除横条）这里没点；需要时手动点一次，确认「关闭」关掉 pane（未保存时先问）、「知道了」只收起横条。
