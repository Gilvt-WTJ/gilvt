# I15 多行任务与四种启动位置
requires: sandbox
checklist: I15
scenarios: [default]

`⇧↩` 换行输入两行任务；`↩`（空闲 shell 就地，否则新标签）、`⌘↩`（右侧）、`⌘⇧↩`（下方）。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i15 && cd -P ~/work/i15 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i15"
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" timeout=5s
type   "i15 第一行"
key    shift+enter
type   "第二行"
wait   windows[0].overlay.task == "i15 第一行\n第二行"
shot   i15-panel
key    enter
# 焦点在空闲 shell：就地执行
wait   windows[0].overlay == null && windows[0].tabs[*] exists count=1 && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?section=="project:i15"].name == "i15 第一行" && windows[0].tabs[0].panes[0].screen_tail[*] == "  第二行" timeout=10s
shot   i15-inplace
# 焦点在 Agent pane：↩ 开新标签
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" && windows[0].overlay.preview.head == "将在新标签执行：" timeout=5s
type   "i15 新标签"
key    enter
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?name=="i15 新标签"] exists timeout=10s
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" timeout=5s
type   "i15 右侧"
key    cmd+enter
wait   windows[0].tabs[1].panes[*] exists count=2 && windows[0].tabs[1].panes[1].focused == true && windows[0].tabs[1].panes[1].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?name=="i15 右侧"] exists timeout=10s
key    cmd+shift+n
wait   windows[0].overlay.kind == "new_agent" timeout=5s
type   "i15 下方"
key    cmd+shift+enter
wait   windows[0].tabs[1].panes[*] exists count=3 && windows[0].tabs[1].panes[?focused==true].foreground == "agent:claude" timeout=15s
wait   windows[0].sidebar.rows[?name=="i15 下方"] exists timeout=10s
shot   i15-splits
```

## judge
- 多行任务作为一个参数传入：左栏名字是第一行（断言），fake claude 的回复里第二行单独一行（`  第二行`，断言）；
  `i15-inplace` 的 shell 里可能先出现续行提示符 `>` 再执行，符合已知限制。
- `i15-splits`：标签 2 里是「新标签」的 pane、它右侧的「右侧」pane、「右侧」下方的「下方」pane。
- 「按住 `⌘` / `⌘⇧` 时预览的位置词变为「右侧」/「下方」」：`keys` 工具只能发完整的按键，不能单独按住修饰键
  （没有 flagsChanged 事件），这一项需要人工看一次：按住 `⌘` 看预览标题变成「将在右侧执行：」，按住 `⌘⇧` 变成「将在下方执行：」。
