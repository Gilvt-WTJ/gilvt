# P1 ⌘Q 重开：2 个窗口、3 个标签（含分屏）原样恢复
requires: sandbox
checklist: P1
scenarios: []

窗口 1：标签 1 左右分屏（比例被挪过，不是 0.5）、标签 2；窗口 2：一个标签。每个 pane 各在自己的目录。`⌘Q` 退出（没有 agent，不弹确认）后重开，
布局、分屏比例、cwd、窗口位置和大小与退出前一致。`windows[].layout` 是此刻会被写进 `workspace.json` 的内容（每次查询现算），
所以重启前后各取一次就能比较。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/p1/a ~/work/p1/b ~/work/p1/c ~/work/p1/d && cd -P ~/work/p1/a && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/p1/a"
# 标签 1：左右分屏，右边 pane 在 b，再把分界线挪一格（比例不再是 0.5）
key    cmd+d
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].focused == true && windows[0].tabs[0].panes[1].foreground == "shell" timeout=10s
type   "cd -P ~/work/p1/b && clear\n"
wait   windows[0].tabs[0].panes[1].cwd contains "/work/p1/b"
key    cmd+ctrl+left
wait   windows[0].layout.tabs[0].tree.ratios[0] != 0.5 timeout=3s
# 标签 2
key    cmd+t
wait   windows[0].tabs[*] exists count=2 && windows[0].tabs[1].active == true && windows[0].tabs[1].panes[0].foreground == "shell" timeout=10s
type   "cd -P ~/work/p1/c && clear\n"
wait   windows[0].tabs[1].panes[0].cwd contains "/work/p1/c"
# 窗口 2：gilvt 在后台时新窗口不会成为 key window，先点一下把 gilvt 带到前台
click  pane(focused)
wait   front == true timeout=5s
key    cmd+n
wait   windows[*] exists count=2 && windows[?key==true].tabs[0].panes[0].foreground == "shell" && windows[?key==true].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   --window key "cd -P ~/work/p1/d && clear\n"
wait   windows[?key==true].tabs[0].panes[0].cwd contains "/work/p1/d"
assert windows[*].layout.tabs[*] exists count=3
assert windows[*].layout.frame != null
# 退出前的布局，写进报告供对照（窗口位置和大小在 frame 里）
state  windows[*].layout
shot   p1-before
# ⌘Q：没有 agent，直接退出并同步写入 workspace.json；再在同一个沙盒里重开
key    cmd+q
sleep  2s
restart
wait   windows[*] exists count=2 timeout=20s
wait   windows[*].layout.tabs[*] exists count=3 timeout=10s
assert windows[*].layout.tabs[*].tree.ratios[0] != 0.5
assert windows[*].layout.tabs[*].tree.children[*].pane.cwd contains "/work/p1/a"
assert windows[*].layout.tabs[*].tree.children[*].pane.cwd contains "/work/p1/b"
assert windows[*].layout.tabs[*].tree.pane.cwd contains "/work/p1/c"
assert windows[*].layout.tabs[*].tree.pane.cwd contains "/work/p1/d"
# 重开的 pane 真的在各自的目录里（shell 集成上报）
wait   windows[*].tabs[*].panes[*].cwd contains "/work/p1/a" && windows[*].tabs[*].panes[*].cwd contains "/work/p1/b" && windows[*].tabs[*].panes[*].cwd contains "/work/p1/c" && windows[*].tabs[*].panes[*].cwd contains "/work/p1/d" timeout=15s
assert windows[*].tabs[*].panes[?kind=="terminal"] exists count=4
assert pending == []
state  windows[*].layout
shot   p1-after
```

## judge
- `state` 的两次输出（`p1-before` 之前、`p1-after` 之前，都在报告里）逐项对照：每个窗口的 `layout.tabs[].tree`（分屏方向 `axis`、`ratios`、`children` 的 `pane_id` 和 `cwd`）完全相同，
  `active_tab` 相同；窗口的 `frame`（`x`、`y`、`w`、`h`）相同（窗口 id 会变，用 `frame` 配对两个窗口；允许 1 点以内的取整误差）。
  断言只能验证重开后各目录、标签数、非 0.5 的比例都在；与重启前逐项相等由这一条判断。
- `p1-before` / `p1-after`：窗口 1 标签 1 的左右两个 pane 的宽度比例看起来一致，标签栏有两个标签，窗口 2 在上次的位置。
- 两个窗口重开后哪个排在 `windows[0]` 不保证，对照时按 `frame` 配对，不按下标。
