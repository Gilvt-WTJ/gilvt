让终端知道你的 Agent 在做什么

Claude Code 和 Codex 照常在自己的原生界面里并排运行。gilvt 告诉你哪个会话在等你、每一轮改了什么，一个快捷键就跳过去。

一个真正的终端，再加上所有 Agent 的全景

gilvt 首先是一个完整的日常终端：标签页、分屏、真彩色、Kitty 键盘协议、中文输入法和 GPU 渲染。在此之上，它读懂 Claude Code 和 Codex 在做什么，但从不替你往里面输入任何东西。

一个左栏看全所有会话

所有 Agent 会话按项目或状态分组，等你审批、在问你问题的始终排在最上面。

跳到需要你的会话 ⇧⌘J

跨标签页、跨窗口，在需要你的会话之间循环跳转；pane 描边和标签圆点一眼看清状态。

每一轮都是一条时间线

命令、文件修改、TODO 和失败，按轮次列出；点一行，终端就滚回那里。

每一轮改了什么 ⌥⌘2

每轮的产物和「本轮」diff，不离开终端就能检查 Agent 的工作。

找回并恢复会话 ⇧⌘R

搜索几天前的会话接着做，离线 Review 跑完的会话，在新的 git worktree 里开出新 Agent。

监控官 ⇧⌘O

所有 Agent 和终端排成卡片墙；在任意标签的命令条里问"什么需要我处理"，由你本机的 CLI 回答。

Quick Look 与编辑器

代码高亮与 diff、排版后的 Markdown 和 Mermaid、⌘P 模糊找文件，以及带实时预览的内置编辑器。

725 套主题

与 Ghostty 同格式的主题库，也支持你自己的主题，深浅色各选一套，窗口外框跟着主题变。

几条基本原则

  • Agent 始终是原生 TUI。不另做聊天界面，也不提供审批按钮。
  • 只观察，不代答。gilvt 只展示状态、移动焦点，从不向 Agent 输入按键。
  • 不改你的配置。hooks 在启动时注入，你的 rc 文件、~/.claude、~/.codex 原样不动。
  • 没有遥测。gilvt 自己不发起任何网络请求。隐私说明

安装

需要 macOS 11 及以上。界面默认简体中文，可以在设置（⌘,）→「语言」里切换成 English。

  1. 下载磁盘映像并打开。
  2. 把 Gilvt 拖进「应用程序」，再从那里打开。如果直接在磁盘映像里打开，gilvt 会提示把自己移过去。
  3. 在 pane 里运行 claude 或 codex，左栏和检查器会自动识别这个会话。

也可以用 Rust 和 Xcode Command Line Tools 从源码构建：

git clone https://github.com/Gilvt-WTJ/gilvt.git
cd gilvt
scripts/bundle.sh release
open target/release/Gilvt.app
