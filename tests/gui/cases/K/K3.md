# K3 无改动的轮折叠、「后被改动」与汇总
requires: sandbox
checklist: K3
scenarios: [artifacts-turns]

三轮连着演完：第 2 轮只解释，第 3 轮又改了 a.txt。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s

type   "cd -P ~/work/k3 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k3"
type   "claude @scenario:artifacts-turns\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[*] exists count=3 && windows[0].inspector.artifacts.cards[0].state == "done" timeout=40s
assert windows[0].inspector.artifacts.cards[1].state == "quiet" && windows[0].inspector.artifacts.cards[1].quiet_group != null

shot   k3-three-turns
```
