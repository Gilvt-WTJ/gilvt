# I21 「会话」菜单
requires: manual
checklist: I21
scenarios: []

「会话」菜单在系统菜单栏里：Peekaboo 读不到 gpui 菜单的菜单项（spec §2），测试也不截菜单栏（只截 gilvt 自己的窗口）。
由用户本人看一次；打开浮层之后的状态仍可以断言。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
# 手动：请用户点菜单栏的「会话」，确认顶部两项是「新建 Agent… ⌘⇧N」「会话… ⌘⇧R」，然后点「新建 Agent…」
wait   windows[?key==true].overlay.kind == "new_agent" timeout=120s
key    esc
wait   windows[?key==true].overlay == null
# 手动：再点「会话」→「会话…」
wait   windows[?key==true].overlay.kind == "sessions" timeout=120s
key    esc
wait   windows[?key==true].overlay == null
```

## judge
- 「需要你」清单：菜单项的文字与快捷键（「新建 Agent… ⌘⇧N」「会话… ⌘⇧R」在最上面）；gpui 菜单不支持勾选状态，快捷键由系统显示。
- 两个浮层是否打开由断言核对。
