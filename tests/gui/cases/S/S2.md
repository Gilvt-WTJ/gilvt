# S2 设置页切换语言并写回
requires: sandbox
checklist: S2
scenarios: []

## steps
```gilvt-steps
restart --set 'language="zh-CN"'
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
raise
key    cmd+,
wait   settings.key == true && settings.language == "zh-CN" timeout=5s
click  'rect(settings.pages[?id=="language"])'
wait   settings.page == "language" timeout=5s
click  'rect(settings.languages[?id=="en"])'
wait   settings.language == "en" && settings.languages[?id=="en"].selected == true timeout=5s
sh     "grep -qx 'language = \"en\"' .config/gilvt/config.toml"
shot   --window key s2-english
click  'rect(settings.languages[?id=="zh-CN"])'
wait   settings.language == "zh-CN" && settings.languages[?id=="zh-CN"].selected == true timeout=5s
sh     "grep -qx 'language = \"zh-CN\"' .config/gilvt/config.toml"
key    cmd+w
```

## judge
- `s2-english`：语言页的 English 行有选中态，左栏页名同步显示英文，窗口中没有需要重启才能生效的提示。
