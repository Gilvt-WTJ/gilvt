# I6 筛选与搜索
requires: sandbox
checklist: I6
scenarios: [hist-claude, hist-codex]

「全部项目」「≥ 7 天未活动」两个筛选，以及按项目名、首条提示词、会话 ID 前缀、cwd 片段搜索（不区分大小写）。
spec §6.2 把 I6 列为真实 Agent 用例，但这一行只验证 gilvt 自己的列表与筛选，不涉及 `--resume`，fake agent 足够。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
seed   hist-claude --cwd work/i6 --age 1h --id c1a0de00-0000-4000-8000-000000000601 --prompt "i6 猫头鹰 当前项目"
seed   hist-codex --cwd work/i6 --age 2h --id 01990000-0000-7000-8000-000000000601 --prompt "i6 河狸 当前项目"
seed   hist-claude --cwd work/i6-old --age 9d --id c1a0de00-0000-4000-8000-000000000602 --prompt "i6 猫头鹰 旧项目"
type   "cd -P ~/work/i6 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i6"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.filter.scope == "current" && windows[0].overlay.items == 2 timeout=15s
shot   i6-current
click  'rect(windows[0].overlay.chips[?label=="全部项目"])'
wait   windows[0].overlay.filter.scope == "all"
shot   i6-all
click  'rect(windows[0].overlay.chips[?label=="≥ 7 天未活动"])'
wait   windows[0].overlay.filter.stale == true
shot   i6-stale
# 输入时自动切到「全部项目」：先回到当前项目、关掉清理筛选
click  'rect(windows[0].overlay.chips[?label=="≥ 7 天未活动"])'
wait   windows[0].overlay.filter.stale == false
click  'rect(windows[0].overlay.chips[?label=="i6"])'
wait   windows[0].overlay.filter.scope == "current" && windows[0].overlay.filter.stale == false
type   "I6-OLD"
wait   windows[0].overlay.query == "I6-OLD" && windows[0].overlay.filter.scope == "all" && windows[0].overlay.items == 1 timeout=5s
key    esc
wait   windows[0].overlay == null
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.query == "" timeout=5s
type   "猫头鹰"
wait   windows[0].overlay.filter.scope == "all" && windows[0].overlay.items == 2 timeout=5s
shot   i6-prompt-word
key    esc
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.query == "" timeout=5s
type   "C1A0DE00-0000-4000-8000-00000000060"
wait   windows[0].overlay.items == 2 timeout=5s
key    esc
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.query == "" timeout=5s
type   "WORK/I6-OLD"
wait   windows[0].overlay.items == 1 timeout=5s
key    esc
wait   windows[0].overlay == null
```

## judge
- `i6-all`：每行加上项目名（i6 / i6-old / 本节其他用例的项目）。
- `i6-stale`：只剩 7 天未活动的会话（至少有「i6 猫头鹰 旧项目」），右侧加上大小，出现勾选框和「⇧ / ⌘ 点击多选」提示。
- `i6-prompt-word`：「i6 猫头鹰 当前项目」（当前项目）排在「i6 猫头鹰 旧项目」（其他项目）之前，分在两个标题下。
- 项目名、首条提示词、ID 前缀、cwd 片段的搜索都由 `items` 断言核对；大写输入也能匹配（不区分大小写）。
- 点击筛选条是前台动作；锁屏时这几步退出 5，改为只做输入搜索的部分。
