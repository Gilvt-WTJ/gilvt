# K11 重启 gilvt 后卡片还在
requires: sandbox
checklist: K11
scenarios: [artifacts-basic]

退出并重新启动沙盒里的 gilvt，恢复同一会话，卡片与文件列表还在。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/k11 && cd work/k11 && git init -q && printf '# Demo\n' > README.md && printf 'base\n' > a.txt && git add . && git -c user.name=t -c user.email=t@t commit -qm init"
type   "cd -P ~/work/k11 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k11"
type   "claude @scenario:artifacts-basic\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.tab == "artifacts" && windows[0].inspector.artifacts.cards[0].state == "done" && windows[0].inspector.artifacts.cards[0].files[*] exists count=2 timeout=30s
wait   windows[0].inspector.card.status == "idle" timeout=10s
restart
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=20s
type   "cd -P ~/work/k11 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/k11"
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.items == 1 timeout=15s
key    enter
wait   windows[0].overlay == null && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=15s
key    cmd+alt+2
wait   windows[0].inspector.artifacts.cards[*] exists count=1 && windows[0].inspector.artifacts.cards[0].state == "done" timeout=15s
assert windows[0].inspector.artifacts.cards[0].files[*] exists count=2
shot   k11-restored
```

## judge
- `k11-restored`：卡片与两个文件行都在。
