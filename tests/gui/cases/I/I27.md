# I27 会话行显示运行目录（含目录已不存在）
requires: sandbox
checklist: I27
scenarios: [hist-claude, default]

每个会话行的名称下方一行灰字是「<缩短目录> · <分支> · N 轮」：目录用 `~` 代替家目录（沙盒 HOME 在 `/var/…` 下是符号链接，
会话记录的是物理路径 `/private/var/…`，同样要显示 `~`）。分支来自左栏的 git 缓存（只查运行中会话的目录），所以这里在一个 git 仓库里
运行一个会话；同一目录下已结束的会话也因此显示分支。目录已经删掉的会话 `dir_missing == true`，行内目录画删除线并标「目录已不存在」。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     'git init -q -b i27-feature ~/work/i27 && cd ~/work/i27 && git config user.email t@t && git config user.name t && git commit -q --allow-empty -m init'
seed   hist-claude --cwd work/i27 --age 3d --id c1a0de00-0000-4000-8000-000000002701 --prompt "i27 在仓库里的会话"
seed   hist-claude --cwd work/i27-gone --age 4d --id c1a0de00-0000-4000-8000-000000002702 --prompt "i27 目录已删的会话"
sh     'rm -rf ~/work/i27-gone'
type   "cd -P ~/work/i27 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i27"
type   "claude @scenario:default i27 运行中\n"
wait   windows[0].sidebar.rows[?name=="i27 运行中"].status == "idle" && windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=20s
# 分支来自左栏的 git 缓存（会话出现后约 1–10 秒）
wait   windows[0].sidebar.rows[?name=="i27 运行中"].git.branch == "i27-feature" timeout=25s
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" && windows[0].overlay.rows[?title contains "i27 在仓库里"] exists && windows[0].overlay.rows[?live==true] exists timeout=15s
assert windows[0].overlay.rows[?title contains "i27 在仓库里"].dir == "~/work/i27" && windows[0].overlay.rows[?title contains "i27 在仓库里"].dir_missing == false
# 分支按目录取：同一目录下已结束的会话也显示它
assert windows[0].overlay.rows[?title contains "i27 在仓库里"].meta == "~/work/i27 · i27-feature · 2 轮"
assert windows[0].overlay.rows[?live==true].dir == "~/work/i27" && windows[0].overlay.rows[?live==true].meta contains "~/work/i27 · i27-feature · "
# 截图前等一帧：后台窗口的截图可能还是上一帧
sleep  1s
shot   i27-current
# 输入就搜索全部项目：已删目录的会话在另一个项目里
type   "i27 "
wait   windows[0].overlay.filter.scope == "all" && windows[0].overlay.rows[?title contains "i27 目录已删"] exists timeout=5s
assert windows[0].overlay.rows[?title contains "i27 目录已删"].dir == "~/work/i27-gone" && windows[0].overlay.rows[?title contains "i27 目录已删"].dir_missing == true
assert windows[0].overlay.rows[?title contains "i27 在仓库里"].dir_missing == false
sleep  1s
shot   i27-missing
key    esc
wait   windows[0].overlay == null
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
```

## judge
- `i27-current`：每行名称下方一行灰字：「~/work/i27 · i27-feature · 2 轮」，运行中的那一行「~/work/i27 · i27-feature · 1 轮」（断言），右侧是时间或「● 运行中」。
- `i27-missing`：「i27 目录已删的会话」那一行的目录 `~/work/i27-gone` 画了删除线，旁边标「目录已不存在」；其他行的目录没有删除线。
