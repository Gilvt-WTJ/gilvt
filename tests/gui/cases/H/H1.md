# H1 时间线实时新增与更新（Claude / Codex）
requires: sandbox
checklist: H1
scenarios: [timeline, timeline-codex]

先后运行 fake claude 与 fake codex 各一轮（Bash / shell 命令 + 文件编辑），检查器「过程」标签不用手动刷新就新增、更新时间线行。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/h1 && cd -P ~/work/h1 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/h1"
assert windows[0].inspector.visible == true
type   "claude @scenario:timeline\n"
# echo early 运行 1.5 秒：这时 Read / Edit / Write 已经在时间线上，Bash 行还在执行
wait   windows[0].sidebar.rows[?section=="project:h1"].detail contains "echo early" && windows[0].inspector.card.status == "running_tool" && windows[0].inspector.timeline_rows != 0 timeout=15s
shot   h1-claude-running
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Done: README.md updated" timeout=15s
shot   h1-claude-done
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=10s
type   "clear && codex @scenario:timeline-codex\n"
# cargo test 运行 4 秒
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" && windows[0].sidebar.rows[?section=="project:h1"].detail contains "cargo test" timeout=15s
shot   h1-codex-running
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "Refactored greet()" timeout=15s
shot   h1-codex-done
```

## judge
- `h1-claude-running`：时间线已有 `Read README.md`、`Edit README.md +2 −1`、`Write hello.txt +1` 三行，`Bash echo early` 一行处于执行中；
  `h1-claude-done` 在此基础上多出 `cargo test`（红色 ✗、`exit 101`）与 `echo late` 两行，`echo early` 变为完成。两张图之间
  没有任何手动刷新，说明时间线是实时更新的。
- Read / Edit / Write / Bash 的图标互不相同；摘要是文件名或命令本身。
- `h1-codex-running`：TODO 块（读代码 ☑、改代码 ☑、跑测试 ◐），时间线有 `sed -n 1,20p src/lib.rs`、`apply_patch src/lib.rs +3 −1`，
  `cargo test` 在执行中；`h1-codex-done` 里 `cargo test` 完成，TODO 全部 ☑。Codex 的命令图标与 Claude 的 Bash 一致。
- 注意：Codex 在新沙盒里第一次启动时如果是精简模式（`up` 打印过 trust cache 没写成的警告），时间线仍然来自 rollout，
  只是没有锚点；这不影响本用例。
