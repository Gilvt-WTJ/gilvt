# H19 重绘后点击较早的行：不跳错
requires: real-claude
checklist: H19
scenarios: []

真实 Claude 在窗口尺寸变化时整屏重绘（清掉回滚缓冲）；fake agent 不这样做，只会让锚点按「换行重排」的已知限制偏移，
所以这一项必须用真实 claude。切换 `⌘I` 引起重绘后点击较早的时间线行：要么正确跳转，要么提示「已超出回滚范围」，绝不跳到错误的内容。

## setup
```sh
tests/gui/sandbox.sh real-up --label h19
```

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
type   "mkdir -p ~/gilvt-lab/h19 && cd -P ~/gilvt-lab/h19 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/gilvt-lab/h19"
type   "claude --no-chrome --allowedTools 'Bash(echo:*)'\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:claude" timeout=30s
# 在这个目录第一次运行时 Claude 会先问是否信任它：screen_tail 里出现 trust 字样时执行 key enter
type   "依次用 Bash 执行 echo h19-one、echo h19-two、echo h19-three（每条单独调用一次），然后只回复 done。\n"
wait   windows[0].inspector.card.status != "idle" timeout=30s
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "done" timeout=180s
key    cmd+i
wait   windows[0].inspector.visible == false
key    cmd+i
wait   windows[0].inspector.visible == true
sleep  2s
shot   h19-redrawn
click  'rect(windows[0].inspector.rows[?label contains "echo h19-one"])'
shot   h19-clicked
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
```

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/H19
```

## judge
- `h19-clicked` 只能是两种之一：终端停在 `echo h19-one` 的调用处并高亮；或出现「已超出回滚范围」提示且终端没动。
  如果高亮落在别的内容上（例如 `h19-two` 或回复文字），判为 ❌。
- 可以再对 `echo h19-three` 重复一次点击，结论相同。
