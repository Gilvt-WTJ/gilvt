# H23 Codex 子 Agent 与后台 terminal
requires: real-codex
checklist: H23
scenarios: []

真实 Codex 的新版 rollout 会把子 Agent 生命周期写成 `SubAgentActivity`，并把后台 terminal 的启动与等待拆成
`exec_command` + `wait`（旧版为 `exec_command` + `write_stdin`）。检查器应把它们还原成用户实际关心的两条过程。

## setup
```sh
tests/gui/sandbox.sh real-up --label h23
```

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
type   "mkdir -p ~/gilvt-lab/h23 && cd -P ~/gilvt-lab/h23 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/gilvt-lab/h23"
type   "codex\n"
wait   windows[0].tabs[0].panes[0].foreground == "agent:codex" timeout=30s
type   "启动一个名为 process_check 的子 Agent，让它只回复 ready；同时在后台 terminal 执行 sleep 8 && echo background-done，并等待两者完成。\n"
wait   windows[0].inspector.rows[?kind=="subagent"].label contains "process_check" timeout=60s
wait   windows[0].inspector.rows[?kind=="tool"].label contains "sleep 8" timeout=60s
shot   h23-running
wait   windows[0].inspector.rows[?kind=="subagent"].status == "ok" && windows[0].inspector.rows[?label contains "sleep 8"].status == "ok" timeout=180s
shot   h23-done
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" timeout=15s
```

## teardown
```sh
tests/gui/sandbox.sh down --keep ~/gilvt-lab/reports/<日期>-<标签>/H23
```

## judge
- `h23-running`：子 Agent 行是紫色 `spawn_agent · process_check`；后台命令行显示 `$ exec_command sleep 8 && echo background-done`，而不是 `exec const r = await tools...`。
- `h23-done`：同两行原地进入完成状态；没有额外的 `wait` 或 `write_stdin` 行。
- 这是真实 Codex 用例：会产生费用并写入真实 `~/.codex`；报告里记下 `codex --version`。
