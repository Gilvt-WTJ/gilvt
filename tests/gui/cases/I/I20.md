# I20 左栏把已结束会话移到废纸篓
requires: sandbox
checklist: I20
scenarios: [default]

右键「已结束」里的测试会话 →「移到废纸篓…」：底部出现确认条；`Esc` 取消；确认后它从左栏和 `⌘⇧R` 列表消失，文件进了真实用户的废纸篓。
spec §6.2 把 I20 列为真实 Agent 用例；但这里移走的是 fake claude 在沙盒里写的会话记录，gilvt 的行为与真实会话相同，
而且不会碰到用户真实的 `~/.claude`。

## steps
```gilvt-steps
restart
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
type   "mkdir -p ~/work/i20 && cd -P ~/work/i20 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/i20"
type   "claude --session-id c1a0de00-0000-4000-8000-000000002001 @scenario:default i20 要删除的会话\n"
wait   windows[0].inspector.card.status == "idle" && windows[0].tabs[0].panes[0].screen_tail[*] contains "⏺ OK: i20 要删除的会话" timeout=15s
type   "/exit\n"
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].sidebar.sections[?name=="ended"].count == 1 timeout=10s
shot   i20-collapsed
click  'rect(windows[0].sidebar.sections[?name=="ended"])'
wait   windows[0].sidebar.rows[?name=="i20 要删除的会话"].rect != null
rclick 'row(name=="i20 要删除的会话")'
wait   windows[0].context_menu.items[*].label == "移到废纸篓…" timeout=3s
click  'menu("移到废纸篓…")'
wait   windows[0].sidebar.trash_confirm.sessions[*] == "claude:c1a0de00-0000-4000-8000-000000002001" timeout=3s
# 附属数据大小在后台算（确认条先写「+ 附属 计算中…」），等一下再截图
sleep  1s
shot   i20-confirm
key    esc
wait   windows[0].sidebar.trash_confirm == null && windows[0].sidebar.rows[?name=="i20 要删除的会话"] exists timeout=3s
rclick 'row(name=="i20 要删除的会话")'
click  'menu("移到废纸篓…")'
wait   windows[0].sidebar.trash_confirm.sessions[*] == "claude:c1a0de00-0000-4000-8000-000000002001" timeout=3s
# 附属数据大小在后台算（确认条先写「+ 附属 计算中…」），等一下再截图
sleep  1s
shot   i20-confirm-again
click  'rect(windows[0].sidebar.trash_confirm.buttons[?label=="移到废纸篓"])'
wait   windows[0].sidebar.trash_confirm == null && windows[0].sidebar.rows[?name=="i20 要删除的会话"] !exists timeout=10s
note-trashed c1a0de00-0000-4000-8000-000000002001
sh     "! find .claude -name 'c1a0de00-0000-4000-8000-000000002001*' | grep -q ."
key    cmd+shift+r
wait   windows[0].overlay.kind == "sessions" timeout=5s
type   "i20 要删除"
wait   windows[0].overlay.query == "i20 要删除" && windows[0].overlay.items == 0 timeout=10s
key    esc
```

## judge
- `i20-confirm`：左栏底部的确认条显示会话名「i20 要删除的会话」和「1 个会话 · X MB 将移到废纸篓（可从废纸篓还原）」，
  以及［取消］［移到废纸篓］。
- `Esc` 取消后会话还在（断言）。已知限制：确认条只在窗口根节点有键盘焦点时响应单按的 `Esc`；如果 `Esc` 没有生效，
  点［取消］代替并在报告里注明。
- 确认后：左栏、`⌘⇧R` 列表里都没有它（断言）；`note-trashed` 核对真实 `~/.Trash`，并记进 `trashed.txt`——不要清空废纸篓。
