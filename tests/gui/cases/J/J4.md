# J4 固定 pane 里拖选并 ⌘C
requires: sandbox
checklist: J4
scenarios: []

`gilvt view --pin` 把预览固定成 pane；在它的代码视图里拖选，选区文字与源码一致（Tab 保持为 Tab），`⌘C` 复制。会覆盖用户的剪贴板。

## steps
```gilvt-steps
wait   windows[0].tabs[0].panes[0].foreground == "shell" && windows[0].tabs[0].panes[0].screen_tail[*] contains "sandbox$" timeout=15s
sh     "mkdir -p work/j4 && cd work/j4 && git init -q && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 2;\n\tlet c = a + b;\n}\n' > main.rs && git add main.rs && git -c user.name=t -c user.email=t@t commit -qm init && printf 'fn main() {\n\tlet a = 1;\n\tlet b = 3;\n\tlet c = a + b;\n}\n' > main.rs"
type   "cd -P ~/work/j4 && clear\n"
wait   windows[0].tabs[0].panes[0].cwd contains "/work/j4"
type   "gilvt view --pin main.rs\n"
wait   windows[0].tabs[0].panes[*] exists count=2 && windows[0].tabs[0].panes[1].kind == "preview" && windows[0].tabs[0].panes[1].code exists timeout=10s
assert windows[0].tabs[0].panes[1].selection == null
# 偏移加在固定 pane 的代码区中心上；起点在第 2 行行号槽里，终点在第 4 行行尾之外（行高 16 点；pane 代码区 (602.5,91,356.5,556)，中心 (781,369)）
drag   'rect(windows[0].tabs[0].panes[1].code)+(-173,-254)' 'rect(windows[0].tabs[0].panes[1].code)+(150,-222)'
wait   windows[0].tabs[0].panes[1].selection contains "let a = 1;" && windows[0].tabs[0].panes[1].selection contains "let b = 2;" && windows[0].tabs[0].panes[1].selection contains "let b = 3;" timeout=5s
shot   j4-selected
key    cmd+c
clipboard contains "let a = 1;"
clipboard contains "let b = 3;"
sh     "test \"$(pbpaste | head -c1 | od -An -c | tr -d ' ')\" = '\\t'"
```

## judge
- `j4-selected`：固定 pane 里第 2–4 行有选区高亮，左边终端 pane 没有任何变化。
- 偏移是固定 pane 代码区的中心加偏移；窗口或 pane 宽度变了、选中的行数不对时，按 `panes[1].code` 的实际 rect 调整后重跑。
- 会覆盖用户的剪贴板（报告里注明）。
